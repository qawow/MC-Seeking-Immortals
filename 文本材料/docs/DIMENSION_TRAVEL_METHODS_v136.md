## 跨界面硬规则

1. **人界 → 天渊**：飞升，本体单向；失败可死/残/魔。  
2. **天渊 → 人界**：仅 **分身**（炼虚+），本体留灵界。  
3. **天渊 ⇄ 风元**：管制门，贡献费。  
4. **灵界 → 仙界**：大乘飞升通道（`gate_spirit_to_immortal`）。  
5. **仙界 → 下界**：默认关闭；仅剧情化身级特例。  
6. **秘境**：挂父维度的实例；出口阵 / 超时踢回。  
7. **阴司 / 魔隙**：特殊入口 + 高风险 + 明确回程。
