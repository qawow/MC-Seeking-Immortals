# 妖兽图鉴说明

> 机器可读全表：`data/beast_bestiary.json`（**30** 种野外妖兽 + **5** 种灵宠/灵虫条目）

## 等级与人类境界

| 妖兽级 | 亚档 | 约等于修士 | 备注 |
|---:|---|---|---|
| 1～4 | 初/中/上 | 炼气～筑基 | 可驯服者多 |
| 5～7 | 初/中/上/顶 | 结丹 | **7 级**渡劫可化形 |
| 8～10 | 初/中/后/顶 | 元婴 | 妖王、海域蛟 |
| 11～13 | 初/中/后/顶 | 化神+ | Boss、圣禽 |

## 灵宠（非纯野外）

噬金虫（群）、啼魂兽、麝兰兽、幻焰蛾；巨猿傀儡见 `puppet_definitions`（待建）。

## 掉落规则

- **妖丹**：5 级起 `demon_core_*`  
- **化形**：7 级 `shape_shift_trial_beast` 或灵宠 tier≥7 任务  
- **Boss 三阶段**：`thunder_jiao`、`mirage_sand_beast`、`six_wing_frost_centipede` 等带 `boss_phases_3`

## 与种族系统

化形成功 → 玩家/灵宠可转 `demon_cultivator` + `ancestry`（见 `WORLD_SETTING_BIBLE` §5）。
