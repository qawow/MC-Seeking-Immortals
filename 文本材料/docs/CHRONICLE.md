# 纪年表（Chronicle）· 草稿 v1

> **定位**：为 `WORLD_SETTING_BIBLE.md` 提供时间锚点；原著未给出统一公元纪年，本表采用模组原创 **「道历」** 与 **「灵纪分段」**，数字为**设计用相对尺度**，非原著铁律。  
> **用途**：任务文案、秘境周期、势力兴衰、Patchouli「纪年」章、世界事件 `world_event` 触发。  
> **维护**：史实增补写本节并同步 `data/chronicle_events.json`（**v1 已建，49 条事件**）。游戏内阅读见 `patchouli_books/seeking_immortals/zh_cn/entries/chronicle/`。

---

## 0. 纪年体系说明

### 0.1 道历（Dao Calendar）

| 符号 | 含义 |
|---|---|
| **道历元年** | 人界有文字记载的「诸宗立约」之年（设定为第 0 年） |
| **道历前** | 记作 **蒙昧纪** / **上古纪** / **封魔纪**（不精确到年，用「约」「余」） |
| **道历今** | 玩家默认进入时代 ≈ **道历 12,800～13,200**（可配置 `world_year`） |

### 0.2 灵纪分段（大时代）

| 灵纪 | 道历约略范围 | 主题 | 人界修炼上限（设定） |
|---|---|---|---|
| **一纪·蒙昧** | 道历前 50 万+ | 天地初灵、真灵残影 | — |
| **二纪·上古鼎盛** | 道历前 8 万～3 万 | 石灵傀儡、昆吾灵山、古修洞府 | 化神后期（传说） |
| **三纪·封魔劫** | 道历前 3 万～2.5 万 | 古魔入侵人界、灵气伤损 | 跌至化神初期 |
| **四纪·诸国争霸** | 道历前 2 万～5 千 | 天南正魔、慕兰突兀、乱星海割据 | 化神初期 |
| **五纪·灵衰与飞升路** | 道历 5 千～今 | 资源稀缺、灵界通道断续、玩家时代 | 化神初期 |

### 0.3 与模组周期事件对照

| 事件 | 周期 | 纪年表标签 |
|---|---|---|
| 血色禁地通道衰弱期 | 每 **5 年** 开 5 天 | `cycle_blood_forbidden` |
| 虚天殿浮现 | 每 **300 年** | `cycle_void_palace` |
| 万宝大会（灵界） | 约每 **千年** 一届 | `cycle_treasure_fair` |
| 小天劫（元婴+） | 个体计时 | 非全球历 |
