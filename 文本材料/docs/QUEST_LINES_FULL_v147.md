## 凡人入世（`chapter_0_mortal`）

【凡人·七玄入世（开局）】
先有灵根，再有仙途。长春功只是稳活的第一步。

开局专链：凡人听闻求仙，测灵根，入黄枫外门（或配置等价），修长春功入炼气，接第一桩宗门杂役。贴七玄门/墨大夫启蒙气质，不强制姓名。结束后自然看见血色配额线。

过程：
  1. 凡人镇求仙 — 听药师/游方散修说仙门收徒，心生求仙之念。
  2. 测灵根 — 石盘测灵，属性与品阶落定，决定你前路的易与难。
  3. 入外门 — 入黄枫外门（可配置掩月等其它开局），领杂役袍。
  4. 炼气入门 — 长春功入门，火弹、定神一类小术练手，只求稳活。
  5. 接宗门日课 — 贡献碑上第一桩差事，世界真正向你展开。

后续：huangfeng_blood_quota

【分支】
- 灵根偏木 → 长春功顺；药园差事加成（root_wood）
- 伪灵根/杂灵根 → 修炼慢；执事语气更冷；仍可玩（root_trash）
- 开局选掩月 → 跳过黄枫日课气质，改接掩月外门杂役（配置）（start_yanyue）

【对话摘录】
  测灵执事：「把手放上去。哭也没用，石盘不认眼泪。」
  外门师兄：「长春功先把气跑通。火弹练百次，再想着出门装剑仙。」
  贡献碑旁杂役：「第一桩差事？扫药渣也算贡献。别嫌。」

【失败支】
- refuse_sect: 可走散修开局，难度上升，无配额优先权

【收束】外门袍上的尘土还没抖干净，禁地的名字已经在任务牌上发光。
【时长感】30–90 分钟教学

## 宗门修行（`chapter_1_sect`）

【黄枫谷·血色禁地配额】
贡献堆出来的入场券，不是人情求来的。

越国七派炼气弟子入血色禁地，靠的是宗门配额与试炼令。你在黄枫谷（或等价开局宗门）外门日课、药园差事与巡山中攒贡献，再经执事核销，换得一枚只在窗口期内有效的令。令不是通关保证，只是「被允许去死一回」的资格。死了贡献不退。

适合：炼气中后期外门/内门弟子，或高声望客卿。
氛围：宗门庭院、贡献碑、任务牌；执事话短，认贡献不认脸。
原著气质：贴七派试炼秩序：禁地是集体窗口，不是个人想进就进。

过程：
  1. 接榜 — 在贡献碑与内门任务牌上看到禁地相关公示，明白门槛是贡献而非银两直购。
  2. 攒贡献 — 接外门巡山、药园、坊市跑腿，一点一点把贡献堆到配额线。
  3. 核销换令 — 找执事核销：验身份、扣贡献、发试炼令；叮嘱窗口与死规。
  4. 窗口待命 — 窗口将开，备疗伤丹、遁符、基础攻术，在谷中待命，听开禁号令。

失败：贡献不够、敌对声望、非本派且无客卿资格——拒兑令。
收获感：试炼令一枚；黄枫声望微升；解锁禁地入口权限。
后续：blood_forbidden_run

【分支】
- 专刷药园差 → 贡献稳、声望正；略无聊（grind_herb）
- 专刷巡山 → 有小战斗与轻伤风险（grind_patrol）
- 试图灵石买通 → 执事拒绝；或高黑市价假令风险（buy_favor）

【对话摘录】
  黄枫执事：「禁地的令，是贡献堆出来的，不是求来的。」
  黄枫执事：「死了不退贡献。窗口外这令就是废铁。」
  同门师弟：「听说中环比妖兽还可怕——是人。」

【失败支】
- hostile_rep: 敌对黄枫则贡献堂拒服
- insufficient: 差事循环，直到达标或放弃

【收束】令入手心还温着，执事已经低头写下一个名字。
【时长感】1–3 小时贡献循环

【慕兰—天南战争战役】
风砂里的军功与符火。边关一锁，配额与传送都要让路。

天南与慕兰草原的长期摩擦与大战气质：边境劫掠、法士阵、军功与风灵石、天澜佛力对照。玩家可走九国盟/七派边军侧，或（高难度）慕兰侧渗透。战时边关可锁传送。与天澜秘境、慕兰符师营、军功经济互链。不强制单场灭国结局——以阶段战役推进。

适合：筑基至结丹为主；高阶可作后勤/斩将。
氛围：风砂、军旗、符纸燃烧的焦味，远处佛钟与法士鼓对撞。
原著气质：慕兰之战=人界中期战争舞台，军功与阵营。

过程：
  1. 边境劫掠常态 — 小股法士劫掠边镇灵矿与坊市，九国盟轮戍应战。
  2. 阗天城记忆战（历史） — 慕兰曾打到阗天城下，九国盟以上元灭光阵击退；作背景叙事与阵法图鉴。
  3. 金鼓原对峙（七派vs魔道） — 一月一大打、每日小打的消耗战结构；灵兽山倒戈可触发防线崩溃事件。
  4. 六派北撤 — 撤入九国盟过程惨烈；玩家可选护送/断后/趁乱夺宝。
  5. 边界大战（慕兰全面冲突） — 慕兰倾巢，四大势力轮派支援；可赌战减员。阴罗宗等大晋魔道可插手。
  6. 议和与迁入 — 慕兰战败迁入边境两国结构，转为防突兀前哨；玩家可接安置/监视任务。

【分支】
- 天南/九国盟侧 → 军功+；慕兰敌对
- 慕兰侧 → 风灵石与符师线；天南敌对
- 两边走私 → 暴利；双通缉风险
- 军功换天澜秘境令 → 解锁 tianlan_secret_grotto

【对话摘录】
  慕兰符师：「战时敌对阵营不交易。军功够了再来换令。」
  边军校尉：「风砂里没有中立。你站哪边，旗就插哪边。」
  天澜僧兵：「降魔与退敌，有时是同一桩事。」

【失败支】
- desertion: 军功清零；阵营惩罚
- battlefield_death: 战场死亡规则
- lockdown: 被关在错误一侧的边关

【收束】风停的时候，谁都说自己胜了。边境的碑上，只刻还活着的名字。

【血色禁地试炼】
药在前，人在侧，窗口一关，清场不问姓名。

持令触界碑，神识一收，便落进血雾。外圈是缓冲，药田是经济核心，中环是人祸大于兽祸的争夺带，内圈古禁是贪者的坟。你的目标可以是采齐筑基三主料、交宗门任务、或只求活着出来。南宫婉与墨蛟不在主线强制里——那是水潭带的权重事件。

适合：炼气后期至筑基；持有效试炼令且窗口开放。
氛围：血雾降视野；药香与血腥气混杂；远处传来他派弟子的法术光。
原著气质：禁地=周期试炼场+药田经济+混战，不是单一副本杀怪。

过程：
  1. 触界碑入场 — 界碑前验令，收神入场；同批七派弟子鱼贯而入。
  2. 外圈适应 — 血雾林熟悉规则：低阶兽、路匪式散修、视野压制。
  3. 药田采药 — 药田环带：卫兽与药点绑定。玉髓芝、紫猴花、天灵果是高价值点，不是路边野草。
  4. 中环周旋 — 中环可选周旋：结仇、结盟、或绕开；声望与因果在此累积。
  5. 撤离 — 窗口将尽走出口阵。超时清场或滞留极危——活着带出的东西才算你的。

失败：战死、超时、被夺囊（规则可配）；令不重发。
收获感：药材与中低阶战利；宗门核销贡献加成；「禁地生还」旗。
后续：nangong_wan_weight_optional, 筑基丹炼制/突破

【分支】
- 只采药避战 → 三主料概率升；中环易被抢（herb_focus）
- 主动猎弟子 → 人祸收益；宗门因果与声望跌（pvp_focus）
- 结伴护采 → 安全换分成（team_escort）

【墨蛟水潭事件（权重·可选）】
水下有蛟，岸上有人。你可以猎、可以救、也可以绕。

禁地墨蛟水潭是原著重要场景气质的可玩化：凶蛟、水压、可能的他派弟子危机。本线为权重事件，不强制你扮演任何原著身份。猎蛟拿筋珠，救助或结盟拿人情旗，绕开则无事发生——三种都合法。

适合：已进入禁地并抵达水潭带者。
氛围：墨色深潭，水汽腥冷，灵压沉。
原著气质：南宫婉线=可触发权重，不是必做主线。

过程：
  1. 发现水潭 — 发现水潭，感知蛟息，判断自身火/水手段与队友。
  2. 抉择 — 抉择：猎蛟、介入人事、或标图绕行。
  3. 结算 — 结算：材料，或人情/声望旗，或空手但保命。

失败：水战灭队；或因误伤结下门派仇。
收获感：墨蛟材或人情旗（影响后续掩月/正道观感可选）。

## 乱星海（`chapter_3_chaotic_sea`）

【星宫登记】
乱星海的规矩，星宫说了算。先登记，再谈航线。

入乱星海，星宫是秩序面：注册费、月例、传送网与征税。登记后你才是「有籍」散修或客修，岛际传送与合法坊市更好走。逆星痕迹过重会被当场驳回——星宫与逆星是死对立，不是可以两边满好感的社交游戏。

适合：筑基以上、初入乱星海。
氛围：海岛枢纽、星宫门阙、吏员冷面与灵石算盘。
原著气质：星宫=海上朝廷气质的秩序垄断。

过程：
  1. 抵达枢纽 — 海船或远程阵抵达枢纽/星宫相关岛。
  2. 缴注册 — 缴注册费，听月例与禁令（尤其逆星）。
  3. 开通传送 — 开通星宫门/岛际传送折扣权限。
  4. 逆星警告 — 规则告知：逆星高声望=拒服与通缉风险。

失败：逆星声望过高；灵石不足；伪造身份被识破。
收获感：星宫声望；合法航线；传送门解锁。
后续：xutian_window_prepare, chaotic_sea travel

【分支】
- 正规缴费 → 声望+，航线开（honest_pay）
- 伪造身份 → 高风险；识破=通缉（fake_id）
- 逆星声望高 → 直接驳回或战斗（already_inverse）

【对话摘录】
  星宫注册吏：「乱星海的规矩，星宫说了算。先登记。」
  星宫注册吏：「逆星的气味洗不掉，驳回。」
  排队散修：「月例比命便宜——活着的时候是。」

【失败支】
- reject_inverse: 拒登；可转 inverse_star_intro
- broke: 去打工攒注册费

【收束】籍录落笔的一刻，海上的风好像也顺了一点——至少星宫门肯亮了。
【时长感】20–45 分钟

【逆星接头】
暗号对了再说话。星宫的走狗，海葬。

逆星盟是乱星海暗线：走私、反星宫、暗港趸船。接头靠暗号与引荐，不靠坊市广告。一旦入线，星宫声望会受损；两边都做高的人，终有一日要站队或被两边追杀。
