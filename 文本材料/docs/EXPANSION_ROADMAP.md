# 世界观缺口扫描与扩充路线图

> 配合 `WORLD_SETTING_BIBLE.md` 使用。每项标注 **价值**（对玩法/叙事/实现的影响）与 **优先级**（P0 阻塞 / P1 核心 / P2 丰富 / P3 远期）。

---

## 一、世界观漏洞（逻辑与一致性）

| 缺口 | 现状 | 风险 | 建议修补 | 价值 |
|---|---|---|---|---|
| **人界化神上限** | 汇编：古魔入侵压至化神初；模组仅三境名 | 飞升动机弱 | 写「古魔劫后史」+ 化神后强制跨界任务 | P1：解释进度天花板 |
| **五界与 MC 维度** | 仅概念，无维度 ID | 灵界/魔界无法落地 | 定义 `dimension_id` 与入境门槛表 | P0：后期内容载体 |
| **阴司之界** | 只提冥河秘境 | 鬼修无归属界 | 阴司=秘境集群或子维度，非完整第五界也可 | P2：鬼修叙事完整 |
| **灵根遗传与凡人** | 提基因库，无机制 | 世家玩法空 | 子女/弟子灵根概率公式、测灵仪式 | P1：家族系统基础 |
| **正道「不杀凡人」** | 共识性规则 | PvE/PvP 无约束 | 业力/宗门戒律 debuff | P2：阵营道德 |
| **时间线** | 无公元/纪元 | 事件无法排序 | 增加「纪年表」：古魔入侵、虚天殿周期等 | P1：历史叙事锚点 |
| **境界名不一致** | 模组引气/聚气/凝元 vs 汇编炼气/筑基/结丹 | 玩家困惑 | 对照表或逐步改名 | P0：文档与 UI 一致 |

## 二、历史空白

| 空白 | 可扩充内容 | 价值 |
|---|---|---|
| **古魔入侵人界** | 何时、何地、谁封印、为何化神上限跌落 | 坠魔谷、昆吾山、魔化装备来源 |
| **上古修士文明** | 石灵傀儡、古修洞府、血色禁地主人 | 低阶秘境背景叙事 |
| **慕兰 vs 突兀** | 千年战争梗概、圣禽 vs 天澜兽 | 法士/双阵营任务线 |
| **乱星海星宫史** | 星宫与逆星盟分裂原因 | 声望与黑市玩法 |
| **大晋世家与真灵** | 陇家等真灵世家起源 | 血脉、联姻任务 |
| **灵界人妖弱势** | 为何西北角、如何进天渊城 | 飞升后新手引导 |
| **千竹教与大衍神君** | 傀儡术传承断代 | 大衍诀任务链 |
| **魔界始祖自爆** | 魔金山脉形成 | 动态地形副本 |

**扩充方向 A：纪年表（Chronicle）**  
- 产出：`docs/CHRONICLE.md` + 游戏内 Patchouli「纪年」章。  
- **价值**：所有地区/势力/秘境可挂「发生于何纪元」，减少设定漂移。

**扩充方向 B：神话层（Mythic Layer）**  
- 真灵、道祖、开天残片（广寒界）。  
- **价值**：终局 Boss 与血脉线不突兀。
