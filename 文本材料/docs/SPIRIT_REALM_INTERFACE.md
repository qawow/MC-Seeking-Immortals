# 灵界与人界接口

> 汇编 **五界分立**、**飞升链**、**天渊城**、**分身下界** 的模组化说明。

## 三界递进

```
人界（化神顶）—[渡劫飞升]→ 天渊城 —[功勋门]→ 灵界风元 —[大乘渡劫]→ 仙界
```

数据：`spirit_realm_interface.json`

## 天渊城职能

- 飞升者**首站**登记与分配任务  
- **人妖两族**共守魔族前线  
- 修炼速度 **×2**（相对普通人界）  
- **元合五极山**级护城阵（传奇）  
- 坊市、功勋殿、灵界传送门

## 商贸

`trade_routes.json` 定义：

- 天南内部、天南↔乱星海、乱星海↔大晋、大晋↔天渊、天渊↔风元  
- 慕兰—天澜灰市、冥河渡船  
- 四大拍卖枢纽（含万宝大会 `cycle_treasure_fair`）

## 店铺

`merchant_shops.json`：贡献堂、岛税杂货、逆星黑市、万宝阁、冥河渡夫、天渊功勋殿、风元拍卖等。
