## 本弧线内容

韩立**筑基后的千竹教遭遇与正式入门段**：

1. **墨蛟炼器**（第 228 章）：韩立在天星宗坊市将墨蛟材料委托徐店主炼器，半个月后得**神风舟**（墨蛟蛟鳍与尾部，速度罕见的飞行法器）与**青火瘴**（两颗蛟目炼制的顶阶法器，青红双色圆球，云团掩身兼带墨蛟丹液剧毒）。
2. **千竹教傀儡大战**（第 228–231 章）：返程途中神风舟被机关兽光柱误伤，韩立以青火瘴藏身云中，目睹千竹教护教法王黄龙以近百傀儡（机关兽五色光柱、弓箭人偶五色光箭、近战重甲傀儡刀枪皆低中阶法器、高五六丈巨型傀儡虎全力一击耗中阶灵石一颗）猎杀尾随的元武国数家门派修士。
3. **林师兄与大衍诀**（第 231–234 章）：竞卖会上买走傀儡机关兽的魁梧男子即千竹教黄龙；林师兄（前教主独子，诈死藏身黄枫谷）现身诱韩立修《大衍诀》（千竹教开派祖师独创、专强神识与分神之术、傀儡必修；正本 vs 简化版；三层以上仅教主与继承人可修；教内有“修至高层更易结丹”的秘密流言）。韩立以颠倒五行阵困死林师兄并灭其元神（元神出体/夺舍设定：唯元婴期后方可元神瞬间离体，夺舍极伤元神须闭关个把月）。
4. **雷万鹤解围与古方交换**（第 233–236 章）：黄枫谷结丹期雷属性修士雷万鹤银光术灭黄龙解围；韩立请其进洞府（以颠倒五行阵禁断神识变化护住储藏室与灵眼之泉），以两株六七百年灵草换得**聚灵丹**、**炼气散**两张古方，并自林师兄遗物得大衍诀与**傀儡真解**（详尽傀儡制作大全）。结丹之难与结丹修士渴求灵药、古方与丹方秘传、洞府储藏室结界保药性等设定一并发掘。
5. **绿波洞正式收徒**（第 237–240 章）：韩立赴太岳山脉东部绿波洞参见李化元；因天地灵药救了师娘性命获正式收徒补偿。李化元讲解**功法三分类**（第一类威力大精进慢、第二类精进快无自保、第三类顶阶兼二者之长但危险重重），韩立选第二类，最终选定金色书页所载**凝元功**（附带聚灵术；金色书页与手中银色书页式样大小一模一样，埋下伏笔）。同批还录有李化元藏书室中的归元功（归元灵甲）、幻灵决（幻影分身）与李化元所修顶阶真阳决。
