# 多方块结构描述扩充 v131

> 无代码。在原有 `block_items_catalog.json` 基础上，将全部方块条目从短词条扩充为完整结构描述。

## 每个结构现在包含

| 字段 | 说明 |
|------|------|
| `dimensions` | 占地尺寸（宽×深×高） |
| `footprint` | 底座占用 |
| `core_blocks` | 核心组成方块列表 |
| `optional_blocks` | 可选扩展方块 |
| `visual_style` | 原著级外观描述（材质、颜色、纹路、光效） |
| `functional_notes` | 详细功能说明（门槛、消耗、限制、交互） |
| `novel_anchor` | 原著/剧情锚点 |
| `placement_hint` | 放置建议 |
