# 冥河 · 阴冥 · 坠魔谷

> `region_cards/nether_river.json` · `yinming.json` · `fallen_demon_valley.json`  
> 秘境：`secret_realms.json`

## 冥河之地

- 阴灵气为主，鬼修势力与冥河巡卫
- **冥河屏蔽区**：可**延缓天劫**（`tribulation_items`）
- 秘境三层，掉落阴材、鬼修残卷

## 阴冥之地

- 极阴苦寒，滞留损寿；炼气~筑基支线
- 与 `D2_ghost_cultivator_rise` 纪年相关
- 出口裂隙需阴功法或特制符

## 坠魔谷

- **元婴**门槛，魔气与空间裂缝并存
- 古魔投影 BOSS，魔化装备掉落
- 渡劫：**煞气/魔功**可能 **加雷**（`demon_qi_penalty`）
