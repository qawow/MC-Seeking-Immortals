# 炼丹系统设计

> 汇编 §6 + 知识库：**炉 + 盖 + 火**，**高火低炉爆炸**，**配方书**（玉简/丹方），**修为**决定可用灵草档与控火。

## 核心规则

1. 三件齐全方可开炉：`alchemy_system.json` → `components`。  
2. **错配**：`flame_grade > furnace_grade` → 炸炉 + 高伤（可毁炉）。  
3. 配方：`alchemy_recipes.json`，缺配方不可炼（可偷学/任务解锁）。  
4. 筑基丹等 **controlled** 丹：宗门贡献兑换为主，野配方成功率低。

## 与地区/任务

| 来源 | 内容 |
|---|---|
| 黄枫谷 | 地火室（grade 4 火）、筑基丹配额 |
| 血色禁地 | `ancient_herb` 材料 |
| 冥河 | 阴材聚魂丹 |
| 乱星海星宫 | 高阶丹方功勋 |

## 模组实现提示

- 炸炉用粒子 + 掉落损毁炉盖  
- 成功率 = `base_success_rate` × 炉阶匹配 × 炼丹技能  
- 勿把汇编具体物价写死进配方成本，用 `economy_reference_magnitudes` 调档
