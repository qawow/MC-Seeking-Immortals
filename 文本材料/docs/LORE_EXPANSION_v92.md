## 原著向结构摘要

### 丹药
- **突破类**：筑基丹、降尘丹、定灵丹/九曲灵参丹、造化丹、培婴丹、虚灵丹、魔元丹…
- **战斗类**：回煞丸（损元气）、各类疗伤/回灵
- **品质**：下/中/上/极品影响药效与炼成率

### 灵药
- 筑基：**玉髓芝、紫猴花、天灵果、千年灵草**
- 结婴：**九曲灵参 + 玛瑙角 + 千叶露**
- 特殊：**灵烛果→造化丹**、**阴芝马→培婴丹**、**寒髓+太阳精火→回阳真水**

### 法宝层级
法器 → 法宝（本命）→ 古宝 → **通天灵宝（通宝诀）** → 玄天/残宝

### 符箓
黄/玄/地/天 × 下中上；天符门主高阶；降灵符可用妖魂炼

### 经济
- 人界：灵石四级（1:100 结构比）
- 天南边功、天渊功勋为平行货币
- 大晋同物约 1.3× 价、供给更足

## 使用建议
1. 与本地 **v90 全量** 合并时：物品表以 **v92 为准新增**，旧 id 冲突则人工对照。  
2. 数值调优先动 `item_economy_index_v92.json` 的 balance_knobs。  
3. 具名剧情物（虚天鼎、八灵尺）建议绑定任务，不进普通刷新。
