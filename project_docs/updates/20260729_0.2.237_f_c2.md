# `0.2.237` F-C2 储物手镯与功法树交互收口

## 变更

- `StorageBraceletMenu.stillValid()` 在客户端允许同一支持物品的 NBT 栈实例替换，避免同步重建导致预测界面关闭。
- 服务端仍要求菜单打开时绑定的原始 `ItemStack` 身份，并通过连续所有权、境界、完整性和存储类型校验。
- `MethodTreeScreen` 节点按下只记录候选和布局基线；超过 4px 才开始拖动，松手才提交选择和布局。
- 功法图重叠命中按最后绘制节点倒序命中；Esc、其他按键和关屏会幂等冲刷实际布局变化。
- 零位移点击不发送布局包，切换流派时详情滚动归零。
