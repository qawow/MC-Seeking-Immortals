# 0.2.60 拍卖 settle 幂等与剩余交付 outbox

## 本批完成

### 拍卖 settle claim-before-deliver
- `AuctionSoftService.settle` 先 `markSettled` + 写 `WON_ROOT`，再 `giveOrEnqueue` 主奖与 extra。
- 玩家 `already_won` 时同步愈合 house settled 标志，不重复发奖。
- 显式 `reward_item` 解析失败 fail-closed（不再模糊回退灵石），防止错误交付。
- 交付 reason 带 lot id：`auction_win:<lot>` / `auction_win_extra:<lot>`。

### 剩余 giveOrDrop 路径
- 目录消耗品礼包：`catalog_consumable` → outbox。
- 储物取出：`storage_withdraw` → outbox。
- 制符/傀儡制作退料：`talisman_craft_refund` / `puppet_craft_refund` → outbox。
- 直接 world-drop 仅保留在 `InventoryDeliveryService.giveOrDrop` 与 outbox 成功交付内部。
