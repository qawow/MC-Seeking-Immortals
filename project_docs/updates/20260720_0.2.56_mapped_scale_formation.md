# 0.2.56 mapped 法宝主动技 powerScale 与阵法映射

## 本批完成

### mapped 法宝主动技 powerScale
- `SkillContext` 增加 `powerScale`（默认 1.0）。
- `ArtifactActiveSkillService.tryCast` 写入 context，并通过 `SpellEffect.pushPowerScale/clearPowerScale` ThreadLocal 覆盖全部 `calculateDamage` 调用点。
- 普通术法释放不受影响（默认倍率 1.0）。

### 阵法自由场映射
- `CraftWorldSoftService` 扩展 seal/kill/nine_palace/blueprint/teleport 等别名，并增加关键词回退（聚灵/杀阵/封印/迷踪/防御）。
- 未知阵法仍可部署为 free field，但更多 id 不再落入弱 `CATALOG_GENERIC`。
- 材料型 inspect_only 盘/旗保持 inspect_only，不凭空增加消耗效果。
