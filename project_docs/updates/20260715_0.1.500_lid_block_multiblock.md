# 0.1.500 Wave500 — lid-block multiblock rework

Date: 2026-07-15

## Goal

Re-implement furnace multiblock rules per user request:

1. Low-tier furnaces do **not** need array nodes.
2. Alchemy lids become **placeable blocks** and are part of the multiblock.

## Rules now

| Furnace tier | Required structure |
|---|---|
| T1–T2 | Top lid only `(0,1,0)` |
| T3 | Top lid + radius-2 outer ring of array nodes (legacy array still OK) |
| T4–T5 | T3 + magma under controller |

## Changes

- Added `AlchemyLidBlock` and registered 5 lid blocks
- Lid items are now `BlockItem`s of those blocks
- `AlchemyFurnaceShellStructure`:
  - always requires lid above controller
  - removes cardinal array requirement for T1/T2
- BE:
  - `lidTier` read from world lid block
  - hand-using a lid places/replaces the top block
  - GUI lid slot disabled
  - fire/formula remain GUI-slot authority
- Resources: blockstates/models/textures/loot/tags/lang for lids
- Tests updated for new offset counts (T1=1, T3=17, T4=18)
