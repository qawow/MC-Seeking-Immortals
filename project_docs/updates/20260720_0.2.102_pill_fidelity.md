# 0.2.102 丹药分条效果差异

## 摘要

把仍落在同质 `cultivation_progress` 的命名丹药与境界辅修丹拆成可区分运行时 effect：
- 命名丹：`jade_spirit_tonic` / `yuan_gathering` / `dragon_tiger_temper` / `spirit_gather_tonic` /
  `dustfall_calm` / `yin_yang_balance` / `spirit_seed_growth` / `star_sea_voyage` /
  `sect_spirit_tonic` / `merit_tonic`
- 通称辅修：`cultivation_aid_*` → `realm_cultivation_aid`（本境最高，低境部分，跨阶过高无效）

## 变更

- `PillEffectCatalog.resolveGenericEffect` 扩展 id 映射
- 新增 11 个 apply* 方法
- 双语 tooltip 11 条
- `PillEffectCatalogTest` 覆盖命名解析与 leftovers 上限

- 协议 26 不变
