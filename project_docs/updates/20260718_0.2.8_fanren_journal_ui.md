# 0.2.8 凡人问道录 · 全前端 UI 克制重设计

日期：2026-07-18

## 目标

从已提交 `0.2.7` 基线干净重做前端视觉，统一为 **克制问道录**：旧纸 / 玉简 / 青铜框 / 朱砂印；暗绿墨底 + 纸色正文；低辉光，无霓虹灵气特效。范围覆盖全部 Screen / Overlay 共享皮肤与遗留屏外壳迁移，不改玩法权威与网络协议。

## 变更摘要

### 皮肤层（ImmortalUiSkin）

- 新增真实 32×32 可平铺资源：`paper_texture.png`、`jade_texture.png`（低对比、低 alpha）。
- `drawLayeredPanel` / `drawInnerFrame` 叠纸纹；`drawTitleBar` 顶 1px 纸色 sheen（alpha ≤ 0x22）。
- 状态条 `drawStatusStripChrome` 与吐纳 `drawBreathingTablet` 叠玉纹；朱砂侧条 + 小印保留。
- 命名 HUD 槽位 token（`HUD_SLOT_FILLED_SOLID` / `HUD_SLOT_EMPTY_SOLID` 等），去掉散落 bare hex。
- 新增 `drawTiledTexture` / `drawPaperFill` / `drawJadeFill`。
- Tab hover 底线、主按钮朱砂侧条、次按钮 hover 基线微调。

### 遗留屏迁入 AbstractJournal*

| 屏幕 | 基类 | 契约保留 |
| --- | --- | --- |
| MethodTreeScreen | AbstractJournalScreen | 图拖拽 / 双滚动 / Layout 公共 API |
| ShopScreen | AbstractJournalScreen | 购买/刷新包与 Layout |
| AuctionScreen | AbstractJournalScreen | 列表滚动与 Layout |
| SectScreen | AbstractJournalScreen | 动态标题 / 摘要 / Layout |
| StorageBraceletScreen | AbstractJournalScreen | 预览滚动 / Layout |
| StorageBraceletScreenMenu | AbstractJournalContainerScreen | 槽位框 / 背包标签 |

双栏屏（MethodTree / Shop / Auction / Sect）`innerFrame=null`，在 content 内自绘分区框，避免双层 chrome。

### 入口

- 背包「修仙」按钮改为 `ImmortalButton.secondary`，与 journal 控件一致。

### 明确未改

- `network/*` 字段/顺序未动；`ModNetwork.PROTOCOL_VERSION` 保持 **24**。
- 服务端玩法结算、C2S 意图包语义不变。
- `ImmortalHudLayout` 几何不变（左上状态条 + 左中技能轨 + 底吐纳）。

## 版本与协议

- `mod_version`：`0.2.7` → **`0.2.8`**
- `PROTOCOL_VERSION`：**保持 24**

## 剩余风险

- 技能图标仍大量占位贴图，未本轮重绘。
- 纸/玉纹在 GUI Scale 3 下可能略糊，已用小尺寸平铺 + 低 alpha 控制。
- 部分 Screen 仍保留局部 `record UiRect/Rect`（测试契约），通过 FQCN/`toUi` 桥接到包级 `UiRect`。
