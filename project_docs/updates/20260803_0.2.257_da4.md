# 0.2.257 D-A-4 call_guard / combat_flag / combat_or_arrest 分型（D-A 收口）

## 更新内容

D-A 四个补丁批收口：三个此前共用 generic hostile shell 的执法/战斗动作建立各自专用语义与失败路径：

- `callGuard`：不再生成攻击玩家的 hostile shell，改为在玩家身旁召唤**归属玩家**的守卫 servitor（`configure(player,...)` + `setStance(Stance.GUARD)`，守点并反击威胁、保护玩家）；按势力/执法权威分派 archetype；每势力上限 `MAX_GUARDS_PER_FACTION=1`（防刷守卫），生命 `GUARD_LIFE_TICKS=20min`。
- `combatFlag`：保持 D-A-1 语义——只写敌对后果账本 + 声望/favor 惩罚 + 标记，绝不生成实体。
- `combatOrArrest`：按 `suspectLevel`（D-A-3）分派——
  - `0 clear` → 警告（`warnPlayer`：favor/声望轻微惩罚，不生成实体）；若该权威已有 combat_flag 则走战斗。
  - `1 warn` → 缴罚（`finePlayer`：扣贡献或灵石 + 声望惩罚，清空疑点）。
  - `2 arrest` → 逮捕（`arrestPlayer`：写 `ARRESTS_TAG` 持久标记〔Authority/At/Dimension/RecoverX/Y/Z〕+ 召唤看守守卫 + 清疑点）。
- 逮捕解除：新增 `settleArrest`——传送回可恢复落点（Recover 坐标）并清除标记；`isArrested` 查询；已逮捕再触发返回 `already_arrested` 提示。
- 新增常量 `ARRESTS_TAG` 并纳入死亡/克隆复制；守卫标记 `GUARD_MARKER`。
- 新双语 lang：guard_called/warned/fined/arrested/already_arrested/arrest_released。
- `DialogueActionCoverageTest` 新增 D-A-4 契约断言（守卫 owner 绑定+GUARD 姿态、suspectLevel 驱动 4 分支、arrest 持久标记+Recover+teleport 释放）。
