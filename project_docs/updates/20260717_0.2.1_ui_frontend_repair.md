# 2026-07-17 0.2.1 前端 UI 修复

## 变更摘要

修复 0.2.0 合并后任务、对话、图鉴百科、HUD、世界包与修炼属性页的 P0/P1 前端问题，并收紧所有相关客户端意图的服务端边界。

## 实现

- 任务追踪同步只更新缓存或刷新已打开页面；J 键先开页再请求同步。页面按 `selectedChainId` 保持和切换操作目标。
- 登录、重生、换维统一同步修炼、术法、技能、功法、布局、宗门、世界、任务和百科镜像；世界快照不再输出摘要聊天。
- `OpenDialogueScreenPacket` 改为服务端裁剪的 bounded View：context、来源/NPC/节点、speaker、16 行正文和 8 个选项。
- NPC 与文本任务会话使用随机 nonce、已签发 choice allowlist、起始维度和 8 格距离校验；refresh 不重复事件、奖励、好感或 effect。
- 普通选择只能进入 `current.next` 且重新校验条件；带台词 root 不再跳过，`default` 只作为单独 fallback。
- `open_shop` 延迟为已校验选项；执行前清 session，打开市场后不再发送对话 Screen。
- Bestiary/Chronicle/Compendium 使用实际窗口响应式布局；窄屏上下分栏，百科六控件支持 6x1、3x2、2x3，长行按视觉行换行滚动。
- lore 同步容量调整为 bestiary 4096、chronicle 256、timeline 128；负数/超限 decode 立即拒绝，当前 1,894 条图鉴完整往返。
- HUD 在宽度 `<300` 使用 rail 布局；世界包按 snapshot revision 重建按钮并按接收时间递减事件/冷却；身法滑块键盘固定 5% 步进并去重 C2S。

- 修正测试为完整当前目录往返并覆盖旧 512 上限后，`./gradlew build`：**BUILD SUCCESSFUL** in 54s，558 tests 全部通过。
- `git diff --check`：通过。

## 版本与协议

- `mod_version`：`0.2.0` -> `0.2.1`。
- `ModNetwork.PROTOCOL_VERSION`：`23` -> `24`。
- 原因：`OpenDialogueScreenPacket` 的字段与编码从单一 chain id 改为 bounded dynamic View；旧客户端无法兼容解码。

# 审查修复批次（0.2.2 / protocol 24）

## 变更摘要

在 0.2.1 首轮前端修复之上，补齐审查发现的权威/布局残留风险；因首轮已成功写入 preflight fingerprint，本批按门禁升至 0.2.2，不改 wire。

## 实现

1. **Clone PersistentData**
   - `TextQuestChainService` / `TimelineChronicleService` / `ChronicleTradeSoftService` / `BestiaryUnlockService` / `NamedNpcRewardService` / `NpcFavorService` / `NpcDialogueFlags` 增加 `copyPersistentData`。
   - `ModEvents.onPlayerClone` 统一调用；临时对话 session 标签故意不复制。

2. **Worldpack 只读镜像**
   - `WorldpackGameplayService.syncSnapshot` 改为 `WorldpackSavedData.get` + `peekRegionId` + `peekDailyEvent`。
   - 生命周期同步不再 `prepareSavedData` / 创建锚点平台 / `refreshDailyEvent`。

3. **对话条件 fail-closed**
   - `equals:false` 反转 `has_item`/`has_token`/`has_stones`。
   - 布尔 `has_token:false`、字符串持有检查、`array_state`、`window_open`、`need_permit` 真实求值。
   - 未知 op 默认 `false`。

4. **幂等 / terminal / nonce**
   - 节点 claim key = `tree:node`；仅有效果的节点执行 immediate effects、发奖、加 favor。
   - terminal effect（teleport/travel/enter_instance/open_shop/deny/end 等）清 session，不 `sendView`。
   - present/refresh 在写 choice 与发送前双重校验 session context，防止晚到 View 盖回已关闭页。

5. **窄屏图鉴布局**
   - Bestiary/Chronicle/Compendium 引入 `MIN_BODY_LINE=10`，chrome 不够时压缩 filter/tab/footer/title。
   - stacked 模式保证 list+detail 各至少一行；compendium viewport 至少一行。
