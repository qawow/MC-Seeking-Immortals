# 0.2.179 功能审计修复

## 范围

- 补齐四个已注册结构兼容载体的物品模型与双语名称。
- 用显式服务端策略执行 19 个秘境的作者开启条件。
- 实现每日事件奖励、玩家任务 hook、战争阶段和燃魂风险的生产闭环。

## 关键行为

- 血色禁地按作者任务资料的 5 年周期、虚天殿按 300 年周期计算；窗口分别使用运行时资料中的 `[10,30]` 与 `[15,60]`。昆吾/广寒没有作者数值周期，因此只接受任务/纪事旗标，不回退任意 30 日周期。
- 虚天钥残片由 `cycle_gate` 的 `SpatialNodeRequiresService` 事务原子预扣，入口失败时退款；秘境开启策略不在预扣后重复检查背包，避免合法入口被永久拒绝。
- 每日遭遇实体写入 owner UUID、region、event 和 until。只有归属玩家或其受控单位造成的已提交击杀可以结算战斗奖励。
- 非战斗奖励由 `/seeking_immortals worldpack daily_events claim` 领取。领取与击杀共用 `(region,event,until)` 幂等键；奖励先完整解析，未知 token 不写 claim，满背包进入 `DeliveryOutboxSavedData`。
- 随机法宝只从已注册、无剧情绑定、符合档位的法宝中选择。`merit_points`、战勋、符纸捆、阵芯碎片、伐尸术残篇、克伐尸符和下品灵石均映射现有 carrier。
- 每日 `quest_hook` 与 `faction_trigger` 获得玩家上下文和独立 roll 账本；只启动精确映射链，已开始任务只在当前 authored step hook 匹配时推进。未知 hook 不再回退黄枫谷主线。
- `war_phase` 在奖励结算中读取校验；`soul_burn_risk_tag` 在护阵供灵期间施加弱化并有小概率损耗灵力。
- 非战斗领取先刷新当前地域与当前 roll，避免跨地域后同一 tick 使用旧事件和新地域组成可重放领取键。
