# 0.2.256 D-A-3 suspicion 时间衰减与 anomaly 势力分桶

## 更新内容

延续 D-A 分型，为 `add_suspicion` 与 `anomaly_log` 建立分桶、衰减和结算点，消除"clamp 到 100 后无衰减"与"散落按原始节点 id 记录"的过度泛化：

- `SUSPICION_TAG` 条目结构改为含 `Value` + `LastAt`（上次更新时间戳）的 CompoundTag；读取时按 `SUSPICION_DECAY_PER_HOUR`（每小时 -12）衰减，作为惰性结算点；写回时记录 `LastAt`。
- `addSuspicion`：先按 LastAt 衰减旧值 → 加 amount → clamp [0,100] → 写回；返回新值。
- `suspicion(player, authorityId)`：只读衰减到现在的值。
- 新增 `suspectLevel(player, authorityId)`：0=clear / 1=warn+缴罚区间 / 2=arrest 区间（`WARN_SUSPICION_THRESHOLD=30`、`ARREST_SUSPICION_THRESHOLD=60`，公开常量，供 D-A-4 `combatOrArrest` 消费）。
- `recordAnomaly`：按执法权威（NPC/势力）优先分桶（键=npcId，回退 tree:node），同一势力的异常见闻收敛到同一桶；条目延续 At/Npc/Node 来源与年龄淘汰。
- 新增 `decayedSuspicion` 私有纯函数（含时间换算，纯逻辑可测）。
- `DialogueActionCoverageTest` 新增契约断言：suspicion 携带 LastAt、定义 warn/arrest 阈值、暴露 suspectLevel、anomaly 按 NPC/势力分桶。
