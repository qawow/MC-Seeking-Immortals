# 2026-06-30 0.1.65

## Summary

- Removed explicit mod-side caps from realm-derived vanilla combat attribute application.
- Max health, attack damage, armor, armor toughness, knockback resistance, and movement speed now use the full realm-derived values when refreshed onto player attributes.
- Kept non-negative additive guards and the vanilla 20 health-point floor for max health.

## Version and protocol

- `mod_version`: `0.1.65`
- `ModNetwork.PROTOCOL_VERSION`: unchanged at `5`
- Packet fields/order/encoding: unchanged

## Verification

- `.\gradlew.bat --no-daemon --max-workers=1 build` passed, `BUILD SUCCESSFUL in 36s`

## Risk

- Very large uncapped attributes can affect balance, UI display, and compatibility with vanilla or other mods that assume normal attribute ranges.
