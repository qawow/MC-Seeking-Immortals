# 0.2.98 高阶炼器阵与传送令

## 摘要

补齐炼器配方 `forge_grade` 4/5/6 对应的多方块工站：注册 `refinement_forge_g4/g5/g6` 方块与专用结构校验，结构目录/station_patterns 扩至 92，材料 sample 覆盖 g2/g4–g6 与 alchemy g4/g5。`teleport_array_ticket` 成为可执行消耗品，右键经 `FlightVehicleService.board` 登船。语料 effect type `aoe_control`/`shield` 纳入 generic resolver，不再静默 fail-closed。

## 变更

### 高阶炼器阵
- `RefinementForgeHighStructure`：环半径 `grade-1`（G4:3 / G5:4 / G6:5），角柱高度与口部净空随 grade 扩展。
- `RefinementForgeHighBlock`：潜行右键校验 → ensureCommissioned → `RefinementForgeCraftHelper.tryCraft(grade)`。
- `ModBlocks` / `ModItems` / `ModCreativeTabs` 注册 g4–g6。
- `MultiblockStationService` 增加 dedicated validator，禁止落入默认 spirit-ore ring 假成型。
- 资源：blockstate/model/texture/loot/lang；pickaxe mineable 标签。

### 结构目录
- `multiblock_structure_index.json` / `multiblock_station_patterns.json`：92 条目，补 `refinement_forge_g2/g4/g5/g6`、`alchemy_furnace_g4/g5`。
- `block_items_catalog.json` 补 forge_grade 2/4/5/6。
- `multiblock_material_prices_v135.json` 扩展 used_by_sample。

### 传送阵令牌
- `BulkItemClassifier` EXECUTABLE + effect `board_teleport_array`。
- `CatalogConsumableService` 调用 `FlightVehicleService.board(player, "teleport_array_ticket")`（燃料走 binding 的 spirit_stone_shard×5）。
- 双语 detail/effect tooltip 更新。

### 术法语料
- `AbstractTechniqueEffectResolver`：`aoe_control` → 区域法；`shield` → buff 族。
