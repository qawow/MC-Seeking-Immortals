## 玩法影响

玩家现在可以右键使用以下物品并获得对应效果：

1. **Travel tokens** 三项：
   - 灵舟船票 → 传送乱星海区域
   - 乱星海传送符 → 传送乱星海区域
   - （冥河渡票已在 0.2.107 接线，本批无涉及）

2. **Lore discovery** 三项：
   - 虚天殿残图 → 解锁虚天殿见闻
   - 坠魔谷探报 → 解锁坠魔谷见闻
   - 昆吾山舆图 → 解锁昆吾山见闻

3. **Quest/faction tokens** 两项：
   - 拍卖请柬 → 打开拍卖邀请界面
   - 星宫巡防令 → 星宫巡防任务效果
   - 宗门令牌 → 显示宗门身份
