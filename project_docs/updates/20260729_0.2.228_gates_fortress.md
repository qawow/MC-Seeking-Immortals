# 0.2.228 施法城墙与门扉独立轮廓

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.227` 升至 `0.2.228`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- `technique_1241`：高大城墙与建筑分段落下，幻化成小型要塞。
- `technique_944`：土墙从地下连续冒出，百里巨墙拔地而起。
- `technique_1478`：黑色双门从屏风飞出，向两侧分开并露出长通道。
- `technique_297`：青光石壁显出两丈石门。
- `technique_468`：蓝霞触及石门后门体分成两半向内开启，后续寒风与寒冰保持独立层。
- `technique_611`：玉佩消去殿门白光，以及青光令石门符文飘动后开启。
- `technique_838`：黑蓝巨网罩住广场后显出高大白色光门。
- 被击穿、切碎、穿越或仅作背景/目标的门墙不命中：`technique_107/177/198/503/582/585/847/974/1224`。

## 编译与运行时

- 新增 `FORTRESS_WALL` 层内 primitive。几何包含前后墙基、分段立面、城垛、墙顶纵线与加高角楼，主动落下和拔地上升共享同一可辨识城防轮廓。
- 新增 `MAGIC_GATE` 层内 primitive。几何包含门槛、左右门柱、门楣、分开的双门板、门内光环，以及向后延伸的通道边框。
- 两者接入 `VisualPrimitive`、复杂轮廓最低预算和 `emitFigurePrimitive`；契约固定的 52-shape authored switch 未改。
- 精确引文规则替代通用 `array_rings`、`beam_lance`、`sound_wave` 或 `projectile_swarm`，不会按裸词“门”“墙”扩大命中。
- 虚灵殿寒风中的“无数猛兽同时大吼”不再误生 20 份弹群，保留 `ice_prison` 与 `ground_field`。

## 数量、路径、动作与配色

- 小型要塞为单份 `FALL/MATERIALIZE`、`earth→metal`；百里石墙为单份 `RISE/STEADY`、`earth→metal`。墙体分段由几何表达，不用重复副本堆叠。
- 屏风黑门为单份 `DIRECT/STEADY`、`yin→qi`；隐匿石门为单份 `STATIC/MATERIALIZE`、`earth→qi`。
- 虚灵殿石门为单份 `STATIC/STEADY`、`earth→water`；青冥佩两次开门均为单份 `STATIC/STEADY`、`water→qi`，符文伴随层继续存在。
- 白色光门为单份 `STATIC/MATERIALIZE` qi；同句黑蓝巨网保留单份 `chain_net` 与 `yin→water`。
