# 0.2.109 结构修复台与蓝图台可右键

日期：2026-07-20  
`mod_version`：`0.2.109`  
`ModNetwork.PROTOCOL_VERSION`：`26`（无包变更）

## 变更

1. 新增 `StructureToolService`：
   - `structure_repair_bench` 右键诊断附近成型工站；潜行右键修理或启封。
   - `structure_blueprint_table` 右键显示建造序列/工站列表；潜行右键启封。
2. `BaseMaterialItem.use` 在阵法物品分发后调用结构工具。
3. 两项 meta 工具不再被 `isStructureTokenCarrier` 标为“仅凭证”，并补双语 tooltip/detail。
