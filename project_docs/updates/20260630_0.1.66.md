# 2026-06-30 0.1.66

## Summary

- Added a Forge Access Transformer for `RangedAttribute.maxValue`.
- Added startup logic that raises vanilla maximum ranges for max health, attack damage, armor, armor toughness, knockback resistance, and movement speed.
- This complements `0.1.65`: mod-side caps are gone, and vanilla attribute ranges are now raised so high realm values can actually take effect.

## Version and protocol

- `mod_version`: `0.1.66`
- `ModNetwork.PROTOCOL_VERSION`: unchanged at `5`
- Packet fields/order/encoding: unchanged

## Verification

- `./gradlew --no-daemon --max-workers=1 build` passed, `BUILD SUCCESSFUL in 1m 16s`

## Risk

- The attribute maximum is raised to a very large value, so extreme realm stats may affect balance, UI display, movement feel, and compatibility with mods that expect vanilla-scale attributes.
