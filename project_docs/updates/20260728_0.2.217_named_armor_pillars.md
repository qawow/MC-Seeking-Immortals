# 0.2.217 锣、面具、织物、符柱与战甲轮廓

## 变更类别

代码、生成资源、测试与文档。继续使用 Lodestone `1.20.1-1.6.4.1`，不新增前置库，不改变网络协议。

## 原文边界

- `magic_gong` 只接入被众修士注视的黑色巨锣；不把“鼓起/凸鼓”误作鼓锣。
- `magic_mask` 只接入翻掌出现并戴上的青色面具；不接入被攻击者既有的野猪面具或气团鬼面。
- `magic_cloth` 接入四方锦帕、符文还原锦帕、包身黑纱和驱动遁逃的血色披风；普通面纱、透明斗篷受击和穿戴叙述不映射。
- `rune_pillar` 接入成形的水晶柱、108 根青铜柱、七根困龙金柱、幻阵石柱林和光柱所化带灵环石柱；“擎天巨柱般的手指”明确排除。
- `spirit_armor` 接入由鳞片、血雾、符文、灵虫或护体光显形的七件战甲；已穿戴、受损或被摧毁的静态战甲不重复生成。

## 运行时几何

- 巨锣由悬架、外缘、内面、中央锣心和侧置锣槌构成。
- 面具由正面轮廓、双眼缝、额心竖印、双颊和收尖下颌构成。
- 织物使用受时间驱动的前后波形，绘制四边、横向经纬、中央折痕和封印星点。
- 符柱绘制高柱轴、双侧棱、柱础/柱头环、中段反旋符环和顶端星点；多柱通过 `EXPAND`/`ORBIT` 分散，不在同一点重叠。
- 战甲绘制胸甲侧缘、肩梁、双肩甲、腰封、头盔环和胸口印记。

## 数量、路径与伴随语义

- 幻阵石柱林为 20 份 `EXPAND`；108 根青铜柱按运行时上限保留 72 份 `ORBIT`；七根金柱/缠龙为 7，八头蟠龙为 8，带环石柱为 12。
- 血披风两条引文均为单份织物加单份 `afterimage_path`，消除“数千里”误读成 20 copies，并使用 `DIRECT` 路径。
- 锦帕下罩使用 `FALL`，保留 5 道金弧；符文爆裂后保留 20 份银丝网与单次爆裂。
- 虫甲保留 20 份汇聚灵虫；水晶柱保留内部黑色巨人；战甲保留符文环绕、血雾融入和金属碰撞尖鸣。
- 金柱、金龙和金色蟠龙固定 metal 局部色，不受同句黑色火焰污染；水晶柱为 water→qi，黑锣/黑纱/黑甲为 yin，黄甲为 earth。
