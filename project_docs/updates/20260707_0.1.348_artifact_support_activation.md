# 2026-07-07 0.1.348 Artifact support activation

## Change class

Code/test/docs gameplay behavior slice. No network packet fields/order/encoding/registrations, SimpleChannel compatibility, item/block/entity registries, resources, artifact/refinement JSON files, FTB files, shops, worldpack schemas, capabilities, or player NBT schema changed.

## Source basis

- Full text-material corpus scan: 315 UTF-8 files read, 207 JSON files parsed, 0 JSON errors.
- Direct basis: `text-material/data/artifacts_catalog.json` and shipped `data/seeking_immortals/artifacts/artifacts_catalog.json` entries for utility, capture, refinement, spirit-liquid, vehicle, and vehicle-key artifact families.

## Implementation

- Added first active behavior for support artifact families through the existing `ArtifactCatalogItem -> ArtifactActivationService` path.
- Utility artifacts now branch by effect text into concealment, reveal/appraisal/navigation/message, natal-growth, or fallback support buffs.
- Capture artifacts pull, damage lightly, slow, weaken, and reveal targets.
- Refinement artifacts grant fire/resistance/luck support and reduce qi-deviation risk.
- Spirit-liquid artifacts restore health, spiritual power, divine consciousness, and reduce qi-deviation risk.
- Vehicle and vehicle-key artifacts grant short travel-burst movement, jump, slow-falling, and forward impulse.
- Generic structural treasure placeholders remain unsupported.
