# 0.2.86 P1 宗门专属玩法闭环

## 本批完成

- 扩展 `sect_specialty_map.json`：补齐原先缺失的 12 个可玩宗门专精条目，使 30/30 可玩宗门均有运行时 `gameplay` 配置。
- 为每宗门配置一项互不重复的阶段功法，共 30 项；外门/筑基阶段按数据授予，宗门同步会为旧存档补授当前阶段可学功法。
- 功法授予不绕过 `ManualCatalogService` 权威：境界、灵根、种族、阵营、宗门关系、前置功法和冲突矩阵仍会阻止不合法学习。

- 宗门屏、宗门命令和服务端购买事务共用同一价格函数；不足提示与成功消息使用真实扣款，不再显示原价。
- 普通物品日常与生成式击杀/护送/驭兽/阵法日常都先叠宗门任务贡献增量，再叠世界事件倍率，并按专精授予对应生活/特殊技能实践。
- 修复宗门候选同步的旧上限：`SyncSectDataPacket` 从最多 8 项提升到 32 项，现有 30 个候选宗门可完整编码/解码。
