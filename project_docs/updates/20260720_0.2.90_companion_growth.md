# 0.2.90 P1 灵兽/傀儡成长闭环

## 本批完成

- 新增共享、无注册表依赖的 0–20 级成长公式：下一级经验为 `20 + 10×当前等级`。
- 灵兽按 `spirit_beast_growth_v99` 的作者阶段数量派生进化阈值：2 阶为 20，3 阶为 10/20，4 阶为 7/14/20。
- 育灵丹、灵兽饵、兽核、灵石碎片和召唤兽战功提供差异化经验/亲和；满级且满亲和时不消耗饲料。
- 满亲和且已卡进化阈值时，若附近没有可运行化形池会在扣料前失败，避免重复尝试浪费饲料。
- 进化阈值会保留已满经验并要求附近存在已成型、可运行的 `spirit_beast_evolution_pool`；突破后作者阶段、妖兽阶位和召唤属性同步提高。
- 旧契约只有 `Growth` 时自动迁移为同等级及其等价作者阶段，新增 `GrowthExperience` / `EvolutionStage` 不清空旧进度。
- 新增玩家持久的傀儡核心成长：7 条 `puppet_craft_recipes` 全部解析到 `puppet_definitions`；组装、命中、击杀和修理提供经验。
- 傀儡在 7/14/20 级要求可运行的 `puppet_core_forge` 完成淬炼；成长倍率和等级名称在后续召唤时应用。
- `seeking_immortals_puppet_growth` 加入死亡/End Clone durable policy，避免成长随重生丢失。
- 更新中英反馈与灵兽饵/成长丹 tooltip，明确经验、阈值工站和傀儡“下次召唤生效”语义。
