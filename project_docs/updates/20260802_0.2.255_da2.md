# 0.2.255 D-A-2 mark_structure 意图匹配 + hint 来源绑定

## 更新内容

延续 D-A-1 的分型，深化 `mark_structure` 与 `hint` 两个世界动作，消除"只看地点不看意图"与"无来源布尔账本"的过度泛化：

- `DialogueWorldActionService.markStructure`：
  - 重载新签名 `markStructure(player, structureId, authorType, authorDimension)`，保留旧签名转发。
  - **结构类型意图**：作者 effect `type` 参数非空时，要求 `StructureEntry.type` 与之匹配，不匹配拒绝并提示 `structure_type_mismatch`。
  - **维度意图**：作者 effect `dimension` 参数非空时，要求 located 维度包含预期（`structure_dimension_mismatch`）。
  - **幂等证明**：`markers` 已含该 id（`alreadyMarked`）时仅刷新位置，不再重复调用 `recordStructureFormed`，防止同一结构的重复结构化证明。
  - 保留既有"目录存在 + 世界锚点/附近成型 + `isStationFormed` + `isCommissioned`"权威校验。
- `DialogueWorldActionService.recordHint`：
  - 新签名 `recordHint(player, hintId, npcId, nodeId)`，返回**仅首次记录**为 true；提示/flag 只在首次写入，重复访问不重复记录。
  - 线索条目改为含来源的 CompoundTag（`At`/`Npc`/`Node`），替代裸布尔键。
- **淘汰策略统一为按时间**：新增 `trimOldestByAge`（hint/anomaly，按 `At`）、`trimOldestCombat`（combat 账本，按 tick 值）；删除原 `trimOldest`（字典序 `.sorted().findFirst()` 删最小键），消除"用排序删键模拟时间淘汰"。
- `recordAnomaly` / `addBoundedEntry` 改为与 hint 一致的来源+时间戳条目与年龄淘汰。
- `DetailedQuestRuntimeService` 新增公共辅助 `currentStepExpectsStructure`/`hasActiveDetailedQuest`，供对话世界动作校验"结构是否为当前任务步骤期待"。
- `DialogueActionExecutor`：`MARK_STRUCTURE` case 转发作者 `type`/`dimension` 参数；`HINT`/`CLUE` case 传入 npcId/nodeId 到 `recordHint`。
- 新双语 lang：`structure_type_mismatch`、`structure_dimension_mismatch`。
- `DialogueActionCoverageTest` 新增两组源码契约断言（意图匹配/幂等证明、hint 来源绑定/只记一次/年龄淘汰）。
