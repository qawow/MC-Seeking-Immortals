## 各项修复

### M5 — 村民兑换吞正常交易
`ModEvents.onVillagerExchange` 原在所有分支无条件 `setCanceled(true)`，导致无灵石/达上限时也吞掉 vanilla 交易 GUI。
- 改：`setCanceled` 仅移入实际兑换成功 if 内；达上限分支与 no_stones 分支放行 vanilla 交易。
- 附带修正复制错误：WATER_SPIRIT_STONE_MID 应换 WATER_SPIRIT_STONE_HIGH（曾误植为 WOOD）。

### M7 — 土遁步穿薄墙
`EarthEscapeStepSpell` 的 `canStandAt` 只查落点，可穿薄墙。
- 改：新增 `isPathClear(level, origin, target)`，沿起止点身体通道逐格检查 `getCollisionShape` 非空即阻挡；与 `canStandAt` 联合判定。

### M14 — 寿元回退值
`PlayerCultivation.load` 缺 `LifespanYears` 时回退 `Realm.QI_REFINING.getLifespanYears()`（=100），凡人玩家应得 MORTAL=80。
- 改：回退 `realm.getLifespanYears()`（按玩家当前境界，凡人=80、练气=100）。

### M16 — 三丹未用吸收率
`HealingPill`/`FastingPill`/`ClearSpiritPowder` 的 `consumePill` 只用品质倍率，未乘吸收率。
- 改：`BasePillItem.effectiveMultiplier(player)` = 品质×吸收率；HealingPill/FastingPill 用之；ClearSpiritPowder 吸收率 ≥1.2 时额外清 缓慢/虚弱/挖掘疲劳。
- 复用既有 `PlayerCultivation.getPillAbsorptionMultiplier()` 与 `BasePillItem.getPillAbsorptionMultiplier(player)`。

### M15 — 丹品质参与产物（本次最大改动）
`AlchemyRecipe` 仅单 `output`，`PillQuality` 不影响产物。
- `AlchemyRecipe`：`output(Item)` → `outputsByQuality(List<Item>)`，按 `PillQuality.ordinal()` 索引；新增 `isQualityVariable()`/`outputForQuality(quality)`；legacy 配方（cultivation_pill、qi_recovery_pill）用 `uniform(item)` 不参与品质掷骰；旧 `foundation_building_pill_low` id 仍 `findById` 兼容存档。
- 新增 6 个丹药物品：筑基丹/稳神丹 各 中/上/极品（`FoundationBuildingPill`/`CalmingPill` 既有类，传不同 `PillQuality`）。
- `AlchemyFurnaceBlockEntity.rollOutputQuality`：按成功余量 normalized×0.8 + 炼丹技能等级(≤0.20) 得 qualityScore，分段映射 LOW/MEDIUM/HIGH/SUPREME。
- `AlchemyRecipeService.getAlchemySkillBonus` 改 public 供跨包调用（H13 已落地该加成计算）。
- 资源：6 个 item model JSON（复用 low 贴图路径，无新 PNG）；zh_cn/en_us lang 各 6 键；创造栏新增 6 条目。
