## H13 — 炼丹技能加成接入
- `AlchemyRecipeService.getAlchemySkillBonus`：`CultivationHelper` 取 `PlayerCultivation`，`hasAlchemy()` 过滤，`SkillType.ALCHEMY` level ×0.02，上限 +0.20，未学=0。
- `AlchemyFurnaceBlockEntity`：新增 `craftingPlayerId` 字段（`startRecipe` 写入、NBT 持久化、`reset` 清空）；成丹成功分支调 `grantAlchemyExperience` — 若未学则 `unlockSkill(ALCHEMY)`，再 `addSkillExperience(ALCHEMY, 25)`，并 `SyncCultivationDataPacket.send` 同步。
- `PlayerCultivation.hasAlchemy()`：便捷访问器（包在 `hasSkill`/`getSkill` 旁）。

## S-EarthWall — 土墙定时消散
- 新建 `block/EarthWallBlock.java`：`extends Block`，重写 `tick(BlockState, ServerLevel, BlockPos, RandomSource)` → `level.removeBlock(pos, false)`；`REMOVAL_TICKS = 200`（10 秒）。
- `registry/ModBlocks`：注册 `EARTH_WALL`（`earth_wall`，DIRT mapColor、GRAVEL 音、不进创造栏）。
- `EarthWallSpell`：改放 `ModBlocks.EARTH_WALL` 方块，每格 `level.scheduleTick(pos, block, 200)`；消息显示消散秒数。
- 资源：`assets/.../blockstates/earth_wall.json`、`models/block/earth_wall.json`（parent `minecraft:block/cube_all`，textures 复用 `minecraft:block/dirt`，无新 PNG，无 BlockItem/item model/创造栏条目）。
