# 0.2.227 五类施法宫殿独立轮廓

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.226` 升至 `0.2.227`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- `technique_859`：九宫天乾符放出后，巨大宫殿虚影在法阵上方一闪即逝。
- `technique_962`：倚天城大殿从土中拔地腾空，底部出现五色光罩，最终化为巨型光球。
- `technique_1104`：元刹整座水殿飘出无数蓝符，化为蓝光破空退走。
- `technique_1178`：白痕扫过后，景物直接幻化为布置典雅的精美殿堂。
- `technique_1451`：幻境中的金色宫殿寸寸崩碎，连同幻象化为灰烬。
- `technique_763/423/1456/504/1103/844/1399` 的宫殿、楼阁或殿堂只是背景、被毁目标、位置或非施法叙述，均不生成 `magic_hall`。

## 编译与运行时

- 新增 `MAGIC_HALL` 层内 primitive，使用方形台基、前后四根立柱、前后横梁、双坡屋顶、正脊、四角飞檐和中央殿门构成可辨识建筑轮廓；门楣星光提供视觉中心。
- 水平朝向先投影到 XZ 平面，再以 `side.cross(forward)` 取得正 Y 竖轴；静止、上升与直线移动场景不会把屋顶或立柱倒置。
- 九宫法阵、五色光罩、巨型光球、蓝色符文、白痕和灰烬分别保留为现有 `rune_orbit`、`light_curtain`、`orb_projectile`、`channel_stream` 与 `projectile_swarm`，主体替换不删除伴随语义。
- 新 primitive 接入 `VisualPrimitive`、`minimumCopyBudget`、`emitFigurePrimitive` 与 Lodestone 几何契约；固定 52-shape switch、每层 8 粒、事件 7/16/30 和 72 copies 上限均未改变。

## 数量、路径、动作与配色

- 九宫宫殿为单份 `STATIC/DISSOLVE` qi，垂直偏移 0.72；阵纹为单份 `ORBIT/DISSOLVE` qi，偏移 0.08，形成上殿下阵。
- 倚天城大殿为单份 `RISE/STEADY`、`earth→metal`；五色光罩为单份 `RISE` qi；巨型光球为单份 `STATIC` qi，并置于上升路径中段高度。通用“万丈”数量不再把光罩复制为 10 份。
- 元刹水殿为单份 `DIRECT/DISSOLVE`、`water→qi`；20 份蓝符以水色 `SCATTER`，保留水殿化蓝光退走的连续变化。
- 化灵境殿堂为单份 `STATIC/MATERIALIZE` qi，运行半径最低提升至 3.2；一道白痕为单份 qi `DIRECT`，覆盖场景变化方向。
- 幻境金殿为单份 `STATIC/DISSOLVE`、`metal→earth`；20 份灰烬以土色 `SCATTER`，金色建筑的终态土灰渐变不会被局部颜色归一化吞掉。
