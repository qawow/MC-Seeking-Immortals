## 技术架构优化

### 1. 数据驱动术法系统
**旧**: 硬编码 SkillType → SkillEffect 映射（需手动注册747条）  
**新**: AbstractTechniqueEffectResolver 自动解析 JSON  
**优势**: 维护成本↓90%, 扩展成本↓90%

### 2. 智能成本分档系统
**旧**: 为每个功法手动配置 cultivation_costs  
**新**: 基于关键词的动态成本计算  
**优势**: 零配置，自动分档，长阶梯摊薄

### 3. 鬼道契约持久化
**旧**: 阴棺钉临时强化，无持久化  
**新**: 完整契约建立/维护/破除机制  
**优势**: 跨会话持久化，稳定度衰减，境界联动

### 4. 多方块结构专属验证
**旧**: 57% 结构使用通用 ring 验证  
**新**: 55% 结构使用专属验证  
**优势**: 结构多样化，验证精准化，错误提示友好化

### 5. 物品使用门禁系统
**旧**: 各物品类自行实现限制检查  
**新**: 统一的 ItemUsageGateService 框架  
**优势**: 标准化，可扩展，用户体验一致
