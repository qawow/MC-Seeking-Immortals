# 0.2.68 材料别名与工站效率进成功率

## 本批完成

### 材料/货币硬别名
- `ItemCatalogService` 新增多方块/经济常用 id 硬别名：
  - `spirit_stone_low/mid/high` → `low/mid/high_spirit_stone`
  - `spirit_stone` / `spirit_shard` / `low_spirit_stone_shard` → `spirit_stone_shard`
  - `jade_immortal` → `immortal_jade`
  - `xuan_iron` → `black_iron`，`iron_wood` → `ironwood`
  - 炼丹炉/炼器炉 g2/g3 映射到已注册功能方块

### 工站效率缩放成功率
- `LifeSkillService.applyStationEfficiency(rate, efficiency)`：`rate * efficiency`，钳制 0.03–0.95。
- `CraftWorldSoftService.nearbyStationEfficiency(...)`：创造模式 1.0，否则取附近工站最优运行效率。
- 制符 / 傀儡组装 / 炼器祭炼成功判定在生活技能加成后乘以工站效率：
  损坏/临界工站降低成功率，禁用（效率 0）落到下限。
