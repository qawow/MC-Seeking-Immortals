# 0.2.46 丹药语义第二阶段与交接

## 范围

- 合并 shipped 丹药效果目录与设计目录，消除运行时 `generic_cultivation`。
- 让丹药消费真实读取境界、目标、标签、元素、风险、流派和时长元数据。
- 补齐关键丹药消费者、失败语义、双语 tooltip 与一次替死持久状态。
- 收口当前小阶段，并记录物品、功法、术法和多方块后续工作。

## 已完成

- `PillEffectCatalog` 同时读取 `alchemy/pill_effect_catalog.json` 和 `text_material/pills_catalog.json`；114 条加载条目均解析为已支持效果。
- 消费门槛读取 `learn_requirements.consume.realm_min`、`realm_max` 和 `realm_target`；未知境界、境界过低/过高、非目标瓶颈和重复破境辅助均 fail-closed。
- 消费端读取 `spirit_gain_flat`、`effect_tags`、`element`、`risk`、`school`、`duration_ticks`，并接入修炼、回灵、疗伤、解毒、炼体、元素亲和、心魔、神魂、地渊、雷劫、灵兽喂养、寿元和高阶药效。
- `soul_heal`、`hp_regen`、`heart_demon_reduce`、`death_substitute_once`、`tribulation_aid`、`detox`、`diyuan_debuff_reduce` 等标签有明确消费者。
- 满灵力/神识、无可清状态、已有更强或更久效果、已固定外貌、已激活替死等无收益场景不再假成功扣丹。
- 破境丹只允许在正确瓶颈为正确目标境界建立辅助；灵兽丹统一调用 `BeastContractService.feedFromConsumable`。
- `PlayerCultivation` 持久保存一次替死并提供心魔减层；普通死亡由独立事件类消费替死，极端走火在隔离背包和强制死亡前先尝试替死。
- 寿元死亡标记在同步 `hurt()` 的完整事件链内保持有效并由 `finally` 清理；替死监听使用 LOWEST 优先级，在其他死亡取消机制之后才消费药力。
- `SPIRIT_SEVERING` 设计境界可解析为 `SOUL_TRANSFORMATION`；Bulk 丹药 tooltip 显示本地化效果、最低境界和目标境界。
- 65 个运行时效果键补齐 `zh_cn`/`en_us` tooltip。
