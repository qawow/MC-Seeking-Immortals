# 0.2.152 作者法宝视觉档案

## 变更类别

代码、资源、生成器、测试与构建校验。法宝视觉复用现有 Lodestone 事件通道，不引入第二套视觉前置库。

## 实现

- 将 v118-v122 五层作者资料确定性合并为 217 条法宝档案，逐条对齐运行时 `catalog_id`。
- 保留外观、剪影、颜色、待机/激活演出、六个基础状态和 `orbit`、`launch`、`open`、`reflect` 扩展状态。
- 将 `activation`、`material`、`utility_deferred` 分流；材料和延后工具不覆盖主动技几何，也不发认主/觉醒/修补/损坏状态演出。
- 法宝激活、祭炼成功/失败、认主、器灵觉醒、储物开启、修补以及耐久跨损坏/碎裂阈值接入一次性作者粒子/拖尾/预兆表现；既有 family/motif 几何语义保持不变。
- 新增生成器、资源加载器、运行时编排器和档案契约测试，并将档案一致性接入 Gradle `check`。
