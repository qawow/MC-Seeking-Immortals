# 0.2.139 Lodestone 高保真 VFX

## 变更

- 接入 Lodestone `1.20.1-1.6.4.1`，使用 Modrinth Maven 坐标 `maven.modrinth:lodestonelib`。
- 新增 `TechniqueVfxPacket`，以小型 S2C 事件替代逐粒子网络广播；客户端按元素族重建渐变粒子、旋转环、节点、光柱、路径、锥面和冲击环。
- `TechniqueVfxPalette` 的八类共享反馈和火球命中接入事件包；火球/飞剑客户端轨迹加入距离与粒子质量 LOD。
- `FormationFieldService` 六类阵场及通用目录阵场每 20 tick 发送真实半径视觉脉冲。
- 增加包编码限幅、客户端专属类隔离、粒子预算和阵场分支契约测试。

## 版本与协议

`mod_version=0.2.139`。新增 S2C 消息改变 `SimpleChannel` 消息表，`ModNetwork.PROTOCOL_VERSION` 从 `26` 升至 `27`。

## 验证

`./gradlew compileJava --no-daemon`、定向网络/协议/客户端隔离测试均通过。贴图批次独立提交后，最终普通 `./gradlew build --no-daemon` 已 `BUILD SUCCESSFUL in 1m 19s`，`aiPreflight` 正常记录 `mod_version=0.2.139`，未使用版本门禁跳过参数。开发客户端已加载 Lodestone、Mixin、粒子图集和模组资源后按超时停止，无崩溃；仅见 Lodestone shader uniform 警告及本机音频环境警告。专服、双客户端和真实战斗/阵法场景中的视觉密度与透明排序仍待发布前实机签字。
