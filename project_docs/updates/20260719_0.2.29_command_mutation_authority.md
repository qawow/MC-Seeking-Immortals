# 2026-07-19 0.2.29 命令、C2S 与任务账本权限

## 范围

收口普通玩家可达的调试命令、功法免费学习包、任意 Boss ID 生成、秘境伪 Boss、重复见闻推进和宗门日常重放/免成本上交。

## 实现

- 法宝炼制/本命绑定成长、文本任务推进、NPC 对话动作、目录制作部署、Boss/phase/mission 等直接变更命令统一要求 permission 2；只读查询和正常玩法入口保留。
- `MethodActionPacket` 只对 `learn:` 增加 permission 2 校验，`cultivate:` 仍按原服务端成本/层级逻辑开放；普通玩家功法树隐藏诊断学习按钮并提示通过秘籍、宗门或剧情获得功法。
- `BossEncounterService` 规范化 ID 并要求 BossLoot 或 BeastBoss 目录命中；未知字符串在任何生成路径前失败。`SecretRealmTrialService` 从 `RealmDef.bosses` 选首个已知 Boss，不再合成 `core_<realm>`。
- 已发现见闻直接幂等返回，不再重复 start/advance/quest-complete 声望；首次映射效果失败时不写发现账本，可在条件满足后重试。宗门任务同一世界日完成后也不能重接。
- 生成采集任务先验证总量再精确扣除；阵法任务接取时清除旧凭证，只有成功持久化的核心阵或自由阵部署才记录完成证据，上交时强制校验。
