# 0.2.212 钵、尺、锤具名法器轮廓

日期：2026-07-28
`mod_version`：0.2.210 → **0.2.212**；`ModNetwork.PROTOCOL_VERSION` 保持 **30**。

## 原文与缺口

- v167 的聚魂钵只有黑雾，主体退化为 `mist_veil`；v262 的碧绿圆钵与盘坐婴儿退化为残影；v426 的房屋般黑钵退化为弹群。
- v433/v435 的混元尺、银色巨尺和两道真假尺影退化为光束，并把旁边“千丈黑峰”误读为 20 份尺。
- v386 的七八丈鬼王所持八骷髅绿焰锤退化为 8 只巨爪，锤上骷髅又被拆成脱离锤体的鬼首；其余巨锤/密集锤影同样没有锤体轮廓。

## 实现

- 新增 `ritual_bowl`：开口钵沿、两侧盆身、底座、内旋内容和升腾物。黑钵、碧绿钵、银钵按命中物件局部取色，不继承同句血珠、禅杖或邻句颜色。
- 新增 `magic_ruler`：双平行尺边、端帽、中心脊、五档刻度和端点闪光。银尺使用 `qi=#C8E7FF` 银白，不误用淡金 `metal`，也不继承同句黑山/绿柱。
- 新增 `giant_hammer`：长柄和宽锤头为核心组件，8 个锤头节点跨帧轮转；八骷髅句以白→绿渐变表达白骨与绿焰，不再额外生成自由鬼首/灵体。
- 三种形象只通过 `emitFigurePrimitive` 层内分发，不进入契约钉住的 52-shape `emitAuthoredShape` switch；每份最小复杂轮廓预算为 2。
- 局部数量绑定后，单锤/单尺保持 1、两道尺影为 2、密集锤影为 12；尺寸词“七八丈”“千丈”不再污染 copies。
