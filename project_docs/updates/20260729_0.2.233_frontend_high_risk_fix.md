# 0.2.233 高危前端交互修复

## 范围

完成 `implementation_plan.md` 的 F-A 批次，覆盖 UI-01 至 UI-05：技法拖拽、任务同步滚动、宗门候选/快照刷新和拍卖重复竞价。

## 实现

- `TechniqueEditScreen` 只允许 `PENDING -> TECHNIQUE`；已经进入 `SCROLLING` 的手势不会因穿过槽位面板升级为绑定拖拽。
- `QuestTrackerScreen` 以过滤器和可见任务 ID 顺序建立稳定签名。相同视图同步保留列表和详情滚动；选择变化只重置详情滚动。
- `SectHallScreen` 将候选渲染、加入按钮、滚动行数收敛到 `visibleCandidates`，并以完整 `ClientSectData.Snapshot` 值变化重建动作控件，避免入宗后的旧按钮软锁。
- `AuctionSoftService` 在货币预留、`placeOrRaise` 和自动结算之前拒绝当前最高价者重放；`AuctionHallScreen` 对单个拍品在请求后暂时禁用按钮，并在同步或 40 tick 超时后恢复。
- `ClientAuctionLadderData` 引入本地单调 revision，使内容相同的拒绝同步包也能解除客户端等待态。
- 中英文语言资源新增“已是当前最高出价者”提示。
