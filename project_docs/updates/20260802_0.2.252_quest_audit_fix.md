# 0.2.252 quest 目录审计修复批

## 更新内容

依据 `issues/src-main-java-com-xunxian-seekingimmortals-quest.md`（26 文件/91 条发现）修复 quest 包问题，未修改网络包字段/顺序/类型/注册/频道行为。

### high 级

- `TextQuestDialogueTreeService.nodeFor`：进行中 stage 按链 `stepCount` 比例映射到 start/mid/finale 节点，不再钳位泄漏到 complete 节点；15/62 条 `step_count>=5` 链的后期阶段不再显示「此线已完结」且保留 advance 选项（`TextQuestDialogueService` 同根因一并消除）。
- 不可产出证明路由（`DetailedQuestProofService`）：为 4 个 token 接线真实服务端对话节点——`mortal_qixuan_entry_step_1→tree_tiannan_steward:visitor_service`（新手链第 1 步可完成）、`true_word_exam_passed→tree_zhenyan_lecturer:inner`、`tianyuan_return_fee→tree_tianyuan_registrar:portal_fee`、`inverse_star_alignment→tree_inverse_star_contact:star_spy`；`auction_catalog_v93.json` 新增 `wanbao_auction` 场馆，修复 `mergeWanbaoLots` 回退到 `tainan_xiaohui` 导致的 `dajin_wanbao_auction` 永久不可证明（kunwu_clue_assemble 第 1 步可完成）。
- 剩余 fail-closed 内容层项（`dayan_complete_rarity_rule`、`bf_mid_contest`、`gh_true_immortal_pressure`、`heifeng_sea_route`、`dajin_jin_capital_rim`、`ziling_exchange`、`fallen_demon_token`、`wuxing_shallow_trial`、`gray_realm_border`、`heifeng_sea`）无运行时内容层，留待后续实施计划（D-A/Y 系列/M 系列）补对话/商店/遭遇内容，继续失败关闭。

### security 级

- `FtbCustomTaskHooks.checkCustomTask` 镜像分支（war/rep/mirror，无 NativeReady）现在要求 `isAuthoritySafeQuest`（无奖励、无消耗任务），修复跨成员团队奖励泄漏；`singleAuthorityPlayer` 重构为先确认 FTB Teams manager 加载再查询在线成员，消除服务端 tick 路径 NPE（`FtbQuestCompatBootstrap` 同根因）。

### medium 级

- `FtbQuestDefaults`：state 文件缺新 manifest 条目不再判 invalid（记为未记录）；inspect 对未记录条目允许升级安装；`snapshotStillMatches` 允许缺失快照条目被本批安装。修复「新增章节后旧安装永久 PRESERVED_CUSTOMIZED」死锁，新增两条回归测试。
- `MainStorySoftService`：`secretRealmClear` 门改读世界级 `SecretRealmProgressSavedData.hasFirstCleared`（保留旧 NBT 键兜底）；`chapter_5` 门 id 修正为 `fallen_demon_valley`；`isComplete` 键读取统一归一化。
- `QuestService`：`teleportToYue` 落点从高空向下找地表（不再下探基岩层）；`hasItem`/`consumeItems` 扫描全容器（含副手/盔甲），消除任务小瓶/证据物品重复发放与漏检；`chooseBranch` 返回值改为真实处理结果。
- `QuestAuthorityCatalog`：`chaotic_sea_politics` 第 3-5 步的互斥 `requires_branch` 硬门移除（一次性分支锁下无解），保留 `branch` 展示标签；`optional` 步骤不再生成阶段硬门（mulan_war_campaign 第 5 步可跳过）；权威文件加载失败改为 fail-closed（`Gate.LOAD_FAILED`，拒绝启动/推进并提示）。
- `DetailedQuestRuntimeService`：5 个「未注册」奖励物品经核查为审计误报（`ItemCatalogService` 别名已折叠到已注册 canonical 物品，撤回本批临时注册）；`new_game` 前置放宽为「无任何链推进到第 2 步/完成」，修复异地出生永久锁死教程链；`recordAndAdvance`/`turnIn`/`showCurrentStep` 增加 stage 越界防护；`rewardPreflight` 对非字符串 `item` 拒绝发放（防扣贡献后抛错）；证据/账本淘汰加警告日志。
- `TimelineChronicleService.onChronicleDiscovered`：补充 `chapter_1`/`chapter_4`/`great_jin` 关键词，完成主章节可解锁对应时间线阶段。
- `QuestRewardService`：注册 7 个 unique 故事奖励真实物品（`true_soul_pill`、`eight_spirit_ruler`、`spirit_refine_art`、`void_heaven_cauldron`、`huiyang_synth_mark`、`zaohua_trial_mark`、`detailed_node_token`，bulk 1202 条，双语+模型+确定性纹理），不再以空白玉简代理并永久烧账本；解析 v101 `unique_account` 键（大挪移令等可发放）；删除 `foundation_path` 死映射；资源缺失/损坏加错误日志。
- `FtbRewardBridgeService`：无权威发放前置时不再标记/迁移账本（防未来 legacy 回调永久吞终局奖励），`toLowerCase` 用 `Locale.ROOT`；legacy 标签名提升为共享常量 `ROOT_TAG`（`TextQuestChainService`/`PlayerPersistentDataClonePolicy` 及测试引用）。

### low 级

- `QuestHookRuntime`：每日事件仅在实际推进后写入 per-roll 幂等 claim（未满足门禁可重试）；`handled` 不再被强制置 true；删除无行为的区域级 `onDailyEvent` 订阅；注册失败记警告；击杀归属改用与 `ModEvents` 一致的战斗权威解析（伴生兽/侍灵击杀计入任务）。
- `QuestHookSoftService`：关键词启发式先于子串匹配（`sect`/`void`/`diyuan`/`nether` 命中作者意图分支）；`accept` 推进失败不再谎报成功；`preview` 补 hook id 占位符（新增 `advance_locked` 双语键）。
- `QuestLineService`：lines 键归一化、空白章节键统一；`steps` 字段支持数值形式；资源缺失/损坏加错误日志。
- `QuestPresentationService`：finale/阶段费用预览按链缓存，消除渲染帧重复解析。
- `QuestProgress`：`reputation` 饱和钳制、`setSectQuestStage` 上下界钳制（迁移判断用原始值）、`Flags`/`SectFlags` 键类型校验。
- `TextQuestChainService`：`advance` 重构——stepCount<=0 拒绝推进（防刷声望）、越界 stage 存档收口结算终局奖励一次、提取 `finishChain` 单一完成路径；`QuestHookRuntime.tryStartOrAdvanceChain` 加当前步骤 hook 校验（防 hook/链 id 碰撞双推进）。
- `TextQuestNpcHookService`：autoStart 失败不再吞掉（不广播成功、不打开对话）；`TextQuestDialogueService.act` 的 `start` 选项补 NPC 邻近门禁。
- `FtbNativeQuestSync`：删除无调用者的 `writeTargets` 死代码（同步更新测试）。
- `FtbQuestBridgeService`：删除 `isFtbPresent`/`sampleMappings` 死代码与未用 imports，修正章节清单注释引用。
- `DetailedQuestProofCatalog`：删除冗余硬编码计数校验（覆盖校验已保证 1:1）、`ADMIN_ONLY` 死判断、未用 12 参数构造器；`validId` 先校验原始值大小写；损坏资源报「Corrupt」而非「Missing」；测试 `TECHNIQUE_LEARNED` 参数键对齐 `technique`。
- `DetailedQuestProofEvent.secretRealmLayerEntered`：worldRegionId 不再误传 realmId。
