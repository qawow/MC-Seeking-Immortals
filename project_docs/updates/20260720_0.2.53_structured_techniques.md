# 0.2.53 术法结构字段与安全回退

## 本批完成

- `TechniqueDataManager.TechniqueEntry` 新增 `damageBase`、`effectKey`、`tags`、`target`、`range`，兼容旧构造调用。
- text-material 加载合并顶层与 `effect.tags`，读取内外层伤害/效果键，以及 `setting.target`、`setting.range`。
- `AbstractTechniqueEffectResolver` 优先复用已登记 `SkillType` 专用效果；注册表不可用的纯 JVM 测试环境会直接扫描 enum 映射。
- 未映射的通用投射、范围、减益、控制、增益、恢复、移动、近战和召唤术法按 authored 伤害、元素、目标与范围生成运行时效果。
- 召唤类改用既有 `HonestSummonSpell`，不再把召唤伪装为自增益。
- `ultimate`、`secret_art`、`talisman_consume`、`command`、`craft_gate`、`wall`、`buff_zone` 无专用实现时返回不可释放，禁止静默降级。

## 权威与兼容

- 已有专用术法继续优先，避免通用 resolver 覆盖定制伤害、状态、视觉和事务。
- 旧 7 参数与 12 参数 `TechniqueEntry` 构造保持兼容；未增加存档字段或网络字段。
- 不支持的高风险类型不扣灵力、不写冷却，沿既有释放链返回效果不可用。
- 未修改网络包字段、顺序、类型、注册、方向或通道行为，`ModNetwork.PROTOCOL_VERSION=25`。
