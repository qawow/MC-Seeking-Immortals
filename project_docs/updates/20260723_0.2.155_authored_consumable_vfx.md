# 0.2.155 作者丹药与消耗品视觉档案

## 变更类别

代码、资源、构建校验、测试与项目文档更新。共享树已提交 `0.2.154` 任务追踪批次，本批将 `mod_version` 升至 `0.2.155`。

## 作者资料与档案

- 新增确定性生成器，严格对账 v118-v122 的 114 条丹药标准资料、两条 v118 丹药专稿，以及 v118/v120/v122 的 57 条消耗品资料。
- 丹药与消耗品使用两个数组保存，允许 `bigu_pill`、`demon_qi_purge_pill` 在两套作者目录中保留不同语义；运行时仍服从 `BulkItemClassifier` 的丹药优先分类。
- 每条档案保存外观、主动/体表/UI 演出、逐帧文本、作者来源、family、motif、VFX kind、粒子、拖尾、半径与强度。粒子/拖尾引用受 v121 白名单约束，禁止 `DEFAULT`。
- 丹药 effect/category 镜像 `PillEffectCatalog.mergeDesignMetadata` 和 generic effect 解析；测试逐项核对 113 条运行时条目，避免解毒、疗愈、突破或毒修退化成统一中性表现。
- 查找顺序为完整 ID、显式别名、品质后缀回落；独立作者条目 `spirit_recovery_pill_high` 保持独立，`jiangying_pill` 兼容读取统一使用 `jiangchen_pill` 运行时视觉语义。

## 服务端接线

- 原生 `BasePillItem`、`CatalogPillItem` 与 `PillEffectCatalog` 三类丹药入口均在真实效果成功后发出作者 VFX；四档品质只调整视觉半径与密度，不影响玩法数值。
- `CatalogConsumableService` 统一在 `UseResult.SUCCESS` 后发出视觉；门禁失败、无效果、重复状态或传送失败不会误播。
- 阴棺钉尸体认主、星宫税契和阴体护符的专用成功路径补齐独立钩子；阴棺钉失败反噬即使消耗物品也不会伪装成成功演出。
- 储物袋/囊只打开既有 UI，不叠加消费粒子；`spirit_stone_low` 等无主动使用入口的作者消耗品档案只保留资料，不会自动发包。
- 视觉复用现有 `TechniqueVfxPacket` 与 Lodestone 四阶段客户端系统，未添加新包或字段。

## 剩余风险

自动测试不替代客户端实机视觉验收。仍需检查不同粒子档、多人密集使用、透明排序、跨区域移动路径、四品质强度差异、投射符与长期状态的视觉密度。
