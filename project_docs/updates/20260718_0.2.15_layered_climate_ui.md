# 0.2.15 四材分层问道录 — 气候内核与壳接线

日期：2026-07-18

## 目标

在 0.2.14 竹简青衿之上，落地「凡人问道录 · 四材分层」设计系统内核，并完成抽象壳/控件/核心屏与 HUD 的气候接线：

1. 引入 `UiClimate` 四材色板（玉简 / 竹简 / 暖漆 / 朱砂危签）
2. `ImmortalUiSkin` 气候栈 + 全 `draw*` 走当前色板
3. 抽象壳 `defaultClimate()` + 各 Screen 语义路由
4. HUD 四层 Overlay 强制玉简气候
5. Danger 按钮叠加朱砂危签
6. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### 设计系统

- 新增 `client/UiClimate.java`：`JADE_SLIP` / `BAMBOO_SLIP` / `WARM_LACQUER` / `CINNABAR_SEAL` + `Palette` record + `Material`
- `ImmortalUiSkin` 重写：
  - `pushClimate` / `popClimate` / `withClimate` / `currentClimate` / `palette`
  - `JOURNAL_*` / HUD 别名随气候 `applyPalette` 重绑（默认竹简）
  - 面板叠层按材质选 paper / jade / bamboo / lacquer grain
  - 中侧装饰：玉脉 / 竹节 / 漆钉
- 新增贴图 `textures/gui/lacquer_grain_texture.png`（32×32 低 alpha 漆木细纹）

### 抽象壳与控件

- `AbstractJournalScreen` / `AbstractJournalContainerScreen`：`render` 包 `pushClimate(defaultClimate())`
- 默认：非容器竹简、容器暖漆
- `AbstractLoreScreen`：强制竹简
- `ImmortalButton`：新增 `danger()`；Danger 绘制时叠 CINNABAR_SEAL

### 屏幕气候路由

| 气候 | 屏幕 |
|------|------|
| JADE | CultivationStats / TechniqueEdit / Meditation / MethodTree / LifeSkillTree |
| BAMBOO | Quest / Dialogue / Worldpack / AlchemyStatus + Lore 族 |
| LACQUER | Shop / Auction / Sect / StorageBracelet / RefinementPlan + Container 族 |
| CINNABAR | Danger 按钮叠加（非整屏默认） |

### HUD

- CultivationHealth / CultivationHud / Breathing / TechniqueSkillBar：渲染入口包 `JADE_SLIP`
- 几何锚点冻结（左上状态条 / 左技能轨 / 底吐纳）

### 明确不动

- `ImmortalHudLayout` 几何与 public Layout API
- packet 字段/顺序；`PROTOCOL_VERSION=24`
- 技能正式图标包、自定义书法字体、玩家主题切换器

## 版本与协议

- `mod_version`：`0.2.14` → **`0.2.15`**
- `PROTOCOL_VERSION`：**保持 24**
