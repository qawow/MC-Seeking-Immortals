# 0.2.52 贡献符与阵法物品语义

## 本批完成

- `sect_contribution_token` 从目录载体转为服务端权威消耗品，每枚严格兑换 1 点当前宗门贡献。
- 只有 `SectDefinitionService` 可识别的当前宗门可兑换；能力缺失、空/未知宗门、贡献封顶时返回失败且不扣物。
- `QuestProgress.addContribution` 使用 long 中间值并饱和到 `Integer.MAX_VALUE`，避免高余额溢出后归零。
- `spirit_gathering_array_disk` 按源目录 `formation_consumable` 语义加入 `formation_item_behaviors`，成为一次性 `spirit_gather` 自由阵场。
- 聚灵阵盘成功激活后才消耗；普通持续 90 秒，成功激活且携带灵砂袋时提交灵砂并延长至 150 秒。
- 所有已登记阵法载体现在按 `place_block`、`activate_free_field`、`inspect_only` 显示真实交互策略。
- 宗门贡献符、传送阵令牌和 12 个阵盘/阵旗条目新增双语精确用途，明确材料、凭证或可执行边界。

## 权威与兼容

- 未加入宗门不能把贡献符兑换为无归属通用货币。
- 未给材料型阵盘凭空增加右键效果；只有源数据明确标记为 formation consumable 的聚灵阵盘新增行为。
- `teleport_array_ticket` 保持凭证载体，等待真实旅行节点显式声明后再接消费事务。
- 未修改任何网络包字段、顺序、类型、注册、方向或通道行为，`ModNetwork.PROTOCOL_VERSION=25`。
