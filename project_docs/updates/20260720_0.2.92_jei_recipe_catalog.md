# 0.2.92 P2 JEI 三类权威配方全量展示

## 范围

- 完成 master plan P2-9：炼丹、炼器、制符配方全量展示。
- 不新增菜单、网络包或服务端制作旁路；JEI 只读取并展示既有权威数据。

## 实现

### 统一展示目录

- 新增 `JeiRecipeCatalog`，本身不依赖 JEI API。
- 目录只把三类权威运行时源投影为 JEI 所需的真实输入/输出 `ItemStack`。
- 无材料映射、无注册物品、空输入或非法数量均 fail-closed，并记录 omitted recipe id；不再显示伪造占位物。

### 炼丹

- 129 个 `alchemy/recipes/*.json` 全部进入 `alchemy/recipe_manifest.json`，资源测试要求文件集合与清单完全相等。
- `AlchemyRecipeManager.jeiRecipes()` 先读取打包清单，再用同进程已 reload 的配方按 id 覆盖或扩展。
- 因此远程客户端不再局限于 23 条 Java fallback，整合服/本地数据包仍能覆盖同 id 条目。
- JEI 保留四品质输出、材料数量、炉阶、火阶、基础成功率、爆炉率、灵力和控火境界信息。

### 炼器

- 73 条作者炼器配方全部复用 `ArtifactRefinementService.resolvePlan(recipe)` 与 `resolveItem(itemId)`。
- 输入显示真实映射材料和数量，输出显示真实法宝；原固定 `artifact_repair_kit` 占位已删除。
- 显示炉阶、基础成功率与最低境界。

### 制符

- 新增独立制符 JEI 分类，覆盖 `TalismanCraftService.recipes()` 的 24 条配方。
- 展示输入直接复用公开的 `materialRequirements(recipe)`，因此与服务端扣料一致，并显式包含每方 1 瓶符墨。
- 显示真实符箓产物与基础成功率。

### JEI 入口

- 炼器 catalysts：G1、G2、G3 炼器炉。
- 制符 catalyst：制符台。
- 炼丹 catalysts：一至五阶炼丹炉。
- 炼丹炉 GUI 的进度条区域可点击打开炼丹分类。
- 新增中英双语炼器统计、最低境界、制符分类与制符统计键。
