# 0.2.105 专服 Screen 侧加载修复 + 多人复签基建

日期：2026-07-20  
`mod_version`：`0.2.105`  
`ModNetwork.PROTOCOL_VERSION`：`26`（字段/顺序未改；仅 client handle 实现迁移）

## 背景

`0.2.104` 落地多人权威回归与 `live_smoke mp` 后，`./gradlew runServer` 在 CONSTRUCT 失败：

`Attempted to load class net/minecraft/client/gui/screens/Screen for invalid dist DEDICATED_SERVER`

栈：`ModNetwork.register` → `SyncSectDataPacket`（及同类 GUI 包）lambda 常量池含 Screen。

## 修复

- 新增 `client/ClientPacketHandlers`：全部 GUI open/refresh 逻辑。
- 新增 `network/ClientPacketDispatch`：字符串反射调用，保证 `network/*` 常量池无 Screen。
- 10 个 S2C 包 handle 改为 `ClientPacketDispatch.invoke(...)`。
- 契约测试：`networkPacketsDoNotEmbedClientScreenTypes`。
