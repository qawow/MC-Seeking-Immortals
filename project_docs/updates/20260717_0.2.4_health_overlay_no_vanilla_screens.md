# 2026-07-17 0.2.4 任意界面隐藏原版血量

## 变更摘要

在 0.2.3 的背包/暂停白名单之上，进一步去掉 Screen 门控：只要生存 HUD 会绘制，就始终用自定义气血/护体替换原版心形，聊天与其它全屏也不再回退显示原版血量。

## 实现

- `CultivationHealthOverlay.shouldReplaceVanillaPlayerHealth` 仅保留 `!hideGui && hasPlayer && shouldDrawSurvivalElements`。
- 删除 `blocksHealthReplacement` / `blocksHealthReplacementByClass` 与 Screen 相关 import。
- `ClientEvents` 仍通过同一公开谓词 cancel `VanillaGuiOverlay.PLAYER_HEALTH`，保证「有 cancel 必有绘制」。
- 其它三块 HUD（修为/技能/吐纳）仍可在任意 Screen 下隐藏，本次不改。

## 验证

- 定向：`ScreenLayoutTest`
- 完整：`./gradlew build`

## 版本与协议

- `mod_version`：`0.2.3` → `0.2.4`
- `ModNetwork.PROTOCOL_VERSION`：保持 `24`

## 备份

- `.bak/20260717_150446_health_no_vanilla_screens/`

## 剩余风险

- 全屏模组 UI 左上角可能叠一层气血面板；若后续需要按页面隐藏自定义条，应单独加绘制策略，且仍不得恢复原版心形。
- 真实客户端 GUI Scale / F1 / 创造模式仍建议人工烟测。
