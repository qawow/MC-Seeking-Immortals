# 2026-07-17 0.2.6 状态条左上 + 技能栏左中半透明

## 变更摘要

把 0.2.5 的右上合并状态条迁回**左上**，技能轨改为**左侧、在状态条下方剩余高度内垂直居中**，并重做两块 HUD 的凡人/玉简视觉：状态条更深更实，技能栏半透明。

## 布局

- **左上 `statusStrip`**：气血 band + 修为/灵力 band（同一玉简外框）
- **左中 `techniques`**：七槽半透明玉简技能轨，`y` 在 `[strip.bottom+gap, bottom]` 内居中
- **底 `breathing`**：打坐吐纳玉简（位置不变）
- 窄屏优先同样左堆叠；病理尺寸才 fallback 到「左技能轨 + 内容列」

## 绘制

- `CultivationHealthOverlay` 仍拥有 chrome（完整条 / 打开 Screen 时的 `healthOnlyStrip`）
- `CultivationHudOverlay` 只画 `cultivationBand` 内容
- `TechniqueSkillBarOverlay` 使用 `drawTranslucentJadeSlipRail` / `drawTranslucentJadeSlipSlot`
- 气血替换谓词保持 0.2.4：`!hideGui && hasPlayer && shouldDrawSurvivalElements`

## 皮肤

- 加深 `drawStatusStripChrome`（多层阴影、朱砂高光边、底边）
- 新增技能专用半透明 token：`HUD_SKILL_*`，不改动 journal 实心 `HUD_*`

## 验证

- 定向：`ScreenLayoutTest` + `ImmortalHudLayoutTest`
- 完整：`./gradlew build`

## 版本与协议

- `mod_version`：`0.2.5` → `0.2.6`
- `ModNetwork.PROTOCOL_VERSION`：保持 `24`

## 备份

- `.bak/20260717_170201_hud_left_status_skill/`

## 剩余风险

- 左上状态条可能与其它左 HUD / 模组列表叠层；技能半透明减轻遮挡
- 极矮屏可能触发 rail fallback 双列，与常规左堆叠观感不同
- 真实客户端 GUI Scale / 打坐 / 低血+护体仍建议人工烟测
