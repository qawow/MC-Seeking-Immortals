# 0.2.62 CAST 注册表保真 / 鉴定扣费 / 飞行权限

## 本批完成

### CAST_* 模式化注册
- 26 个 `CAST_*` SkillType 从 `ElementalProjectileSpell` 迁移到 mode-aware `TalismanConsumeSpell` helper。
- `effectKey` 驱动 projectile / aoe / buff / control / movement 分支。
- `CAST_GHOST_HIDE_TALISMAN` 保留 `SelfBuffSpell` + `conceal_qi` 状态生产契约。

### 鉴定扣费先提交
- `ArtifactAppraisalService.appraise` 先校验并消耗灵力，再写鉴定 NBT 与练习/声望。
- 灵力不足或 capability 缺失 fail-closed，双语提示 `appraisal.no_power` / `appraisal.no_data`。

### Curios 飞行持续授权
- `hasFlyingArtifact` 经 `isAuthorizedFlyingArtifact` 过滤。
- 静默校验：`isUsableBy`（拒绝对方主人）、高阶未认主 `requiresClaim`、完整性 `> 0`。
- 不在 tick 路径调用 `canActivate`，避免每 tick 刷认主消息。

- `CastTalismanRegistryTest`、`ArtifactAppraisalServiceTest` 顺序契约、`FlyingArtifactAuthorityTest`。
- `SkillStatusProductionTest` 保持 ghost-hide `conceal_qi`。
