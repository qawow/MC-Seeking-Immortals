# 0.2.13 竹简青衿 — 别名清理与占位加深

日期：2026-07-18

## 目标

在 0.2.12 polish 之上继续收口：

1. `CultivationStatsScreen` 去掉暖漆 `BRONZE` 词汇，结构填充与强调字色分离
2. 「玉简」文案改为「竹笺」
3. 修为进度条 helper 去旧暖色贴图，改原生竹框填充
4. 无图标术法占位改为竹笺卡（偏绿 seed + 纸纹 + 朱砂侧条）
5. 残留对话/节点字色对齐竹纸层级
6. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### CultivationStatsScreen

- `BRONZE` / `BRONZE_DIM` → `BAMBOO` / `BAMBOO_DIM`（仅 rim/fill）
- 强调数值字色 → `JADE`（`JOURNAL_JADE_TEXT`）
- 分区标题字 → `PAPER`
- 「功法玉简」→「功法竹笺」；空术法标签「玉简」→「竹笺」
- 滑块拇指 fill 用 `BAMBOO`

### ImmortalUiSkin

- `drawCultivationProgressBar`：不再 blit 旧 `cultivation_progress_bar.png`；双调竹框 + 纸纹 + 竹青填充 + 前缘节点
- 删除未再使用的 progress texture 常量
- `drawSkillIconBacking`：竹边 + 朱砂侧条 + 大号叠纸纹
- `skillPlaceholderColor`：确定性偏竹绿 seed（G 高于 R/B）

### 残留字色

- `SectScreen` / `SectHallScreen` 对话标题 → `JOURNAL_PAPER`
- `MethodTreeScreen` 焦点节点字 → `JOURNAL_PAPER`

### 明确不动

- Layout / packet / skill 图标全量美术重画
- 旧 PNG 文件可仍留在资源目录（未接线），避免误删外部引用

## 版本与协议

- `PROTOCOL_VERSION`：**保持 24**
