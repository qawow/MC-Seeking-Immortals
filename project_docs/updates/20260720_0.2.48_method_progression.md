# 0.2.48 功法动态层数与学习门槛

## 范围

- 消除功法运行时、同步与客户端界面的固定九层假设。
- 消费 `cultivation_methods.json` 的显式层数、学习境界上限和前置功法层数。
- 消费 `method_layer_technique_matrix_v130.json` 的总层数、阶段层名和逐层境界带。
- 收紧典籍、术法来源和宗门授法，不再把未知名称形态直接写入已学功法。

## 已完成

- `MethodEntry` 保留 `realm_max_learn`、`setting.layers_max`、`learn_requirements.layers_required`、`prerequisite_methods` 和 `prerequisite_realm_layers`。
- 功法最大层数统一按显式 `layers_max`、`layers_required`、矩阵正 `total_layers`、固定 1 层的优先级解析。
- 长春功以真实 13 层运行，矩阵五阶段按 `1/4/7/10/13` 映射；青元剑诀按矩阵真实 13 层运行；黄枫丹经等零阶段生活功法学习后固定 1 层且不可继续精进。
- 学习功法同时校验最低境界、`realm_max_learn`、前置功法是否已学及其要求层数；青元剑诀要求筑基且长春功 13 层，筑基后不能再补学仅允许炼气入门的长春功。
- 精进下一层前读取矩阵 `realm_band`；青元剑诀第 7/9/13 层分别要求结丹、元婴、化神，不满足时不扣灵力或修为。
- 术法解锁按实际层到矩阵阶段映射，不再让长春功第 2 层提前获得 4-6 层阶段术法。
- 典籍 unlock 只接受目录中的精确功法 id；术法来源关键词映射和宗门授法也必须命中真实目录并通过境界、前置和冲突门槛。
- `SyncLearnedMethodsPacket` 保持原字段与编解码，仅按功法 id 的动态上限钳制；客户端镜像、精进按钮、进度条、节点链、层名和下一层境界共用同一上限。
- 新增中英文学习失败、前置、逐层境界和界面字段文本。
