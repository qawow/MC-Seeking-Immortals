## 背景
`docs/code-review-fix-checklist.md` 第四批 `S-技能图标`、`project_docs/pending_requests.md:36`、`project_docs/frontend_refactor_handoff.md:167` 与 `docs/task-board.md` 多处一致指向：左侧 7 槽技能栏 `TechniqueSkillBarOverlay.drawTechniqueIconPlaceholder` 用 `techniqueId.hashCode()` 取色 + 技能名首字母作占位，15 个可释放技能无 PNG 图标，视觉不可区分。本轮建立 `textures/gui/skill/<id>.png` 图标目录、HUD 渲染接入，并用脚本生成程序化占位 PNG。

## 实现

### 生成脚本（新增 `scripts/generate_skill_icons.py`）
Python 3 + Pillow，幂等可重跑。对 15 个可释放 techniqueId 各生成 16×16 RGBA PNG：
- 配色按属性：火=红橙、水=蓝、冰=浅蓝、木=绿、土=黄棕、金=灰白、雷=紫黄、神识=金、剑=青灰、阵=紫、遁=棕、通用=暗褐。
- 简单符号区分：火球=圆点、冰锥=三角、雷=闪电折线、剑刺=竖线、剑阵=方框+点、遁=箭头、探测=同心圆、护体=环、飞行=向上三角、被动=菱形。
- 输出到 `src/main/resources/assets/seeking_immortals/textures/gui/skill/<id>.png`。
- techniqueId 列表以 `SkillType` enum 为单一真源。

### HUD 渲染接入
- `client/ImmortalUiSkin.java`：
  - 新增 `KNOWN_SKILL_ICONS`（15 个 id 的 `Set`）。
  - 新增 `SKILL_ICON_CACHE`（`ConcurrentHashMap<String, ResourceLocation>`），`drawSkillIcon` 内 `computeIfAbsent` 构造 `ResourceLocation(MODID, "textures/gui/skill/" + id + ".png")`，避免每帧 `new`。
  - 新增 `hasSkillIcon(techniqueId)` 与 `drawSkillIcon(graphics, x, y, size, techniqueId)`，`blit` 16×16 纹理到 size×size。
- `client/TechniqueSkillBarOverlay.java`：`drawTechniqueIconPlaceholder` 改为先 `hasSkillIcon` → `drawSkillIcon`（占满槽内 size-2）；未知 id 回退原 hashCode+首字母占位，保降级可用。
