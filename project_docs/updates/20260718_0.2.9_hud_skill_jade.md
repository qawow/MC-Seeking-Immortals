# 0.2.9 HUD 技能轨玉纹对齐 + Auction Rect 清理

日期：2026-07-18

## 目标

在 0.2.8 克制问道录基础上，补齐技能轨/槽位的材质一致性，并去掉 AuctionScreen 局部 `UiRect` 对包级类型的遮蔽。

## 变更

### ImmortalUiSkin

- `drawJadeSlipRail` / `drawTranslucentJadeSlipRail` 内层叠低 alpha `jade_texture` 平铺。
- `drawJadeSlipSlot` 始终叠玉纹；`drawTranslucentJadeSlipSlot` 仅在已填充槽叠玉纹，空槽保持安静。
- 注释：Shop/Auction/Sect/Storage 已不再是「遗留未迁屏」。

### AuctionScreen

- 局部 `record UiRect` 重命名为 `Rect`（与 Shop/Sect/Storage 一致）。
- `toUi` 桥接到包级 `UiRect`；`renderJournalTitle` 可正常 override 包级签名。
- Layout 字段类型改为 `Rect`；几何/滚动/发包契约不变。

## 版本与协议

- `mod_version`：`0.2.8` → **`0.2.9`**
- `PROTOCOL_VERSION`：**保持 24**
