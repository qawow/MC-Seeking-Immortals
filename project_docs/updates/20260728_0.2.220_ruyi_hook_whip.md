# 0.2.220 如意、摄魂钩与火鞭兽筋独立轮廓

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.219` 升至 `0.2.220`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 精确匹配玉如意、白色如意、狼首如意、摄魂钩、火鞭、纤细/丝线状兽筋及巨大白骨头。
- `爪如钩`、`鞭炮`、`金冠` 等比喻或无关名词不生成对应法器。
- 如意、钩、鞭均为单件；飞剑牵丝保留三组飞剑与三组兽筋，不把同句剑体过滤掉。

## 运行时实现

- `MAGIC_RUYI`：长柄、云首、端环、冠部星芒，固定静止显形。
- `MAGIC_HOOK`：刚性钩杆、内弯钩尖、链环、钩尖闪光，固定直线钩击。
- `MAGIC_WHIP`：跨帧波动鞭身、加固握柄环、击打端星芒；火鞭及弹射兽筋使用直线路径。
- 三者加入 `VisualPrimitive`、层内 `emitFigurePrimitive` 和复杂轮廓最低副本预算，不改变契约固定的 52 种作者 shape switch。

## 颜色与伴随层

- 红黄两色玉如意使用 `fire→earth`，精血没入白霞如意使用 `fire→qi`，白色如意为 qi。
- 摄魂钩 5 层均使用 yin；火鞭使用 fire，兽筋使用 earth。
- 狼首如意同句恢复红黄双狼 `summon_gate`；巨大白骨头同句恢复飞遁 `afterimage_path`。
- 弹射兽筋后化成的淡黄色手镯继续使用 `wheel_disc`，没有被鞭体替代。

## 差异与契约

- 相对 `0.2.219` 恰有 12 个预期 technique ID、17 条语义引文组变化；非目标 ID 和非 `visual_program` profile 字段变化均为 0。
- 目录保持 5,727 profiles、2,292 techniques、1,806 authored、9,947/9,947 引文；术法程序为 10,867 层、97 种 primitive。
- 新增计数为 `magic_ruyi=6`、`magic_hook=5`、`magic_whip=5`；`ghost_head` 保持 33 层。
- 每层 8 粒、事件 MINIMAL/DECREASED/ALL 的 7/16/30 粒上限、named copies 72 上限与全局公平预算均未提高。
