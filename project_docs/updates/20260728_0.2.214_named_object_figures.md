# 0.2.214 扇、炉、卷、盘、棒具名轮廓

日期：2026-07-28
`mod_version`：0.2.213 → **0.2.214**；`ModNetwork.PROTOCOL_VERSION` 保持 **30**。

## 原文与边界

- 三焰扇的扇体长期只剩符环/火鸟/火柱，青色羽扇又误用双翼轮廓；本批只匹配“三焰扇、青色羽扇、单手持扇”和带三色火焰的完整扇面短语，不匹配 94 处表示 AOE 形状的裸“扇面”。
- 银焰火炉和炼丹炉被压成光球/雾幕，且具名主体加入后必须继续保留炉内银焰与紫雾。
- 黑色百鬼画卷与金色防御卷轴缺少展开纸面；只匹配“黑色画卷、金色卷轴、卷轴之上”，不匹配“如画卷般”等比喻。
- 水属性阵旗阵盘、蓝色阵盘和巨大青光阵盘缺少圆盘实体；规则使用“阵旗阵盘、是阵盘、青光阵盘”等完整短语，避开“一阵盘旋”，并不覆盖已经爆裂成碎片的阵盘。
- 两处狼牙棒分别只剩通用光爆与地场，现保留武器本体、挥击狂风和砸地坑三者的正确组合。

## 实现

- `magic_fan=10`：扇柄、中心扇骨、六条侧扇骨和弧形扇沿；三焰扇为 fire → qi，青色羽扇为 wood，并从 `wing_fan` 迁出。
- `alchemy_furnace=8`：炉体长轴、三层炉腔、前炉口、炉盖、烟囱与升腾物；银焰/火球/紫雾作为独立伴随层保留。
- `magic_scroll=3`：展开纸面、上下轴杆、侧边和三道内文；黑色百鬼卷为 yin 并保留 12 份鬼图弹群，金卷轴为 metal。
- `formation_disc=8`：外环、反转内环、十字轴和八个阵眼节点；水阵盘使用 water、青光阵盘使用 wood、无明示颜色的阵盘使用 qi。
- `spiked_club=2`：完整长柄、加固棒头、环状尖齿与端点星芒；十余丈巨棒保持 1 份并保留地坑，挥棒句保留声波式狂风。
- 五种形象只经 `emitFigurePrimitive` 层内分发，并进入每份至少 2 粒的复杂轮廓预算；核心长轴/外环在低预算下覆盖完整范围。
