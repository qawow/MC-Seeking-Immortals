# 2026-07-26 0.2.194 六套界面主题与游戏内切换

## 概述

将 `project_docs/ui_prototypes/` 中的全部五套 UI 原型方案实现为可切换主题层，与《云笈墨卷》基线共六套主题，并在修仙面板提供游戏内切换按钮与客户端持久化。

## 实现内容

### 主题层（`client/ui/UiTheme`）

- 六套主题：`inkscroll` 云笈墨卷（基线）、`night_starchart` 玄夜星图、`bronze_tripod` 青铜鼎彝、`cave_inscription` 洞府石刻、`talisman_paper` 符箓黄纸、`inkwash_landscape` 水墨山水。
- 每套主题内嵌静室/行录/账房/凶兆四个语义场景的完整 46-token `UiClimate.Palette` 字面量（由 `scripts/expand_theme_palettes.py` 按主题设计基调推导生成后固化）。
- `InkScene.palette()` 统一经 `UiTheme.active().paletteFor(scene)` 解析；基线主题委托 `InkScene.basePalette()`，保证默认外观零回归。
- 场景仍按屏幕语义路由（静室/行录/账房/凶兆），主题是玩家选择的观感层，两者正交。

### 主题贴图

- `scripts/generate_ink_ui_textures.py` 扩展为按主题基调生成 20 张纸面/底材平铺贴图：`{night,bronze,cave,talisman,inkwash}_{quiet,field,ledger,omen}.png`。
- `ImmortalUiSkin` 新增 `themedTexture(material, baseline)` 与 `coolSlipTexture()`：主题非基线时解析 `<prefix>_<scene>.png`，`THEME_TEXTURE_CACHE` 缓存 `ResourceLocation`；7 处硬编码 `JADE_TEXTURE` 平铺调用点全部改走主题解析，`grainTexture`/`bodyTexture` 同步主题感知。

### 切换入口与持久化

- `CultivationStatsScreen` 页眉右侧新增「界面主题：%s」循环按钮，点击 `UiTheme.next()` 即时切换（`UiTheme.setActive` → `ImmortalUiSkin.refreshPalette()` 实时重绑全部静态色板别名）并原地更新按钮标签。
- `client/ui/UiThemeConfig` 持久化到 `config/seeking_immortals-ui-theme.properties`（`theme=<id>`）；`ClientEvents.onClientSetup` 的 `enqueueWork` 首行加载。加载/写入全程失败容忍，损坏配置回退基线。
- 纯客户端装饰层：不新增网络包，服务端零参与，不信任亦不同步主题状态。

### 本地化

- zh/en 双语补齐 `screen.seeking_immortals.ui_theme.button` 与六个主题名键。

### 测试

- `InkPaletteTest` 参数化为 6 主题 × 4 场景全组合：
  - 文本/边框不透明；对比方向按主题亮度分三档断言（亮纸墨字：基线/符箓/水墨；中调石刻亮字：洞府；暗底亮字：玄夜/青铜）。
  - 17 个关键 token 无霓虹色；场景间 accent/panel/border 保持区分；朱砂/警示语义色在主题内跨场景恒定，基线保留历史精确值断言。
  - 新增 `byId`（null/未知/大小写空白容错）与 `next()` 全循环覆盖。
