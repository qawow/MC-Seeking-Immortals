# 0.2.57 交付 outbox 与制符原子扣料

## 本批完成

### 持久交付 outbox
- 新增 `DeliveryOutboxSavedData`（overworld SavedData，按玩家 UUID 记账）。
- `InventoryDeliveryService.giveOrEnqueue`：行囊可完整收下则即时交付，否则写入 outbox。
- 登录时 `claimQueued` 尝试补发；仍满则重新入账，不落地掉落。
- 拍卖退款/中奖、秘境奖励箱领取接入 `giveOrEnqueue`。

### 制符事务
- `TalismanCraftService.consumeMaterials` 先全量预检再扣料；中途异常全额退还。
- 成功产物走 `giveOrEnqueue`，避免满包世界掉落丢失。
