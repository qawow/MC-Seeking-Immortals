# 0.2.14 竹简青衿 — 残留细抠与验证

日期：2026-07-18

## 目标

在 0.2.13 之上继续仔细收口，并跑通布局单测 + 全量 build：

1. 数值/选中字色不再用 `JOURNAL_BORDER`（框色）当强调字
2. `CultivationStatsScreen` 斑马行改走 `drawListRow`
3. JEI 暖金 hex 改竹纸 token
4. 遗留 `drawPanel` / `drawSkillSlot` 转发到竹简绘制
5. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### 字色层级

- `MeditationScreen`：效率倍率 / 金丹评分 → `JOURNAL_JADE_TEXT`（有分）或 `PAPER_MUTED`（无分）
- `MethodTreeScreen`：列表选中未学节点 → `JOURNAL_JADE_TEXT`（不再用 BORDER 当字）

### 列表行

- `CultivationStatsScreen.row`：去掉 raw `JOURNAL_ROW` fill；交替 `NORMAL`/`DISABLED` 走 `drawListRow`
- 删除无用 `INK_ROW` 别名

### JEI

- `SeekingImmortalsJeiPlugin` 炼丹/炼器标题与副文：`0xFFE6D59A` / `0xFFBFAF8A` → `JOURNAL_PAPER` / `JOURNAL_PAPER_MUTED`

### 遗留 API

- `ImmortalUiSkin.drawPanel` → 转发 `drawLayeredPanel`
- `ImmortalUiSkin.drawSkillSlot` → 转发 `drawJadeSlipSlot`

### 明确不动

- Layout / packet / skill 图标全量美术
- 磁盘上未接线的 `cultivation_progress_bar.png` / `skill_bar_frame.png`（无 Java/JSON 引用，保留避免外部误引用）

## 版本与协议

- `mod_version`：`0.2.13` → **`0.2.14`**
- `PROTOCOL_VERSION`：**保持 24**
