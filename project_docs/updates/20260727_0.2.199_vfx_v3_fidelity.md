## 问题

对账 `文本材料/` 视觉描述后，运行时三处结构性失真：

1. `LodestoneTechniqueVfx.emitProgramLayer` 以 `quota/3` 截断 `layer.copies()`，原文「七十二口青色小剑」等精确计数无法存活。
2. `PaletteColors.fromArgb` 仅从 primary 合成 END（`*0.68+0.32`），编译器写入的 `secondary_argb`（如「由红转金」红→金）永不渲染。
3. `program_copies` 只认单字数字/百/无数，漏掉「七十二 / 三十六 / 十八」复合数词。
4. 鼎/钟/葫芦/光幕/光环/幡/印/虹桥等具名器物无独立 primitive，被错误映射到 swarm/mist/orbit。

## 实现

### 生成器 `scripts/generate_authored_visual_catalog.py`

- 编译器字面量 `semantic_layers_v2` → **`semantic_layers_v3`**（两处返回点）。
- `PROGRAM_RULES` 新增 8 个图形象：`cauldron_vessel / bell_chime / gourd_vessel / light_curtain / halo_ring / banner_streamer / seal_stamp / bridge_arc`。
- `PROGRAM_SHAPES` 同步纳入上述 8 个，并补 latent 缺口 `falling_barrage`。
- `PROGRAM_COLOR_RULES` 增补更长色词（赤金/紫红/苍青/玄黑/五色…）仍映射既有 11 色板键，**不发明新 ARGB**。
- `program_copies`：复合数词表优先匹配（七十二→24 上限、三十六→24、十八→18…），再回退旧规则。
- `program_scale`：补 `十丈 / 数丈 / 丈` 档位。

### 运行时

- `VisualPrimitive` 枚举加 8 常量。
- `LodestoneTechniqueVfx`：
  - `PaletteColors.fromArgb(primary, secondary)` 使用 secondary 作 END 梯度。
  - copies 忠实发射：`namedCopies = min(24, layer.copies())`，配额不足时 stride 采样跨 tick 铺满。
  - **层内** `emitFigurePrimitive` 分发 8 个新形象（**不**进入 `emitAuthoredShape` 契约钉死区，保持 generated==rendered=52）。
  - 8 个几何 helper：鼎三足+蒸汽、钟穹顶+余韵环、葫芦双球+雾、光幕竖帘、光环单环、幡杆+飘带、印方章下压、虹桥拱弧。
