# 0.2.43 批量物品功能第一阶段

## 范围

- 将 bulk 目录条目分为炼丹方、完整法宝、丹药、可执行消耗品和普通载体。
- 为 36 个目录消耗品接入服务端行为与双语效果说明。
- 收口便携储物、避雷/天劫、灵田肥、投射物和效果失败路径。
- 修复 max 审计确认的四项当前批次映射问题。

## 已完成

- 炼丹方从 `text_material/alchemy_recipes.json` 读取 `medium`：`paper_formula`、`jade_slip`、`sect_secret_scroll` 分别映射 PAPER、JADE、SECT_SECRET；缺少 medium 的旧方明确回退 PAPER，未知 medium 启动失败而非静默降级。
- `spirit_recovery_pill_high` 等完整丹药 ID 先按原始 ID 精确查找，再尝试显式别名，最后才剥除品质后缀。
- `storage_pouch_low/mid` 的 `extra_inventory_slots_9/18` 规范化为 `portable_storage_9/18`，复用现有储物菜单、NBT 容量与嵌套容器门禁，打开不消耗物品。
- `ArtifactDefinition.type=material_artifact` 的碎片、胚体和炼器材料不再创建 `ArtifactCatalogItem`，因此不能认主或激活。
- 食物、恢复、礼包、灵兽饵、遁符、测灵石、符箓、避雷、灵田肥和储物等 36 个目录条目已有真实使用路径；符方 `recipe_binding_talisman`、`recipe_gold_armor_talisman`、`recipe_invisibility_talisman` 因缺完整材料/产量/门禁数据，继续诚实保留为载体。
- 避雷 charge 在最终伤害阶段提交；天劫伤害取消时不推进波次并延迟重试；种植器冷却按维度隔离并清理过期键；投射物生成与金甲效果失败返还灵力。
