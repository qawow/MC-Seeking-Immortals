# 0.2.63 功法个性化精进成本与层数清理

## 本批完成

### 个性化精进成本
- `cultivateMethod` 改为按 `MethodEntry` 取成本。
- `costProfile` 按 school/attribute/id 分流：
  - 生活/炼丹/鉴定/辅修：更低 base 与 per-layer；
  - 剑修/战斗/魔道/鬼道：更高成本；
  - 炼体居中；
  - 长阶梯（≥12 层）摊薄每层成本；
  - 木系/疗愈略降，火雷略升。
- 无参重载保留默认 `20+12*layer` / `40+30*layer` 基线。
- `MethodTreeScreen` 展示 method-aware 成本。

### 旧层数 NBT 清理

- 钳制到 catalog/matrix `maxMethodLayer`；
- 补齐已学功法缺失的 layer=1 条目。
