# 0.1.499 Wave499 — alchemy furnace FORMED + GUI authority

Date: 2026-07-15

## Goal

Phase 1 + Phase 2 of the furnace multiblock plan:

- dedicated shell node
- durable FORMED state + light visuals
- GUI-authoritative formula/lid/fire install
- keep earth-fire room as a parallel gate

## Previous state (Wave498)

- All tiers required a shell geometry check
- Shell material was only `spirit_gathering_array`
- No FORMED blockstate / formed look
- Lid/fire/formula lived in BE scalar fields; GUI 5-slot handler was mostly decorative

## Changes

1. **Dedicated shell node**
   - New block/item `alchemy_furnace_array_node` (丹炉阵基)
   - Resources: blockstate/model/texture/loot/recipe/lang/tab/tags
   - Shell match accepts **node OR legacy spirit_gathering_array**

2. **FORMED state**
   - `AlchemyFurnaceBlock.FORMED` BooleanProperty
   - Server refresh on place/neighbor/tick
   - Form transition particles + sound
   - Blockstate variants `formed=false|true` with `*_formed` models/textures

3. **GUI authority**
   - Slots 0/2/3 are formula/lid/fire authority
   - Hand right-click inserts into matching slots
   - Typed `mayPlace` filters + smarter shift-click
   - Legacy scalar installs migrate into slots once on load
   - Break drops handler contents

4. **Earth-fire room**
   - Still independent via `SectEarthFireRoomMultiblock`
   - Idle message + GUI show room linked/missing

5. **MultiblockPattern**
   - Requirements now use `Predicate<BlockState>`
   - Added `requireAny(...)` for node|array compatibility
