# 0.2.250 Q-B-4 击杀、活捕、护送、遭遇与归属事件的结构化任务证明

## 范围

本批实现后续实施计划 Q-B-4：为击杀（ENTITY_KILLED）、活捕（ENTITY_CAPTURED_ALIVE）、遭遇（ENCOUNTER_CLEARED）和护送（ESCORT_COMPLETED）事件补齐结构化任务证明生产与校验。不含网络包字段、顺序、类型、注册或频道行为变化，`ModNetwork.PROTOCOL_VERSION=31` 保持不变。

## 完成内容

### 可信实体映射（纯函数）

- `PROOF_ENTITY_MAPPINGS`：路由实体令牌 → 真实服务端实体/Boss id（`qianzhu_tower_lord` → `puppet_tower_lord`，千竹塔塔主真实 Boss id）；身份规则始终生效，因为事件实体 id 来自被击杀/捕获实体的服务端观察事实，客户端字符串无法注入。
- `encounterRegionsForPhase`：秘境层清场 → 遭遇区域 id 映射：blood_forbidden:mid→bf_water_jiao、fallen_demon_valley:core→zm_candle、thousand_bamboo_puppet_tower:mid→qz_l2、core→qz_l3、yinyang_ku:mid→yy_yezha、guanghan_realm:core→gh_inner。

### 校验

- ENTITY_KILLED / ENTITY_CAPTURED_ALIVE：事件实体 id 必须属于路由令牌证明集（`entityTokenMatches`）；击杀归属为服务端解析的作战权威（含伴生兽/受控单位归属），历史回放只使用服务端记录事实。
- ENCOUNTER_CLEARED：绑定会话的秘境层清场事件（realm+phase+session 校验）或普通现场地域别名；深层遭遇区域不能经普通路径伪造。
- ESCORT_COMPLETED：事件区域必须等于玩家现场地域且为可信别名。

### 生产点接线

- `BossEncounterService.onBossKilled`：在 `claimEncounter` 会话归属校验成功后才记录 `recordEntityKilled(killer, bossId)`。
- `QuestHookRuntime.onLivingDrops`：玩家直接击杀记录 `recordEntityKilled(killer, typeId)`。
- `QuestHookRuntime.onSecretRealmClear`：追加 `recordEncounterCleared(player, realm, layerKey)`。
- `ArtifactCaptureService.releaseOrCapture`：活捕事务完成（实体移除）后记录 `recordEntityCaptured(player, id)`。
- `EscortMissionService.onStewardContact`：受控侍灵与玩家均抵达执事后记录 `recordEscortCompleted(player)`（现场地域）。

### 历史

HISTORY_TAG 记录新增 `Entity`/`Region` 字段；`eventFromHistory` 可重建击杀/捕获/遭遇/护送事件。
