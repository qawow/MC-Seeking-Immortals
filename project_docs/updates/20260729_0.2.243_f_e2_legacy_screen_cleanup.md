# `0.2.243` F-E2 旧屏幕清理

## 范围

- 完成 `implementation_plan.md` 的 UI-22：删除不可达的宗门、坊市和拍卖旧屏幕。
- 删除没有生产发送方的 `OpenAuctionScreenPacket` 及其消息注册。
- 保留 `SectHallScreen`、`MarketHallScreen`、`AuctionHallScreen` 的正式菜单入口。

## 实现

- 删除 `SectScreen`、`ShopScreen`、`AuctionScreen` 和 `OpenAuctionScreenPacket`。
- `ClientPacketHandlers.handleSyncSect`、`handleSyncShop` 只更新 `ClientSectData`/`ClientShopData`，不再因同步包的 `openScreen` 标记强开旧屏。
- 删除旧屏专属布局测试和双语语言键；正式 Hall 复用的键保持不变。
- 更新网络方向/多人权威契约测试，确认旧包文件和注册均不存在。
