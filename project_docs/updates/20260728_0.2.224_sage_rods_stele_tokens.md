# 0.2.224 儒圣、阵桩、天晶碑与牌网连续性

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.223` 升至 `0.2.224`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 浩然儒圣只命中十几丈白色儒袍圣像及其连续动作；银瞳、五色大笔和银色“儒”字保持独立伴随层，不把普通人影扩展为儒圣。
- 阵桩只命中黄色豆粒化成的数百金黄木棍及青丝网中的十二根青色木棍；钢叉般手指、城市号角等比喻和背景物不生成阵桩。
- 天晶碑只命中明确“石碑微颤、通体灵光闪烁”的可执行碑体；在石碑旁挖坑、碎石融平及背景门楼/石碑不生成 `rune_stele`。
- 木牌、铁牌、玉佩、玉牌和金银令牌只在本体显形/操作时生成；巨大地图保持背景，青色爪芒组成的大网按实际网体处理。

## 编译与运行时

- 新增 `CONFUCIAN_SAGE`：贯穿袍体、肩线、双侧袍摆、阔袖、头环、儒帽、三缕长髯、双眼星点和旋转腰环。
- 新增 `FORMATION_ROD`：平行杆芯、上下端环、三枚铭文节点和叉形顶冠；大量副本通过既有跨帧公平采样分批显形。
- 新增 `RUNE_STELE`：收顶厚碑板、加宽台座、横竖晶槽、圆形封印、斜刻线与中心星芒。
- 三类轮廓均经层内 `emitFigurePrimitive` 分发，并纳入复杂轮廓最低 2 粒预算；固定 `emitAuthoredShape` 52-shape switch、每层 8 粒、事件 7/16/30、named copies 72 上限均未改变。
