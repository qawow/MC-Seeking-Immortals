# 2026-06-30 0.1.68

## Change summary

- Added `runClientNoPatchouli` for local single-player regression when the Patchouli dev runtime crashes before the main menu.
- Added a `noPatchouliDevRuntime` Gradle property path that excludes Patchouli only from runtime configurations for that nested dev launch.
- Kept normal Patchouli optional support intact: compile API, normal dev runtime dependency, `mods.toml` optional declaration, and guide resources were not removed.
