# 0.2.251 Q-B-5 NPC 对话、选择、商店、拍卖、声望与规则告知事件的结构化任务证明

## 范围

本批实现后续实施计划 Q-B-5（Q-B 系列最后一个事件域）：为 NPC 对话（NPC_DIALOGUE）、规则告知（INFO_ACKNOWLEDGED）、对话选择（CHOICE_COMMITTED）、商店（SHOP_TRANSACTION）、拍卖（AUCTION_TRANSACTION）和声望（REPUTATION_REACHED）事件补齐结构化任务证明生产与校验。Q-B-1 至 Q-B-5 全部完成后，95 个详细任务步骤的全部事件域已接入统一证明服务。不含网络包字段、顺序、类型、注册或频道行为变化，`ModNetwork.PROTOCOL_VERSION=31` 保持不变。

## 完成内容

### 可信令牌映射（纯函数）

- `PROOF_NPC_MAPPINGS`：`qianzhu_teacher` → 真实 NPC `npc_qianzhu_mechanic`（千竹机关师）。
- `PROOF_SHOP_MAPPINGS`：`star_palace_registry`→star_registration/star_palace_patrol_supply、`inverse_star_smuggle`→inverse_black/inverse_star_black_market、`reincarnation_trade_desk`→reincarnation_desk/nether_ferry_vendor（与 `DialogueActionExecutor.canonicalizeShop` 一致）。
- `PROOF_AUCTION_MAPPINGS`：`dajin_wanbao_auction` → 拍卖场 `wanbao_auction`。
- `PROOF_FACTION_MAPPINGS`：`huangfeng` → 真实声望账本键 `huangfeng_gu`（`tianyuan` 身份直配）。
- `INFO_CHOICE_SOURCES` / `CHOICE_COMMITTED_SOURCES`：规则告知/对话选择令牌 ← 服务端对话树节点：(tree_sect_contribution_clerk, quota_shop)→blood_forbidden_window、(tree_star_palace_registrar, inverse_block)→star_palace_rejection_rule、(tree_tianyuan_registrar, pay_portal)→fengyuan_gate_contribution_rule、(tree_tianyuan_registrar, jobs)→tianyuan_garrison_board（Q-B-2 指定入口）、(tree_zhenyan_lecturer, accept_lesson)→true_word_lecture/true_word_basic_drill、(tree_reincarnation_clerk, intro_quest)→reincarnation_backlash_terms、(tree_inverse_star_contact, cipher)→inverse_star_cipher。

### 校验

- NPC_DIALOGUE / SHOP_TRANSACTION / AUCTION_TRANSACTION / REPUTATION_REACHED：事件令牌必须属于路由令牌证明集；REPUTATION_REACHED 以服务端声望账本实时值 ≥1 为准。
- INFO_ACKNOWLEDGED / CHOICE_COMMITTED：事件令牌必须与路由令牌严格相等，令牌只能由服务端对话节点映射产生。
- 历史回放只使用服务端记录事实。

### 生产点接线

- `QuestHookRuntime.onDialogueNode` → `recordDialogueNode(player, npcId, treeId, nodeId)`：一次节点访问同时产生 NPC 对话证明与映射令牌的规则告知/选择证明。
- `ShopService.handleClientAction`：购买成功后记录 `recordShopTransaction(player, normalizedShop)`。
- `AuctionSoftService.bid`：出价提交成功后记录 `recordAuctionTransaction(player, venue.id())`（场馆来自服务端快照）。
- `ReputationService.add`：声望达正值后记录 `recordReputationReached(player, factionKey)`。

### 历史

HISTORY_TAG 记录新增 `Npc`/`Choice`/`Shop`/`Auction`/`Faction` 字段；`eventFromHistory` 可重建全部 Q-B-5 事件。
