# 0.2.248 Q-B-2 地域、维度、秘境和结构事件的结构化任务证明

## 范围

本批实现后续实施计划 Q-B-2：为地域、维度、秘境和结构事件补齐结构化任务证明生产者与校验，并同步四类路由分类修正。不含网络包字段、顺序、类型、注册或频道行为变化，`ModNetwork.PROTOCOL_VERSION=31` 保持不变。

## 完成内容

### 可信世界上下文事件

- `DetailedQuestProofEvent` 新增服务端世界上下文：`dimensionId`、`currentRegionId`、`secretRealmId`、`sessionId`、`phase`、`packedPosition`、`hasPosition`、`authorityId`，并提供 `regionEntered`、`dimensionEntered`、`secretRealmLayerEntered`、`structureFormed`、`spiritualRootTested` 类型化工厂。路由参数仍只含目录要求字段，客户端不能输入可信世界上下文。

### 校验收紧

- `authoritativeState()` 为非修炼域补齐：REGION_ENTER 要求现场地域与事件一致或绑定秘境会话；DIMENSION_ENTER 比较传送完成后的 `player.level().dimension()`；STRUCTURE_FORMED 要求目录存在、`isStationFormed` 为 true、且 `MultiblockOperationalService.isCommissioned`（只读，不通过 `ensureState()` 创建状态）；SPIRIT_ROOT_TESTED 检查 `cultivation.isSpiritualRootTested()`。
- 深层秘境 ID（`bf_water_jiao`、`zm_candle` 等）只能由绑定玩家、会话、session 和阶段的可信服务端事件生成；普通地域路径无法伪造。

### 生产点接线

- 地域传送成功 → `recordRegionReached`（现场地域校验）；维度传送成功（DimensionTravelService/AscensionService/专属秘境维度进入）→ `recordDimensionEntered`。
- 秘境入口/中/核心/主动退出 → `recordSecretRealmEntry` / `recordSecretRealmLayer` / `recordVoluntaryExit`；超时与死亡遣返走非主动路径，不产生 `blood_forbidden_exit_array`。
- `MultiblockOperationalService.form()` 仅在材料事务完成且 `forceIntact()` 成功后记录结构证明；`DialogueWorldActionService.markStructure()` 只标记真实成型、正式启用且维度匹配的结构。
- `LingGenTestStoneItem.testPlayer()` 成为 `spirit_root_test` 的唯一生产点。

### 分类修正

- `spirit_root_test` → `SPIRIT_ROOT_TESTED`（producer `spirit_root`）。
- `tianyuan_garrison_board` → `INFO_ACKNOWLEDGED`（choice=tianyuan_garrison_board），可信入口留待 Q-B-5。
- `zm_candle` → `REGION_ENTER`，仅由 fallen_demon_valley core 会话事件生产。
- `hy_core` → `ITEM_ACQUIRED`（item=tai_yang_jing_huo），留待 Q-B-3。

### 历史与回放

- HISTORY_TAG 新记录为 CompoundTag（类型、eventKey、observedLayer、世界上下文），兼容旧 boolean 修炼历史；地域/维度只回放服务端记录过的事实；结构回放重新验证原维度、原坐标结构仍成型并启用；死亡克隆继续独立复制 LEDGER_TAG 与 HISTORY_TAG。
- 链启动后立即 `replayCurrent`，此前记录的事实无需等下次登录即可结算。
