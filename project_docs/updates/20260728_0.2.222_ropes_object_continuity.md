# 0.2.222 绳索独立轮廓与器物连续显形

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.221` 升至 `0.2.222`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 全量回读结构化 `visual_descriptions` 中含“绳/索”的 13 条引文，实际映射金索、黑青绳索、红丝化火索、银焰化绳和红绳捆束；`思索`、`搜索` 等词内假命中不进入规则。
- `technique_1071` 明示“绳索般的东西”是九头魔蟾长舌，`technique_825` 明示“粗索般”是拉长的怪兽身体，两者均由回归测试禁止生成 `magic_rope`。
- `immortal_rope`、`ghost_bind`、`soul_banner_wave`、`miaoyin_zither_domain`、`kunwu_tower_bind` 的多表模板引文使用精确 profile id 绑定主体，避免通用帧文案退化为光团、人影或残影。
- 继续回读聚魂钵、鼎上/鼎外/铜鼎、紫色铜炉、方盒/玉匣/匣盖，以及真实婴火、银色火焰、黑青火焰和五色寒焰；所有新增词均为实体或实际火焰，不使用裸“绳”“盒”“焰”泛词。

## 编译与运行时

- 新增 `MAGIC_ROPE` 层内 primitive。Lodestone 轮廓由纵向绳芯、2.5 圈螺旋绳体、两道收紧束缚圈和双端星芒组成；2 粒最低副本预算仍保留绳芯与中心束缚圈。
- 具名捆仙绳/缚鬼索各 16 条时间轴引文持续保留绳体。五道金弧化金索为 5、五根火索为 5、数根火索以 5 表达、双足束缚为 2，其余实体绳索为 1。
- 红丝阶段复用 `blood_thread`：十根/十道为 10、十余根/周身密布为 12、几根并最终化五索为 5；火索、火鸟、符箓、地面伏线等伴随层继续共存。
- 聚魂钵复用 `ritual_bowl`；鼎/炉、盒匣、招魂幡、妙音琴、昆吾塔分别复用 `cauldron_vessel` / `alchemy_furnace`、`magic_box`、`banner_streamer`、`spirit_qin`、`pagoda_tower`，并保留寒焰、符文、声波和封印环。
- `emitAuthoredShape` 的 52-shape switch 未改；新轮廓仍经层内 `emitFigurePrimitive` 分发。每层 8 粒、事件 7/16/30、named copies 72 和公平采样预算均未提高。

## 调色与路径

- 金索为 metal，黑青绳为 `yin→wood`，红绳/火索为 fire，银焰绳为 `qi→fire`；束缚、盘旋、缠绕和捆绑采用 `ORBIT`，出击/扩散阶段保留原时间轴路径。
- 聚魂钵为 yin，铜鼎为 metal，紫铜炉为 yin、其婴火为 fire；银焰为 `qi→fire`，黑青火焰为 `yin→wood`，五色寒焰为 `qi→water`。
- 玉匣/玉盒为 `qi→water`，金属方盒为 metal；招魂幡固定 yin，妙音琴及声波固定 yin，昆吾塔及封印符环固定 earth，避免伴随人物衣色或火焰重染主体。
