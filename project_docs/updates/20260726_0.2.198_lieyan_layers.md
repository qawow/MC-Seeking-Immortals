## 背景

对账后 P1 首项：五个点名核心功法中，玄阴经（4 层）、大衍诀（5 层）、天符灵经（4 层）、掩月周天功（3 层）均已有真实层数带，唯烈焰功仍是 v125 自动生成的退化单层矩阵——`total_layers: 1`、唯一一层挂 NASCENT_SOUL 带，与其"火属性入门、炼气可学"的定位（`realm_min: QI_REFINING`、描述"可修火弹、炎爆一类低阶火术"）直接矛盾：炼气期学了功法却一门术法都解锁不了，直到元婴才一次性拿到烈焰真火秘。

## 设计

五层真实层数带，术法全部取自运行时数据集已存在且经 authored 特效通道可执行的火系条目：

| 层 | 层名 | 境界带 | 解锁术法 |
| --- | --- | --- | --- |
| 1 | 火种初燃 | QI_REFINING | spark_art 火花术、fire_bullet_art 火弹术 |
| 2 | 聚炎成环 | QI_REFINING | flame_ring 火环术、fire_talisman 烈火符 |
| 3 | 燎原火雨 | FOUNDATION | fire_rain 火雨术、elemental_burst_fire 火系爆发术 |
| 4 | 遁焰通灵 | FOUNDATION | fire_escape 火遁术 |
| 5 | 真火大成 | NASCENT_SOUL | lieyan_true_fire_secret 烈焰真火秘 |

- 层 1/3 呼应功法描述"可修火弹、炎爆一类"；层 5 保留原有压轴术法，反查索引同步改指层 5。
- `stageCount == maxLayers == 5` 走 `MethodLayerTechniqueService.actualThreshold` 的精确逐层映射（无比例分带歧义）。
- 境界带字符串 QI_REFINING/FOUNDATION/NASCENT_SOUL 均经 `Realm.fromDesignId` 白名单验证可解析（FOUNDATION → FOUNDATION_ESTABLISHMENT）。
- 全部 8 个术法 id 均在运行时数据集 `data/seeking_immortals/cultivation/*.json`（477 条）中存在，维持矩阵 0 孤儿不变量。
