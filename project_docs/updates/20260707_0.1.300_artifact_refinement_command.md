## Implemented

- `ArtifactDataService` now exposes exact `materials` from artifact refinement recipes.
- Added `ArtifactRefinementService`, a server-authoritative command refinement path.
- Added `/seeking_immortals artifact refine <recipe_id>`.
- Refinement validates cultivation data, realm gate, mapped material item ids, registered item availability, and exact inventory counts before consuming materials.
- On success, the command gives the existing artifact carrier; on failure, source materials are consumed.
- Low flying sword now has an exact command path for 4x mapped low spirit iron and 8x spirit-stone shards.
- Recipes with missing material mappings, such as Qingye fan's `ironwood`, fail before consumption.
