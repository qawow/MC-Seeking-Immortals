# 2026-07-19 0.2.20 状态伤害与旅行权限深化

## 范围

延续 0.2.18 权限审查，处理目录旅行费用旁路、传送取消后的错误提交、未知维度持续飞行回授、M10 Boss 状态占位、M14 状态生命周期与命中缺口、明确的 M02 状态生产者、匿名玩家魔法伤害、术法 PvP、投射物共享倍率/战斗结算和 M15 背包协同扫描。5 名 max 前置审计与 3 名 max 补丁复审分域覆盖这些链路。

## 实现

- `DimensionTravelService.travelToDimension` 在 matrix 前优先解析 authored route，并统一调用 `travelByRoute` 扣除贡献、失败退款；跨维 `teleportTo` 后验证实际 level，成功后才生成平台并写返程点、冷却、区域和飞行状态。
- `FlyingAuthorityPolicy.permitsManagedFlightDimension` 为持续 tick 提供 fail-closed 维度门禁；未知/第三方维度清理飞剑 active key 与全部 `FlyingAuthority` 来源，创造/旁观不再被 policy 采样为生存基线。
- `BeastBossService` 只发布已注册 canonical 状态，beneficial 状态施加给 Boss、有害状态施加给目标；guaranteed encounter API 保留 Boss caster 但跳过当前不适用于非玩家 Boss 的玩家境界命中检定；每阶段成功施放后归零 elapsed cooldown，无目标不推进。
- `StatusRegistry` 返回 `addEffect`/`removeEffect` 的真实结果，带 caster 调用来源重载，抗性时长限制在 `[1, requested]`；状态 catalog/effect 增加 `accuracyDelta`，`CombatCalculator` 聚合后 clamp 到原有 0.99 命中上限。
- `PoisonAntidoteService` 的 emergency 只忽略 `fails_on`，不再越过 `clears_families` 清除护体、剑意或敛息等无关状态。
- `SelfBuffSpell` 支持可选 canonical 状态并与原版 buff 使用同一等级时长缩放；血祭、天魔狂化、敛魂符与剑合一分别生产 `berserk`、`conceal_qi`、`sword_intent`，不再误用位移或火弹效果。
- 21 个技能类与 `ArtifactActivationService` 的玩家魔法伤害改为 caster-aware `indirectMagic(player, player)`。所有伤害术法目标选择统一检查 `canHarmPlayer`；自定义投射物先应用共享倍率，再进入 PvP 命中/闪避/暴击/防御，且只有 `hurt` 成功才附加控制；两个投射物补齐父类 NBT 读写。
- `ArtifactSynergyService` 只扫描主手、副手和 Curios，对 capability 缺失、境界不足、他人所有、需认主但未认主和完整性为零失败关闭；破损法宝不能借本命零消耗绕过主动技门禁。
