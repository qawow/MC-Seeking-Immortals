# 0.2.65 多方块运行态与修理事务

## 本批完成

### 持久运行态
- 新增 `MultiblockOperationalSavedData`：按维度/工站 id/原点记录 `intact/damaged/critical/disabled` 与耐久。
- 效率曲线对齐语料：intact 100% / damaged 60% / critical 20% / disabled 0%。

### 运行时服务
- `MultiblockOperationalService`：
  - `inspect` 查看成型与运行态；
  - `repair` 灵石碎片预留→提交→失败退款；
  - `dismantle` 置 disabled 并按效率部分返还碎片到 outbox；
  - `bestNearbyEfficiency` 供软制作工站门禁。
- `CraftWorldSoftService.requiresNearbyStation` 要求附近成型且效率 > 0（禁用工站不可制作）。

### 命令
- `/seeking_immortals station inspect|repair|dismantle <id>`（dismantle 需 permission 2）。

### 测试
- `MultiblockOperationalServiceTest`：效率曲线、修理成本、预留顺序、软制作门禁源码契约。
