# 0.2.149 方块模型与五行灵石矿

## 变更分类

代码、方块资源、数据包与 worldgen 行为变更。`mod_version` 从 `0.2.148` 升至 `0.2.149`。未修改网络包字段、顺序、类型、注册或频道行为，`ModNetwork.PROTOCOL_VERSION` 保持 `28`。

## 方块资源与模型

- `scripts/generate_block_textures.py` 现在确定性维护 104 张 16x16 RGBA 全不透明方块纹理；矿脉、丹炉、炉盖、阵核、界门、工站的顶面/侧面语义被拆开，重复像素组和复渲染差异均为 0。
- 新增 7 个共享 `elements` 模板：丹炉、炉盖、阵法核心、炼器炉、聚灵阵盘、阵台和工站。
- 42 个状态模型接入模板：五阶丹炉及成型态、五种炉盖、十五种阵核、六阶炼器炉、聚灵阵盘、三种界门/传送控制器、符箓台和傀儡装配台。
- 37 个可获得控制器由同名 blockstate 和 BlockItem 反向到达三维模型；5 个丹炉 `*_formed` 只作为状态模型。目标方块使用 `noOcclusion()` 并保留与模板高度一致的 VoxelShape。

## 五行矿与生成修复

- 新增 `metal_spirit_ore`、`wood_spirit_ore`、`water_spirit_ore`、`fire_spirit_ore`、`earth_spirit_ore`，接通方块/物品注册、创造栏、双语、方块状态、方块/物品模型、贴图、掉落、工具标签、Forge 矿物标签和自然生成。
- 五行矿分别掉落对应下品灵石，支持精准采集、时运与经验。旧 `spirit_ore` id 保留，非精准采集时等权随机掉落一种五行下品灵石。
- 旧灵石矿生成 count 从 8 调到 3，五行矿各 count 1，合计仍为每区块 8 次尝试；旧灵石矿和下品灵铁矿补齐 deepslate target。
- 阴精矿将主世界石料与下界基岩规则拆成独立 configured/placed feature。下界目标使用 1.20.1 实际存在的 `minecraft:base_stone_nether`，覆盖下界岩、玄武岩与黑石。
- 物理灵脉矿体保持 14% 下品灵铁、6% 阴精，其余 80% 按山地/森林/水岸/平原偏置金木水火土矿。

## 剩余风险

- 自然生成只影响新区块，仍需实机抽样矿量、垂直分布与五行占比。
- 仍需检查三维 BlockItem、掉落物/手持构图、模型与粗包围盒碰撞边角、多方块组合外观以及第三方资源包覆盖。
- Forge biome modifier 按 biome tag 注入；复用同一原版 biome 的自有维度会继承这些矿物。严格 dimension-key 隔离需要后续自定义 placement filter 与专服回归，不能由现有 biome tag 测试证明。
