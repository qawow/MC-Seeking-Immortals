# 0.2.11 竹简青衿 — 全前端 UI 竹简气候重设计

日期：2026-07-18

## 目标

在 0.2.10 暖漆问道录之上，把气候从暖漆金木改为 **竹简青衿**：
外门弟子的山村竹简手札——青竹框、竹荫底、竹纸正文、黛墨次要、朱砂印主操作。
谦逊清爽，不是土豪金，也不是临床冷玉。不改布局与协议。

## 变更

### ImmortalUiSkin 色板

- `JOURNAL_BORDER` → 青竹绿 `#6B8F5A`（去古铜金 `#D4BC78`）
- `JOURNAL_VOID/PANEL/INNER/HEADER` → 竹荫系
- 正文/次要 → 竹纸 `#E6E0C8` / 黛灰纸 `#A8A890`
- 玉语义改为竹青 `#7A9E6A`；修为填充同步竹青
- HUD / 技能轨半透明 token 同步竹荫，**alpha 不变**
- 遗留 `PANEL_*` / `TOOLTIP_*` / `STATUS_*` / skill 边框对齐同一竹简气候
- `JOURNAL_RIM_INNER` → 嫩竹高光 `#90B070`

### 绘制层细节

- `drawLayeredPanel`：双阴影 + 双调竹边 + 竹纸纹 + 大面板竹节纹 + 竹节角标/侧标 + 朱砂印
- `drawTitleBar`：朱砂侧条、双底线、右侧竹节短标（替代暖漆装订金线）
- `drawInnerFrame`：双调内嵌竹井
- `drawListRow` / `drawButtonBackground` / `drawTooltipPanel` / `drawControlBox` / `drawCornerMark`：边色走竹青
- 新增私有 `drawBambooNodeMark`

### 贴图

- 重生成 `paper_texture.png`：竹纸纤维，低 alpha 可平铺
- 调整 `jade_texture.png`：竹青微纹，低饱和
- 新增 `bamboo_grain_texture.png`：深竹节/竖纹，大面板低 α 叠层

### 标题字色

- `AbstractJournalScreen` / `AbstractJournalContainerScreen` 标题由 `JOURNAL_BORDER` 改为 `JOURNAL_PAPER`（框仍竹青，字用竹纸）

## 版本与协议

- `mod_version`：`0.2.10` → **`0.2.11`**
- `PROTOCOL_VERSION`：**保持 24**（纯客户端皮肤，无 packet 变更）
