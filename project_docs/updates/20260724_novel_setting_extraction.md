# 原著设定提取 — 文本材料 v148 / v149

**完成时间**: 2026-07-24
**版本**: mod_version 0.2.173（未 bump，见变更类别）
**变更类别**: 设定数据 / 文档（`文本材料/` 独立自版本化设定层，非代码/资源/数据包）

## 背景

用户要求：全量阅读 `root/work/原著` 下两部小说（《凡人修仙传》《凡人修仙传仙界篇》，合计约 35MB / 4795 章 / 1100 万字），
把其中的**设定、材料、法宝、法术**及其**描述与视觉描述**提取到 `root/mc-mod/文本材料`。
用户先要求程序化提取（v148），后明确要求**不要使用脚本、改为人工精读**（v149）。

## v148 — 关键词扫描版（脚本）

- 方法：以既有 `data/` 实体词典 + 境界/地理/势力词表（2229 词）构建 Aho-Corasick 自动机，单次扫描全文。
- 产出：命中 445 实体（法宝 66 / 法术 98 / 材料 121 / 异兽 62 / 设定 98），视觉描述原文句 848 条。
- 文件：`data/novel_extract_{artifacts,techniques,materials,beasts,settings,index}_v148.json`，`docs/NOVEL_EXTRACT_v148.md`。
- 特点：覆盖广；但句子是"含实体名的句子"，未必是描写。

## v149 — 人工精读版（非脚本）

- 方法：沿全书弧线逐段**阅读原文**（七玄门·神手谷 → 黄枫谷·血色禁地 → 乱星海·坠魔谷 → 灵界·玄天 → 仙界篇·北寒仙域·黑风海域），
  凭理解概括设定，视觉描述均为**原文逐字引用**。
- 产出：高保真条目 46 条（设定 12 / 法宝 8 / 法术 11 / 材料 10 / 异兽 5），每条含出处、设定概括、原文视觉描写。
- 文件：`data/novel_curated_{settings,artifacts,techniques,materials,beasts,index}_v149.json`，`docs/NOVEL_CURATED_EXTRACT_v149.md`。
- 特点：条目少而精、每条有出处；与 v148 互补。

## 验证结果

- v148 / v149 全部 JSON 通过 `json.load` 有效性校验。
- `git diff --check` 无空白错误。
- `文本材料` 不在 `src/` 内、不参与 JAR 构建，故未运行 `./gradlew build`。
