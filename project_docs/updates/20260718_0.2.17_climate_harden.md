# 0.2.17 四材气候 hardening

日期：2026-07-18

## 目标

在 0.2.16 残留收口之上，把走火危签语义与气候栈行为固化为可测公共契约：

1. 统一 HUD / 修仙玉简的走火阈值与字色 helper
2. 删除 Stats 内局部重复/死代码
3. 新增纯 JUnit 气候栈测试（不依赖 GuiGraphics）
4. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### 共享走火 helper

- `ImmortalUiSkin.QI_DEV_WARN_THRESHOLD = 50`
- `ImmortalUiSkin.QI_DEV_DANGER_THRESHOLD = 70`
- `ImmortalUiSkin.qiDevRiskColor(risk, calm)` / `qiDevRiskColor(risk)`
  - ≥70 → `JOURNAL_CINNABAR_BRIGHT`
  - ≥50 → `JOURNAL_WARNING`
  - 否则 → calm（默认 `JOURNAL_PAPER`）

### 接线

- `CultivationHudOverlay`：删除局部 50/70 常量；`coreLine` / `coreLineColor` 走共享 helper（平静色仍为玉简强调字）
- `CultivationStatsScreen`：走火行改 `ImmortalUiSkin.qiDevRiskColor`；删除局部 `qiDevRiskColor` 与未使用的 `dangerColor`

### 测试钩子与单测

- package-private：`climateStackDepthForTest()` / `forceResetClimateForTest()`
- 新增 `UiClimateStackTest`：
  - 默认竹简色板
  - push 玉简重绑 paper/border，pop 还原
  - `withClimate` 异常仍还原
  - 嵌套 push 顺序
  - null → bamboo safe
  - 走火阈值边界
  - 暖漆兼容别名（`COLOR_TEXT_*` / `PANEL_BORDER` / `HUD_BORDER`）

### 审计（本轮确认无新增代码债）

- client 屏无静态 `ImmortalUiSkin` 色冻结
- 屏内无裸 body hex（色板仅在 `UiClimate` / `ImmortalUiSkin` 默认值）
- 无 `JOURNAL_BORDER` 当 `drawString` 字色
- 突破 Danger 已在 0.2.16 接线

## 版本与协议

- `mod_version`：`0.2.16` → **`0.2.17`**
- `PROTOCOL_VERSION`：**保持 24**
