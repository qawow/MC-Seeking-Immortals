# 0.2.12 竹简青衿 — 残留屏与 HUD 细节 polish

日期：2026-07-18

## 目标

在 0.2.11 竹简气候 token/绘制层之上，做完整 polish：

1. 残留屏标题/分区标题字色统一为竹纸层级
2. 遗留 `drawSkillSlot` 改走 `drawJadeSlipSlot`
3. 列表行统一 `drawListRow`
4. HUD/皮肤竹节纹与竹笺细节加深
5. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### 标题与分区字色

- 真标题：`TechniqueEdit` / `MethodTree` / `Meditation` / `LifeSkillTree` / `QuestTracker` / `Dialogue` / `Shop` / `Auction*` / `Sect*` / `Worldpack` / `MarketHall` / `AbstractLore` / `StorageBracelet` / `RefinementPlan` / `CultivationStats` header → `JOURNAL_PAPER`
- 分区标题条（`drawTitleBar` 上的 section label、shop stock、technique panes、method detail 图标题）→ `JOURNAL_PAPER` 或 `JOURNAL_JADE_TEXT`
- HUD：`BreathingHudOverlay` 标题、`CultivationHudOverlay` 境界行 → 竹纸；进境行 → 竹青字；技能轨占位首字 → 竹纸

### 槽位与列表

- `TechniqueEditScreen` / `AlchemyFurnaceScreen`：`drawSkillSlot` → `drawJadeSlipSlot`
- `BestiaryScreen` / `ChronicleScreen` / `QuestTrackerScreen`：原始 zebra fill → `drawListRow` + `InteractionState`

### ImmortalUiSkin / HUD 细节

- `drawStatusStripChrome`：玉简注释改为竹笺；叠 `BAMBOO_TEXTURE`；满条加竹节侧标
- `drawBreathingTablet`：竹纹 + 朱砂侧条
- `drawHudPanel`：宽卡叠纸纹 + 右侧竹节
- `drawJadeSlipRail`：高轨叠竹纹 + 两端竹节（半透明轨仍不抬 alpha）
- `drawJadeSlipSlot`：大号已填槽底部竹节短标
- `CultivationStatsScreen.drawSeal`：复用 `drawCinnabarSeal`

### 明确不动

- Layout / `ImmortalHudLayout` 几何
- 网络 packet / `PROTOCOL_VERSION`
- 技能图标全量重画、`cultivation_progress_bar.png` 美术重制（仍为未接线旧资产）

## 版本与协议

- `mod_version`：`0.2.11` → **`0.2.12`**
- `PROTOCOL_VERSION`：**保持 24**
