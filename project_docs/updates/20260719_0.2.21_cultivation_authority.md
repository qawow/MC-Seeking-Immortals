# 0.2.21 修炼权限与存档红线

## 范围

全仓库 max 子代理审计首先确认三条可直接复现的修炼红线：未来仙界境界被解析为炼气、术法冷却在 capability 反序列化时清空，以及真仙高倍率属性强转 `int` 后变为负数。同步收口凡人初始值和渡劫阶段数与发布语料不一致的问题。

## 修复

- `Realm.fromDesignId` 统一识别 `_EARLY/_MID/_MIDDLE/_LATE/_PEAK` 后缀；`ProgressionGateApi` 与 `WorldpackGameplayService` 对空门槛保持放行，对非空未知境界拒绝。
- `TechniqueDataManager` 不再把未知境界回退到炼气，`TechniqueEntry` 不再覆盖解析失败结果，`TechniqueGateService` 对缺失定义和不支持境界 fail-closed。
- `PlayerCultivation.saveNBTData` 写入 `CultivationNbtVersion=1`，加载器只读取新版本全局时钟冷却；无版本旧冷却按既有迁移策略清空。
- 灵力、神识和生命上限改用浮点中间值并饱和至 `Integer.MAX_VALUE`；凡人初始灵力/神识调整为 50/3。
- `TRIBULATION` 遵循 `subStages=1`，只生成一个 `EARLY` 运行阶段。
