# 2026-07-01 0.1.70 Late-game stats, movement slider, compact HUD

## Summary

- Bumped `mod_version` to `0.1.70`.
- Bumped `ModNetwork.PROTOCOL_VERSION` from `5` to `6` because cultivation sync gained movement fields and a new C2S movement-speed packet was added.
- Retuned realm-derived values toward modest early-game growth and intentionally extreme late-game growth.
- Added a persistent movement-speed scale and a 0%-100% stats-screen slider.
- Reworked the top-right cultivation HUD into compact Chinese short-label rendering.

## Implementation

- `RealmStageConfig` now uses segmented arrays for mana cap, stage span, divine sense, health, mana recovery, cultivation gain, flying speed, attack, and defense.
- `PlayerCultivation` persists `movementSpeedScale`, defaults it to `1.0`, and exposes effective walking-speed bonus as realm bonus multiplied by the scale.
- `ModEvents` applies the effective movement-speed bonus to the vanilla movement-speed attribute.
- `SetMovementSpeedScalePacket` lets the client request a scale change; the server clamps, saves, refreshes speed, and resyncs cultivation data.
- `SyncCultivationDataPacket` and `ClientCultivationData.Snapshot` now sync `movementSpeedScale` and effective `movementSpeedBonus`.
- `CultivationStatsScreen` displays movement speed in the combat section and exposes the slider with 5% steps.
- `CultivationHudOverlay` shows realm/stage, cultivation progress, mana progress, divine sense, and qi-deviation risk with abbreviated large numbers.
