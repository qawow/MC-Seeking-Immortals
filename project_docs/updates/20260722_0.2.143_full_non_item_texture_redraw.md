## 剩余风险

- 多数现有方块模型仍使用 `cube_all` 或在多个面复用同一纹理；当前纹理本身可平铺，但阵纹、门纹和工站正面仍需真实三维场景确认方向与重复效果。
- 实体图集按 Geo UV 区域绘制并通过静态边界/重叠检查，仍需客户端确认模型各面没有错位或镜像。
- 同元素、同 motif 的技能保持家族化轮廓；逐像素唯一不等于 1,392 张完全独立手绘构图。
- 仍需不同 GUI scale、语言环境、第三方资源包和多人客户端下的最终视觉签字。
