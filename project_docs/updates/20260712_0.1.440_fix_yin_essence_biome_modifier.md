# 0.1.440 Fix create-world crash: yin_essence biome_modifier

## Class
Resources / datapack (biome_modifier)

## Root cause
`add_yin_essence_ore.json` used an illegal biomes array:
`["#minecraft:is_overworld","#minecraft:is_nether"]`
Forge `forge:add_features` codec rejects that list and fails registry load while opening CreateWorldScreen.

## Fix
- Rewrite `add_yin_essence_ore.json` to overworld-only tag string (same pattern as spirit/low iron ores)
- Add `add_yin_essence_ore_nether.json` for nether tag string

Unchanged (`13`). No packet fields changed.
