# 2026-07-19 0.2.23 秘境与旅行事务权限

## 范围

延续全仓库 max 子代理审计，收紧玩家可达的秘境入口、界门费用、旅行费用与跨维传送提交边界，并修复服务端构造召唤物时 `archetype` 尚未初始化导致的目标注册崩溃。

## 实现

- 客户端 `ACTION_ENTER` 改为拒绝提示，worldpack 秘境按钮显示“需由界门进入”；`worldpack enter` 与 `catalog spatial travel` 仅 permission 2 可用。受 nonce/距离约束的服务端剧情对话入口保持可用。
- 秘境传送成功后才写返程位置、active realm、session 与 cooldown；专属维度传送失败不再降级到 anchor，绑定界门失败不再执行 fallback 或二次尝试。返回失败保留全部状态且不会再次扣入口费。
- `SecretRealmDimensionService` 与 worldpack anchor 传送均验证实际维度和目标距离，被取消或偏离时返回失败。
- `InventoryReservation` 保存实际扣除的 ItemStack 副本；门票、空间节点、风羽舟票、联盟功勋令、目标节点材料与阴石渡资失败退款保留原始 NBT，满背包只掉落真实余量，退款幂等。
- 七类 placeable gate 先处理 active-realm 返程再预留费用。catalog 诊断校验 authored `dimension_from`、按 authored region 路由，并在任何失败时退回节点费用。
- 客户端 ACTION_SYNC 走只读镜像，开屏同步不再调用默认平台 bootstrap，不能通过重复发包改写 anchor 周边方块。
- `SummonedServitorEntity.registerGoals` 在构造期以 `GENERIC` 兜底，避免空 archetype 的 switch NPE。
