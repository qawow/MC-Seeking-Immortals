# 2026-07-04 0.1.90 breakthrough pill success-rate fix

Change class: code + resources + docs/tests.

## Implemented

- Bumped `mod_version` to `0.1.90` because the shared worktree already used `0.1.89` before this fix started.
- Added a server-side hand-consumed breakthrough-aid helper in `BreakthroughService`.
- Matching breakthrough pills now apply aid only when the held item matches the next breakthrough resource.
- Dual-use catalog pills convert into breakthrough aid only at the bottleneck and only when they match the next major-realm resource; otherwise their normal pill effects are preserved.
- `breakthrough_pill` and Foundation Building Pill still support pre-consuming matching next-breakthrough aid, but existing aid blocks repeat consumption.
- Essence Condensing Pill now uses `PillQuality.getBreakthroughBonus()` for the unified +5%/+10%/+15%/+20% table.
- Successful hand-consumed aid immediately sends `SyncCultivationDataPacket`, so client stats and `/seeking_immortals realm` read the same server value after use.
- Creative-mode preview now uses the same best-available pill bonus that creative breakthrough settlement applies.
