# 0.2.16 四材分层残留收口

日期：2026-07-18

## 目标

在 0.2.15 气候内核之上，收口「静态色值冻结」与「突破危签」两类残留：

1. 修炼玉简屏在 `JADE_SLIP` 气候下不再因 class-init 快照画成竹简色
2. 突破操作显式走 `ImmortalButton.danger`（叠 `CINNABAR_SEAL`）
3. 走火风险字色分层对齐 HUD 危签语义
4. **不改布局几何、不改 packet**；`PROTOCOL_VERSION` 保持 **24**

## 变更

### 静态色别名 → 实时 token

- `CultivationStatsScreen`：删除 `private static final int BAMBOO/JADE/PAPER/...` 类加载快照；正文/框/危签色全部运行时读 `ImmortalUiSkin.JOURNAL_*`
- `MethodTreeScreen`：删除 `LINK/NODE_*` 静态快照；节点/连线色同样实时读气候 token

### 突破与走火

- 突破按钮：`ImmortalButton.primary` → `ImmortalButton.danger`（绘制期 push `CINNABAR_SEAL`）
- 新增 `qiDevRiskColor(int)`：
  - 风险 ≥ 70 → `JOURNAL_CINNABAR_BRIGHT`
  - 风险 > 0 → `JOURNAL_WARNING`
  - 否则 → `JOURNAL_PAPER`

### 审计结论（本轮不改）

- JEI 标题/说明已走 `JOURNAL_PAPER` / `JOURNAL_PAPER_MUTED`
- 未发现 `JOURNAL_BORDER` 当正文 `drawString` 色
- Container 屏依赖 `AbstractJournalContainerScreen` 默认 `WARM_LACQUER`，无需逐屏覆写
- 宗门踢人/离开等 Danger 钮本轮未发现可接线点

### 明确不动

- `ImmortalHudLayout` 几何与 public Layout API
- packet 字段/顺序；`PROTOCOL_VERSION=24`
- 技能正式图标包、自定义书法字体、玩家主题切换器

## 版本与协议

- `mod_version`：`0.2.15` → **`0.2.16`**
- `PROTOCOL_VERSION`：**保持 24**
