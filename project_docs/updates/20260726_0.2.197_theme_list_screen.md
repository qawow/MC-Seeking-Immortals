# 2026-07-26 0.2.197 界面主题列表式选择界面

## 概述

落实 0.2.195 的遗留建议：11 套主题单按钮循环遍历成本高，改为列表式选择界面。修仙面板页眉的主题按钮现在打开一个主题列表屏，点选任一行立即应用并持久化该主题。

## 实现内容

- 新增 `client/UiThemeSelectScreen`（`AbstractJournalScreen` 子屏，`JADE_SLIP` 静室场景，面板上限 300×330 居中）：
  - `ScrollableListPanel` 行列表（行高 20、行距 2）遍历 `UiTheme.values()` 全部 11 套主题；
  - 每行绘制该主题静室场景的 panel/accent/cinnabar 三色样块加主题名（`displayNameKey()` 本地化），当前主题行以 SELECTED 态高亮并在行尾标「当前」；
  - 点选行调用 `UiThemeConfig.select(theme)`：立即重绑 `ImmortalUiSkin` 全部色彩别名并写入 `config/seeking_immortals-ui-theme.properties`，整屏随新主题重绘，天然充当实时预览；
  - 滚轮按行滚动、拖拽滚动、细滚动条；「完成」按钮与 Esc 经 `onClose()` 返回父屏。
- `CultivationStatsScreen` 页眉主题按钮 onPress 由 `UiThemeConfig.select(UiTheme.active().next())` 改为 `minecraft.setScreen(new UiThemeSelectScreen(this))`；`themeButtonLabel()` 保留，按钮仍显示当前主题名；移除未用的 `UiThemeConfig` 导入。`UiTheme.next()` 保留（`InkPaletteTest` 全循环用例仍覆盖）。
- 本地化：zh/en 双语补 `screen.seeking_immortals.ui_theme.title`（界面主题 / UI Theme）、`.hint`（点选主题立即应用并保存 / Click a theme to apply and save it instantly）、`.current`（当前 / Current）。

## 验证结果

- `./gradlew build --no-daemon --max-workers=1` `BUILD SUCCESSFUL in 1m 29s`，`InkPaletteTest` 5 用例继续全绿。
- 构建期间 `authoredSpellEffectsCheck` 因并行会话提交的新输入报过期，重跑 `generate_authored_spell_effects.py`（2,292 profiles）与 `generate_authored_visual_catalog.py`（5,727 profiles）后通过；两个生成 JSON 归属并行生成资源批次，不入本批提交。
