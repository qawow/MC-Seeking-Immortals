# 0.2.229 活化屏风与铭文书页独立轮廓

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.228` 升至 `0.2.229`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- `technique_1478`：山水屏风先泛起白色晶芒，画中山水旋转活化；随后黑色双门从屏风飞出并向两侧分开。
- `technique_605`：老者以铁牌在巨大地图屏风上把银色数字二改成三，韩立再以玉佩射出青光标出数字一。
- `technique_031`：玉盒中金色薄书页与银页同形，页上密布古文。
- `technique_035`：书页光芒收束为密集微小光字，页面如繁星闪耀。
- `technique_399`：黑色书页前悬浮精血，以血书写古文后显出黑焰鬼头，最后蓝光没入书页完成封印。
- `technique_1215`：无数金篆文从书页涌出形成经文，经文随后化为点点灵光消失。
- 规则只绑定上述 profile 与长引文；桌椅背景、阁楼比喻、普通屏幕文本和未显形书册不按裸词命中。

## 编译与运行时

- 新增 `MAGIC_SCREEN` 层内 primitive。几何包含左右立柱、上下框、稳定支脚、山水折线、面内光环和随时间游动的地图星点。
- 新增 `MAGIC_PAGE` 层内 primitive。几何包含四边薄页、折起页角、轻微厚度边与五行有序铭文，避免与带卷轴杆的 `magic_scroll` 或狭长 `jade_slip` 混同。
- 两者接入 `VisualPrimitive`、`emitFigurePrimitive` 与复杂轮廓最低 2 粒预算；契约固定的 52-shape authored switch 未改。
- 精确分派保留已有 `magic_gate`、`command_token`、`channel_stream`、`scripture_glyph`、`magic_box`、`orb_projectile`、`ghost_head` 与 `fire_plume` 伴随层。
- 活化山水、密集光字和无数金篆文不再错误消耗 `projectile_swarm` 层。

## 数量、路径、动作与配色

- 山水屏风为单份 `STATIC/MATERIALIZE`、`qi→water`；门扉飞出阶段仍保留单份静止屏风。地图屏风两阶段均为单份 `STATIC/STEADY`、`earth→metal`。
- 金色盒中书页为单份 metal；青元书页与五藏书页为单份 `metal→qi`。黑色血誓书页按阶段为 `yin→fire` 或 `yin→water`。
- 青元光字为 12 份 `CONVERGE/MATERIALIZE`；血誓古字为 8 份，并保留精血球、鬼头和黑焰。
- 五藏金篆文为 20 份 `DIRECT/MATERIALIZE`，后续经文以 20 份 `STATIC/DISSOLVE` 灵光消散。
