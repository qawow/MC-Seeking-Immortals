# 0.2.141 Lodestone 全量语义 VFX

## 变更

- 将 Lodestone 视觉扩展为 21 种语义 motif，覆盖 81 个术法专用形态，并统一接入普通施法、双重施法和法宝主动技。
- 为同步施法增加 GENERIC 意图捕获与真实服务端几何重放，避免 beam/cone/区域视觉穿墙或重复广播；异步投射物命中仍沿用原有路径。
- 为阵法、多方块、自定义状态和地渊/阴冥/魔隙危害补齐激活、周期、保护、消散、破坏等生命周期视觉。
- 客户端加入 additive/lumitransparent depth-fade、extruding spark、位置震屏、距离 LOD 与粒子预算；服务端视觉异常不影响权威玩法事务。
- 收口阵法世界卸载、方块实体复活、状态脉冲和危害瞬态状态的可靠性边界。
- 最终复核修正自由阵场同步重复包、Lodestone 震屏回升包络、MINIMAL 阵纹截断和元素阵法误配色。

## 版本与协议

`mod_version=0.2.141`。`TechniqueVfxPacket` 新增 `Motif` 字段以及 `STATUS`/`DISSIPATE` 类型，属于不兼容网络格式，`ModNetwork.PROTOCOL_VERSION` 从 `27` 升至 `28`。复核修复没有再次改变包字段、顺序或类型，因此协议保持 `28`。
