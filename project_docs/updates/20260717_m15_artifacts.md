# 2026-07-17 M15 法宝与器灵落地

## 变更摘要

落地 217 件法宝语料全量解析、十一阶品阶缩放/越阶压制、认主 UUID 绑定与器灵觉醒、主动技映射 M02 `SkillEffectRegistry`、协同伤害钩子、拍品/掉落数据服务、飞行法宝与 `FlyingAuthority` 对接，以及草案注册对账报告。

## 实现要点

1. **法宝主数据 / 品阶**
   - `ArtifactDataService` 源文件 16→18：加入 `item_synergy.json`、`artifact_tier_map.json`
   - 结构化解析：eleven_tier_map / taxonomy / grade bands / synergies / combos / realm_drops / faction specialty / wanbao auction / draft / ancient
   - 217 件 `ArtifactDefinition`（含 element/binds/compliance/uses）

2. **认主与祭炼 / 器灵**
   - `ArtifactOwnershipService`：物品 NBT 存主人 UUID；偷取不可用；高阶强制认主
   - 祭炼成功写层数；器灵觉醒门槛：本命 + 层数≥5 + 结丹
   - 与 `NatalBindingService` 协同

3. **主动技 / 压制**
   - `ArtifactActiveSkillService`：effect/type/id → M02 techniqueId，服务端校验冷却与灵力
   - `ArtifactPowerService`：`realm_power_scale` 越阶压制（cost/CD/damage）
   - `ArtifactActivationService` 优先走 SkillEffect，回退 kind 激活

4. **协同 / 飞行 / 对账**
   - `ArtifactSynergyService` + `ModEvents.onLivingHurt` 攻击/防御倍率（不绕过伤害管线）
   - 飞行：`isFlyingCapable` 语料判定 + `FlyingAuthority.SOURCE_ARTIFACT`
   - `ArtifactDraftReconcileService`：draft 22 件全可解析；unique 限制集合

5. **验收测试**
   - `M15ArtifactCorpusTest` + 既有 artifact 测试全绿
