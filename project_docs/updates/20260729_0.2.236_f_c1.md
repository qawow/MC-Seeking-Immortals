# `0.2.236` F-C1 任务、对话、编年史与 Lore 交互收口

## 变更

- `QuestTrackerScreen` 的筛选只改变可见列表，不再改写全局选中任务；被筛选隐藏的任务仍保留详情并明确提示。
- `ClientPacketHandlers` 拒绝对话包覆盖 `AbstractContainerScreen`，同一权威会话可以刷新现有对话屏。
- `DialogueScreen` 的动作闩记录 tick，100 tick 无回包自动恢复；屏幕重建继承真实 pending 状态。
- 编年史未解锁的事件和时间线统一显示锁定文本，列表和详情均不泄露真实名称。
- `AbstractLoreScreen` 增加详情内容测量、滚动条和边界钳制；选择变化才重置详情滚动。
- NPC 招呼语仅在新会话首次初始化播放，resize/init 重建不会重复播放。
