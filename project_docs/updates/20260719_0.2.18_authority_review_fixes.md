# 2026-07-19 0.2.18 权限审查修复

## 范围

收口审查报告中的 13 条 P1/P2，覆盖维度旅行、飞升库存回滚、秘境会话、NPC 对话、任务链接、法宝主动技、区域同步、维度飞行和状态消费端。6 个 `gpt-5.6-sol`、`reasoning_effort=max` 子代理并行审计各链路，主代理逐项复核并整合。

## 实现

- `DimensionTravelService` 解析发布数据的 `from_dim`、`to_dim`、嵌套 `methods[]`、`one_way_main_body` 与方法级门槛；拒绝空目标、错误来源、逻辑实例和未实现直达路线。贡献费用由路线权威扣除，失败自动退款，成功后同步区域。
- `AscensionService` 保留物品留在原槽，仅移除重置物品；失败回滚先清空当前库存，再按备份槽位覆盖恢复；起步礼包仅在成功传送后幂等发放。
- `SecretRealmProgressSavedData` 与 `SecretRealmSessionService` 使用 overworld 统一时钟；party 容量按 `expiresAtTick` 计算，离线超时会话不再永久占位。
- `DialogueBranchService` 精确解析整数贡献阈值和数组效果参数。`NpcDialogueApi` 仅在 immediate effect 全部成功后发布事件、claim、加好感和清终端会话。
- `DialogueActionExecutor` 的血色禁地入口统一走 `WorldpackGameplayService.enterSecretRealm`；付费界门统一走 `DimensionTravelService`/worldpack 权威；任务只由成功后的 `DialogueNodeReachedEvent` 结算一次。
- `QuestHookRuntime` 保留 authored exact link，按 effect destination 精确匹配，只有无精确项时才回退 authored bare link，并对任务 id 去重。
- `ArtifactActivationService` 在 mapped cast 前统一校验境界、冷却、完整性和次数；`ArtifactActiveSkillService` 用 `UNMAPPED`、`DENIED`、`SUCCESS` 区分回退语义，破损法宝不能继续施法。
- `RegionRegistry` 优先解析当前精确维度，再协调 preferred region；跨维度后写回正确区域。`FlyingAuthorityPolicy` 精确分类维度，Nether、End 和第三方未知维度默认拒绝模组免费飞行，凡界炼气门槛为十层。
- M14 状态消费端一并合入：`outgoingDamageMul` 进入 LivingHurt 出伤乘区，`blocksTechnique` 进入主释放/双放共用门禁，`hidesRealm` 进入神识读心境界出口。
