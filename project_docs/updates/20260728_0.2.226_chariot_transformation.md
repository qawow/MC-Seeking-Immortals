# 0.2.226 倚天城巨人、战车与飞舟变形

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.225` 升至 `0.2.226`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- `technique_962` 首条直接引文中的建筑主动幻化为三类城防：高大巨人、巨型战车、巨型飞舟；轰鸣巨响作为同组声波层保留。
- `technique_995` 的战车已被剑丝搅碎，`technique_762` 的战舟是被撕裂/击落目标，`technique_1302/1303/1375` 的灵月飞舟只是法阵、巨石或雷击目标，`technique_1457` 的灵舟仅通过阵法口，`technique_538` 的玉车只是攻击位置，均不生成战车。
- 第二条直接引文仍保留大殿拔地、五色光罩与巨型光球的既有程序语义；本批不把背景建筑或普通飞舟叙事扩大为施法载具。

## 编译与运行时

- 新增 `MAGIC_CHARIOT` 层内 primitive：车体主梁与横梁构成刚性车架，四个竖直轮环附带轮辐，前后轮轴、双柱车盖、顶梁和前撞角共同形成可辨识战车轮廓，撞角端点使用星芒强调朝向。
- 高大巨人复用已有 `PUPPET_FIGURE` 人形骨架，巨型飞舟复用已有 `MAGIC_BOAT` 龙骨、舟艏艉、双舷与甲板肋；三类形体不再退化为单个 `orb_projectile`。
- 修正 `magicBoatShape` 的水平朝向竖轴：由反向 `forward.cross(side)` 改为 `side.cross(forward)`，静止飞舟的船身和抬升舟艏不再向下倒置。
- 新 primitive 接入 `VisualPrimitive`、`minimumCopyBudget`、`emitFigurePrimitive` 与 Lodestone 几何契约；固定 52-shape switch、每层 8 粒、事件 7/16/30 和 72 copies 上限均未改变。

## 数量、路径与配色

- “一只只”以战车、巨人、飞舟各 12 份表达，并继续由运行时 named-copy 分层采样在多帧间公平轮换，避免一次事件突破粒子预算。
- 三类形体均为 `STATIC`，从建筑土石的 earth 过渡为战备金属的 metal；轰鸣 `sound_wave` 为单份相同渐变。
- 战车、巨人、飞舟的垂直偏移分别为 0.03、0.28、1.35，使地面车阵、人形防线和空中舟阵可同时辨识，不会完全叠在同一平面。

## 剩余风险
