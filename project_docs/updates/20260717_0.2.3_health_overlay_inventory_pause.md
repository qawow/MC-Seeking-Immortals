# 2026-07-17 0.2.3 背包/暂停界面保留气血 UI 重构

## 变更摘要

修复打开背包或 ESC 暂停界面时，自定义气血/护体面板消失、原版心形血条可能重新显示的问题。

## 根因

`CultivationHealthOverlay.shouldReplaceVanillaPlayerHealth` 用 `minecraft.screen != null` 同时门控：

1. 自定义左上角气血面板绘制
2. `RenderGuiOverlayEvent.Pre` 对 `VanillaGuiOverlay.PLAYER_HEALTH` 的 cancel

任意 Screen（含 `InventoryScreen` / `PauseScreen`）都会同时关掉替换与取消，导致重构失效。该共享谓词来自 0.1.95，本意是避免 F1/聊天时「只 cancel 不绘制」；但对背包/ESC 过严。

## 实现

- 将 `hasScreen` 语义改为 `screenBlocksReplacement`。
- 新增 `blocksHealthReplacementByClass`：`InventoryScreen` 与 `PauseScreen`（含子类）不阻止替换；聊天与其它全屏仍阻止。
- 渲染与 cancel 继续共用同一公开谓词。
- 其它三块 HUD（修为/技能/吐纳）仍按 `screen != null` 隐藏，本次不改。

## 验证

- 定向：`ScreenLayoutTest`（含 Inventory/Pause 白名单与 Chat 阻止矩阵）
- 完整：`./gradlew build`

## 版本与协议

- `mod_version`：`0.2.2` → `0.2.3`
- `ModNetwork.PROTOCOL_VERSION`：保持 `24`（无 packet 字段/顺序变化）

## 剩余风险

- 第三方替换原版暂停/背包屏的模组不会自动进入白名单。
- 真实客户端 GUI Scale / F1 / 聊天 / 创造模式仍建议人工烟测。
