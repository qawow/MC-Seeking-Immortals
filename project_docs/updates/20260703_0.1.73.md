# 2026-07-03 0.1.73 Five-tier alchemy fire

## Summary

- Implemented five alchemy fire tiers: mortal fire, true-essence dan fire, foundation dan fire, earth fire, and nascent-soul fire.
- Added tier 2-5 alchemy furnace blocks and tier 4-5 furnace lids so furnace body, lid, fire, and recipe tier requirements can match 1-5.
- Added a sect earth-fire room anchor block; earth fire requires a nearby anchor when installing and when starting refinement.

## Gameplay

- Existing `alchemy_furnace` remains tier 1.
- Fire above furnace tier still explodes and can destroy the furnace.
- Fire above lid tier still blows the lid and damages nearby players.
- Recipes now use stronger tier requirements for mid/high/legendary pills, including tier 4 earth-fire and tier 5 nascent-soul recipes.
- Fire installation checks cultivation realm requirements: tier 2 requires Qi Refining, tier 3 requires Foundation Establishment, tier 4 requires Core Formation plus earth-fire room, and tier 5 requires Nascent Soul.

## Resources

- Added creative-tab entries, zh_cn/en_us localization, blockstates, item models, and the earth-fire-room block model for new furnace, lid, fire, and room-anchor content.
- No new PNG textures were added; new models intentionally reuse existing furnace/block/material/fire textures until dedicated art is available.
