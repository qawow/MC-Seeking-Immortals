# 0.2.99 结构 token 诚实化与阵图残卷双路径

## 摘要

修复两类“描述承诺与右键路径分裂”的语义缺口：
1. 结构目录同名 bulk 载体（如 time_acceleration_array、structure_repair_bench）统一诚实 detail，标明为 form/建造/任务组件，单独右键不放置完整建筑。
2. `array_blueprint_scroll` 作为 `CatalogManualItem` 时，首次右键研读；已研读后落回 `FormationItemService.tryUse` 激活自由阵场。

## 变更

- `CatalogItemDescriptionService`：`STRUCTURE_TOKEN_IDS` + 结构目录命中且无 formation 行为 → `detail.structure_token`。
- `CatalogManualItem`：study 优先；双路径手册不在研读时消耗；已研读后 `FormationItemService.tryUse`。
- 双语 lang：structure_token / array_blueprint_scroll detail / formation_after_study。
- 测试：`CatalogItemDescriptionServiceTest` 扩展。

## 验证

- `./gradlew build --no-daemon` 成功；preflight `mod_version=0.2.99`。
- 协议保持 26。
