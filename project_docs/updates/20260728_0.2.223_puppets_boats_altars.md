# 0.2.223 傀儡、飞舟与祭台独立轮廓

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.222` 升至 `0.2.223`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 全量回读结构化 `visual_descriptions` 中真实显形的人形傀儡、移动或传送舟、祭坛/高台、骨戒和星盘引文，不使用裸“傀儡”“舟”“台”“盘”泛词。
- 傀儡仅命中士兵玩偶、士兵傀儡、黑黝木人、数寸小傀儡、白玉/人形/石人/青甲/黑铁/铜人傀儡；傀儡功法说明、兽傀、影傀与单独手臂不扩展为完整人形。
- 飞舟仅命中脚下实际遁走的神风舟、失控训练舟、传送金舟、缩小黑舟与血气幻化小舟；被巨爪撕裂、剑光击碎、神识扫描或仅作为背景的舟船不生成 `magic_boat`。
- 祭台仅命中天卜碧绿石台、法则巨祭坛、银浆聚星台、金色烽燧台、石傀祭坛与八幡高台；人物盘坐和受击背景台面不宽泛映射。
- 黄金雕像、钢叉手掌等比喻保持原形；逆星盘未出现在直接视觉引文中的盘体不凭设定摘要虚构。

## 编译与运行时

- 新增 `PUPPET_FIGURE`：贯穿躯干、肩横梁、加大头环、双臂双腿、胯梁、六关节星点与旋转胸核；最低 2 粒仍保留躯干和肩线。
- 新增 `MAGIC_BOAT`：纵向龙骨、上扬舟艏、舟艉、双舷、底部收束与三道甲板肋；移动舟使用 `DIRECT`，失控训练舟保持 `STATIC` 摇摆语义。
- 新增 `RITUAL_ALTAR`：十字顶面核心、方形台沿、四角支柱、旋转阵心与中心星点；祭坛本体保持静止，光柱、符阵、幡旗和刀气继续作为独立层。
- `emitAuthoredShape` 的 52-shape switch 未改；三类新轮廓仍经层内 `emitFigurePrimitive` 分发。每层 8 粒、事件 7/16/30、named copies 72 和公平采样预算均未提高。

## 数量、调色与连续性

- 两名铁甲士兵、数个召兵、八尊大头木人、四具白玉傀儡和三只青甲傀儡分别为 2/5/8/4/3；其弓、刀、四旗、元婴/圭灵、石傀刀气与十二蓝刺均保留。
- 木人为 `yin→wood`，白玉和无色傀儡为 qi，铁甲/铜人为 metal，青甲为 `water→metal`，黑铁蓝刺为 `yin→water`；未写明材质的傀儡不凭空染金。
- 神风舟 qi、金舟 metal、黑舟 yin、血舟 fire；血舟保留 4 份双翼 primitive，表达两侧各两对晶翅，并保留单道纯火色 `DIRECT` 血迹。
- 碧绿石台 wood、巨祭坛/石傀祭坛/八幡高台 earth、聚星台 qi、金色高台 metal；巨祭坛同句八根圆柱为 8 份静止 `rune_pillar`。
- 五枚骨戒复用 `wheel_disc`，同句五个骷髅头与五道 `qi→water` 寒焰均为 5；百脉炼宝后续戒体继续维持 5 份。移星子母盘、破碎阵盘和北斗天星盘各保留单个 `formation_disc`，破碎冲击修正为 1。
