# 0.2.215 令牌、剪、砖、伞、弓具名视觉

## 变更级别

- 代码、生成数据、测试与项目文档更新。
- `mod_version` 从 `0.2.214` 升至 `0.2.215`。
- 未修改网络包字段、顺序、类型、注册或频道行为，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 全量反查 9,947 条术法视觉引文，逐条回读令牌/玉牌、金剪/雷剪、晶砖/金砖/火砖、玉伞、傀儡大弓及陶羽银铃。
- 只使用“黑色令牌”“令牌上血光”“金银令牌”“金色/青色剪刀”“淡蓝色晶砖”“玉伞”“手持一把大弓”等完整短语。
- 不匹配“弩箭般”“杀手锏”“自投罗网”等比喻，也不把普通鼓胀、盘旋或泛指兵器编译为新物件。

## 编译与运行时

- 新增 `command_token` 12 层：矩形边框、双斜印记、横竖符线与顶部悬孔；黑雾隐遁、灰色磁浪、金色翼蛟、金银光柱及玉牌符文/破碎伴随层保持。
- 新增 `magic_scissors` 2 层：双刃、铰点、双指环；百余丈金剪从全句“百”误读的 12 份修正为 1，青色雷剪为 thunder，并保留鸣响与两条雷蛟。
- “六条水桶粗细的青色雷蛟”由通用 beam 修正为 `serpent_dragon x6`；局部数词绑定不影响其他数量。
- 新增 `magic_brick` 3 层：有厚度的八边砖体与中央印记；晶砖 water+修复光环、金砖 metal+元磁灰霞、火砖 fire+青色光幕均并存。
- 新增 `magic_umbrella` 1 层：伞顶、环形伞沿、八根伞骨与伞柄，使用 qi→metal 表达玉伞被金芒斩开的瞬间，并保留 `blade_arc`。
- 新增 `magic_bow` 1 层：弯曲上下弓臂、绷紧弓弦、箭杆与箭镞，使用 metal→fire 表达傀儡大弓上的红色箭芒；同句黄光厚背长刀继续作为 `flying_blade`。
- 陶羽银铃接入已有 `bell_chime`，银铃为 metal，单一声波 copies=1，被打散的青竹蜂云剑仍保留；已有黑色小钟终色同步收紧为 yin。
- 五种新形象仍只走 `emitFigurePrimitive`，未进入契约钉住的 52-shape `emitAuthoredShape` switch。
