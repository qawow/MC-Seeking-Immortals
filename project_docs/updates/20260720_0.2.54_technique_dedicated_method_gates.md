# 0.2.54 七类专用术法与功法扩展学习门槛

## 本批完成

### 术法七类专用实现
- 为 `ultimate`、`secret_art`、`talisman_consume`、`command`、`craft_gate`、`wall`、`buff_zone` 提供专用运行时：
  - `HighImpactTechniqueSpell`：终极/秘术高冲击范围或束状伤害，读取 damage/range/target/element/tags/effect_key。
  - `TalismanConsumeSpell`：按 effect_key/tags 分流投射、AOE、控制、移动、增益；不二次消耗符箓（包路径已扣）。
  - `CommandTechniqueSpell`：强化附近自有召唤物，无目标时短时自聚神识。
  - `CraftGateTechniqueSpell`：短时炼器增益并绑定/强化附近自有傀儡。
  - `WallTechniqueSpell`：沿视线生成临时 `EARTH_WALL` 并附带路径伤害/减速。
  - `BuffZoneTechniqueSpell`：激活自由阵场并给友军回灵/抗性等增益。
- `AbstractTechniqueEffectResolver` 对上述类型走专用工厂，不再静默降级或直接不可释放。
- 未知抽象类型仍 fail-closed。
- 双语消息补齐七类成功/回退提示；伤害来源权威测试计数更新为 47。

### 功法扩展学习门槛
- `MethodEntry` 加载 `requiredSpiritRoots`、`bonusSpiritRoots`、`requiredFaction`、`factionRelationMin`、`learnSources`、`suggestedItems`、`requiredItems`、`mustConvertAfter`、`requiredConstitution`、`requiredRace`、`regionPresent`、`source`。
- `ProgressionGateApi` 新增 any-of 灵根门槛与纯 token 校验。
- `ManualCatalogService.evaluateLearnGate` 在境界/前置之外接入：
  - 灵根 any-of
  - 体质/种族
  - 转修后禁止初学（`must_convert_after`）
  - 他宗成员硬拒绝；同宗时校验 `faction_relation_min` 品阶
  - 无宗门时保留典籍/遗留学习路径
- 失败提示补齐中英文。
