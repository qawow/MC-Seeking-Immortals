# 0.2.59 储物菜单持续授权

## 本批完成

### 持续授权 helper
- `ArtifactStorageService.isContinuouslyAuthorized(ServerPlayer, ItemStack)`：
  - 空栈 / 不支持栈直接拒绝；
  - 创造模式放行；
  - 法宝储物要求 `ArtifactOwnershipService.canActivate`、境界不低于 `realmMin`、完整性 `> 0`；
  - 便携储物袋仅校验 support。

### 菜单 mutation 再校验
- `StorageBraceletMenu.stillValid` 在实例身份与 `supportsStack` 之外，对服务端玩家调用 `isContinuouslyAuthorized`。
- `clicked` / `quickMoveStack` 入口先 `stillValid`，失败直接返回。
- `removed` 与 `clicked` 写回 handler 仅在 `stillValid` 仍为真时执行，避免授权失效后把脏快照写回。

- 新增 `continuousAuthorizationHelperExists` 覆盖 helper 与菜单 re-check 字符串契约。
