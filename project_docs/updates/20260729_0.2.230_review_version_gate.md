# 0.2.230 审查修复与版本门禁收口

## 变更分类

代码、生成资源、版本配置与项目文档更新。`mod_version` 从 `0.2.229` 升至 `0.2.230`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 当前批次

- `BreakthroughService` 在批量目录缺失 `jiangchen_pill` 时不再直接解引用空注册项，而是记录警告并安全放行该资源门槛。
- `PlayerCultivation` 读档时不恢复打坐状态，并将灵力与神识共同钳制到 `[0, 当前上限]`。
- `ShopQuotaService` 按世界游戏日滚动每日购买计数。
- `ShopService` 的物品货币购买路径补齐鬼修坊市封禁和每日限购，并在成功交付后记录购买次数。
- `authored_spell_effects.json` 与 `authored_visual_catalog.json` 按“spell→visual”依赖顺序重生成；目录规模保持 2,292/5,727 profiles，最终仅同步 Java 审计与下游源哈希。

## 审查意见处理

可发布的 Java 与资源变化原先仍沿用 `mod_version=0.2.229`，导致 `:aiPreflight` 拒绝构建。本批将补丁版本递增到 `0.2.230`，不使用 `-PaiSkipVersionBumpCheck=true` 绕过门禁。
