# 0.2.219 巨剑独立几何与伴随层保真

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.218` 升至 `0.2.219`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- 精确匹配实际显形的 `巨剑`、`石剑`、`巨大光剑` 以及薄金/长青/厚黑三口异形剑。
- 普通“巨剑门”宗门叙事不生成物体；只有可执行的“巨剑门重劈”保留巨剑和斩弧。
- 三色巨剑、六口金剑、四柄石剑、两把同形巨剑与 7/12/36/72 口前置小剑均按各自物件局部绑定。

## 运行时实现

- `VisualPrimitive.GIANT_SWORD` 通过层内分派进入独立 Lodestone 几何：宽阔收尖剑身、中央剑脊、横向护手、握柄与剑首亮点。
- 多副本在 `STATIC`、`DIRECT/TRACK`、`RISE`、`FALL` 路径中获得稳定径向偏移，不再完全重叠；轨迹两端使用相同偏移，避免剑体扭曲。
- 金/黑/红巨大光剑以三层同位颜色轮廓表达；薄金、狭长青、厚钝黑三剑以三个垂直位置表达。
- 巨剑和作者小飞剑同时出现时保留二者，移除语义重复的通用 `projectile_swarm`。

## 伴随保真

- 传送阵角保留符纹，迷蒙青灵光使用 12 份木色弹群，十丈青虹使用单份木色残影。
- 巨剑雷弧与电蟒使用 `metal→thunder`；银色火球、银色火鸟和银焰使用 `qi→fire`。
- 黑色目标光柱固定阴色；灰丝和金丝各自固定阴色/金色；斩首血线固定火色。
- `technique_1310` 的无数黑符为 20 份，单道粗大乌光为 1 份，避免共享数量污染。

## 差异与契约

- 相对 `0.2.218`：39 个预期 technique ID、56 条语义引文组变化，非目标 ID 为 0。
- 所有 profile 的非 `visual_program` 字段保持不变；`authored_spell_effects.json` 仅 Java 源审计摘要变化，术法语义不变。
- 目录保持 5,727 profiles、2,292 techniques、1,806 authored、9,947/9,947 引文；术法程序为 10,860 层、94 种 primitive，`giant_sword=60`。
- 52-shape 作者目录契约、每层 8 粒、事件 7/16/30 粒和 named copies 72 上限均未改变。
