# 0.2.232 投影建造引导修复

## 修复内容

- 结构蓝图台新增开工前选择手势：主手持蓝图台，副手持目录设施令牌或受支持控制器，右键任意方块表面即可把对应投影固定在原版判定的相邻放置位置。
- 固定投影现在优先于手持物的随准星临时预览；锁定后即使设施令牌仍在副手，投影也不会跟随准星漂移。相同结构和原点再次使用会解除固定。
- 无有效副手选择器时，原有“蓝图台直接右键已放置控制器”路径保持不变；蓝图台在副手时仍可沿旧路径识别已放置控制器。
- 新增 `MultiblockProjectionSelector` 作为公共解析边界。测试确认 46 个真实目录设施令牌均由批量注册器生成 `CatalogCarrierItem` 并能解析投影；结构修复台、蓝图台自身、普通目录载体及其他命名空间不会被误判。
- 中英文提示补充双手组合、相邻放置位、锁定坐标、逐层查看及空气潜行启封说明；解除提示改为“解除固定”，与仍可能存在的手持临时预览一致。

## 生成资源
