# 0.2.213 杖、灯、琴、棺、符笔具名轮廓

日期：2026-07-28
`mod_version`：0.2.212 → **0.2.213**；`ModNetwork.PROTOCOL_VERSION` 保持 **30**。

## 原文与缺口

- `technique_308` 的乌黑禅杖只剩银剑与圆钵；`technique_479` 的降魔巨杖巨化、七色佛光和砸碎五色光幕被误编为 7 份剑雨/单独光幕。
- `technique_268` 的古灯和足下白莲被压成通用残影；`technique_1487` 的晶莹白色古琴、琴弦和银珠声被压成符环。
- `technique_186` 的寒玉棺只有法阵，`technique_358` 的石棺与起身人影只有升腾光点。
- `technique_275` 的蓝色灵符笔被“六七寸长”误读为 7 份符环，笔尖涌出的金符也没有笔体。

## 实现

- 新增 `magic_staff`：贯穿长杖、杖首横梁、法环、两侧杖牙与顶端星芒；降魔杖的十余丈巨化固定为 1 份，金属杖体到七色佛光以 metal → qi 表达，砸幕句同时保留杖和五色光幕。
- 新增 `ritual_lamp`：灯座、悬灯体、灯柄与上升灯焰；精确白莲词和两条化风原句使古灯、莲台、遁风在同一引文内并存。
- 新增 `spirit_qin`：横向琴身、端框、三道琴弦和向外扩张的三层声波；晶莹白琴使用 qi 银白。
- 新增 `ritual_coffin`：长棺主轴、收束侧轨、首尾棺板、内棺线与升魂光；寒玉棺局部使用 water 冷色，石棺保留 yin，并与法阵/高大人影同时执行。
- 新增 `talisman_brush`：笔杆、箍环、双侧笔锋和笔尖符光；蓝笔固定 1 份，第二句使用 water → metal 呈现蓝笔涌出金色符文。
- 五种形象均只经 `emitFigurePrimitive` 层内分发并进入每份至少 2 粒的复杂轮廓预算；核心采用单一贯穿长轴，低预算仍覆盖两端，细节跨帧轮转。
