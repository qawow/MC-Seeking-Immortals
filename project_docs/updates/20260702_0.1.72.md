# 20260702 0.1.72 Pill Catalog

## Summary

- Implemented the 18-species pill catalog for cultivation, breakthrough, recovery, special, poison, and evil pills.
- Added 16 new catalog pill items; existing Foundation Building Pill quality items and `fasting_pill_low` count as the remaining catalog species.
- Integrated all catalog species into the 0.1.71 alchemy furnace formula/recipe flow.

## Gameplay

- New consumable effects cover mana/cultivation gain, fire and ice-fire training, marrow cleansing, Core Formation breakthrough aid, divine-consciousness recovery, emergency healing with costs, fasting, lifespan extension, one-time Return Yang True Water, poison pills, and risky evil combat boosts.

- Fasting uses player persistent NBT for a one Minecraft day timer.
- Clear Void, Forget Dust, and Appearance Fixing are MVP placeholders for future pet, memory, and appearance systems.
