# 0.2.253 时间线持久化稳定键

## 更新内容

`TimelineChronicleService` 持久化键不再直接使用本地化显示名（如「凡人·七玄门」），改为稳定键：

- 新增 `stablePhaseKey`：以 `si_phase:<realm>:<name>` 为键（realm 为目录稳定字段），解锁时双写稳定键 + 旧显示名键，兼容旧存档读取。
- `resolvePhase`：按显示名或 realm 关键字解析阶段（abbrev 名字段兼容），替代原先仅 `contains` 的模糊匹配。
- `hasPhase`：先查稳定键，再查显示名键（兼容历史存档）。
- `unlockedPhaseCount`：按目录阶段列表统计（每个 phase 的稳定键或显示名键任一为 true 即计入），避免重命名后孤儿键导致进度错乱/重复解锁提示。

连带：`chapter_1`/`chapter_4`/`great_jin` 关键词已在上批接入，本批无数据改动。

其余审计剩余项评估为内容层缺失或设计决策，未在本批改动：
- 6 个任务 NPC 注册（NamedNpcRegistry 内容层，属 M-C 计划）
- SevenMysteriesQuest 逃离/传送目标显示（需天罡盟逃离交互内容层，分离状态机会导致生存卡死）
- 10 条 fail-closed 内容层路由（D-A/Y/M 系列）
- DETAILED 结构跨维度锚点（依赖未成型结构，对应步骤失败关闭已接受）
- 贡献事务非原子 / hasAuthorityReward 读路径迁移 / FTB 留存标签契约（崩溃窗口/幂等/失败关闭，评估后保持）
