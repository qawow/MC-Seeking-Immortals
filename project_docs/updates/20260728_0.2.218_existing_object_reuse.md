# 0.2.218 既有物件几何精确复用

## 变更分类

代码、生成运行时数据、测试与项目文档更新。`mod_version` 从 `0.2.217` 升至 `0.2.218`；网络包字段、顺序、类型、注册和频道行为均未改变，`ModNetwork.PROTOCOL_VERSION` 保持 `30`。

## 原文边界

- `法盘` 在作者术法引文中恰有 4 条，全部接入已有 `formation_disc`。
- `晶球` 8 条，加上黑色晶核、黑白圆石和奇寒晶莹珠子，全部接入已有 `orb_projectile`。
- 龟壳法器与两面铜盾接入 `shield_plate`；唯一指环接入 `wheel_disc`。
- 五口黑色匕首、十六口短刃及佛像周围晶莹短刃接入 `flying_blade`。
- 只匹配实际显形的十余头/四只傀儡兽及晶莹玉鼠；两条傀儡制作功法说明和普通手持匕首保持不映射。

## 保真实现

- 数量按命中对象局部绑定，距离“数十丈”、方向“四面八方”、身体“五指”和伴随“无数符文”不再复制主体。
- 一叠法盘保留单份盘体、12 团灵光与五色符文阵；雾海道路使用扩张雾幕，守卫神念使用追踪流束。
- 龟壳防御同句同时保留 1 面盾、4 只傀儡兽、4 道光柱；十余头傀儡军保留 12 份兽影和单次召唤门。
- 黑匕首为 5 份 `yin→thunder`，伴随 5 道 `thunder→yin` 电弧；十六短刃在插入、寒气晶化和冰层复原三阶段持续保持 16 份。
- 黑球封绿气、白球受金柱、蓝球与玉鼠共鸣、血符晶球单次爆裂、奇寒晶球、黑白圆石和黑晶核均使用局部主体颜色与独立伴随层。
