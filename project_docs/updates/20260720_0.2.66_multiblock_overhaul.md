# 0.2.66 多方块结构材料大修事务

## 本批完成

### 结构材料目录
- 新增 `MultiblockMaterialCatalog`，从 `multiblock_material_prices_v135.json` 的 `used_by_sample` 建立工站→材料列表。
- 通过 `ItemCatalogService.resolveCatalogItem` 解析可扣材料。

### overhaul 事务
- `MultiblockOperationalService.overhaul`：
  1. 预留结构材料（各 1）；
  2. 预留灵石碎片附加费；
  3. `forceIntact` 写满耐久/intact；
  4. 任一步失败 `refundStacks`。
- 命令：`/seeking_immortals station overhaul <id>`。
- 双语消息：`overhaul_need_materials` / `overhauled`。
