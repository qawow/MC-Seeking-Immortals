# 2026-06-30 0.1.64 Realm stat application fix

## Summary

- Fixed realm-derived stat values not taking effect in actual gameplay by applying them to server-side vanilla player attributes.
- Increased the realm growth constants substantially in `RealmStageConfig`.
- Preserved the current packet format and network protocol.

## Code Changes

- `ModEvents` now refreshes cultivation attributes during server player ticks and after login, respawn, and dimension changes.
- Applied attributes:
  - max health
  - attack damage
  - armor
  - armor toughness
  - knockback resistance
  - movement speed
- Severe injury still applies after cultivation max health, so its multiplier affects the raised health pool.
- `CombatCalculator` has an overload to skip adding cultivation attack when the vanilla attack attribute already contains it; the PvP event path uses this to avoid double counting.
- `RealmStageConfig` now uses larger values for mana, cultivation span, divine sense, HP, recovery, cultivation gain, flying speed, and combat stat growth.

## Version and Protocol

- `mod_version`: `0.1.64`
- `ModNetwork.PROTOCOL_VERSION`: remains `5`
- Reason: no packet fields, order, encoding, decoding, or channel compatibility behavior changed.
