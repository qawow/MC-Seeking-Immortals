# 0.2.185 原著法术逐条视觉程序化

## 本次完成

- 生成器把每条术法视觉引文编译成可执行 `semantic_layers_v2` layer。
- layer 保存 primitive、锚点、路径、运动、复制数量、尺度、速度、旋转、颜色、证据词、原文和 timeline 事件 ordinal。
- 客户端按 `profileKey` 和本地 timeline ordinal 解析 layer；作者术法走程序执行，未提供程序的其他资料保留兼容后备。
- 严格目录解析器拒绝未知 primitive、路径、颜色、越界事件或未覆盖引文。

## 数据与验证

- 2,247 个术法 profile。
- 9,838 段视觉引文，13,614 个执行 layer，覆盖计数相等，并包含当前 v647 精读生成数据。
- `./gradlew test --tests ...AuthoredVisualCatalogTest --tests ...LodestoneVfxContractTest` 通过。
- `./gradlew compileJava --no-daemon --max-workers=1` 通过。
- 普通 `./gradlew build --no-daemon --max-workers=1` 在 1 分 21 秒内成功，1,161 项测试、资源检查和作者目录预检全部通过。

## 版本与风险

- `mod_version=0.2.185`。
- `ModNetwork.PROTOCOL_VERSION=30` 不变，程序随现有 profileKey 在客户端本地读取。
- 词法编译不能替代没有明确视觉原文时的人工镜头签字；仍需真实客户端和专服取证。

## 后续生成稳定性

共享工作树的原著精读流可能在构建期间产生尚未提交的下一版本文件。生成器在 Git 工作树中通过关闭 `core.quotePath` 的 `git ls-files --cached` 只读取已跟踪输入，避免 scratch 文件污染预检；下一版本提交后重新运行生成器即可纳入。该修复在 `0.2.186` 独立批次完成，网络协议保持 30。v649 已提交后重新生成并通过检查：2,253 个术法（747 条基础语料、1,506 条原著增量），统一视觉目录 5,688 个 profile；普通构建将在本批提交前重新执行。
