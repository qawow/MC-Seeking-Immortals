# 0.2.106 术法高层 type → 可执行 effectType

日期：2026-07-20  
`mod_version`：`0.2.106`  
`ModNetwork.PROTOCOL_VERSION`：`26`（无包变更）

## 问题

`cultivation/*.json` 遗留包 477 条术法只有高层 `type`（spell/defense/ghost_art…），加载时 `effectType` 被写成空串。  
text_material 覆盖了 337 条；**cult-only 约 107 条**既无 SkillType 映射又无 effectType → 释放路径 `effect_unavailable` fail-closed。

## 修复

`TechniqueDataManager.loadCultivationEntries`：

- `inferEffectType(type,id,name,attribute)` 映射到 abstract runtime 词汇（projectile/shield/scan/debuff/…）
- `inferElement` 从 attribute/id 推断元素
- 默认 damage/target/range，使 `AbstractTechniqueEffectResolver.createForTechnique` 可实例化

公开 mapper 供单测；text_material 仍按 id 覆盖，权威语料不变。

## 测试

- `M02TechniqueCorpusTest.cultOnlyHighLevelTypesMapToExecutableRuntimeEffects`
- 断言 builtin 无 blank effectType；resolvableRuntime ≥ 747
