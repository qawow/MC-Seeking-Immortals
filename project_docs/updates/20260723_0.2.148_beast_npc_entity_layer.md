# 0.2.148 灵兽与专用 NPC 实体层

## 变更分类

代码、实体资源、数据包和运行依赖变更。`mod_version` 从 `0.2.147` 升至 `0.2.148`。未修改网络包字段、顺序、类型、注册或频道行为，`ModNetwork.PROTOCOL_VERSION` 保持 `28`。

## 完成内容

- 新增数据驱动 `CultivationBeastEntity`，以六种体型承载完整 1,800+ 图鉴，并执行 13 阶属性、15 元素、陆水空移动、状态攻击、Boss 技能和 NBT 恢复。
- 自然生成、每日事件、Boss 与秘境试炼使用专用灵兽；和平模式、安全落点、碰撞和 `addFreshEntity` 结果均失败关闭，生成失败不写一次性完成闩锁。
- 捕获罐与契约召唤恢复真实灵兽 id/阶位；伴生兽支持跟随、守卫、主动、停留姿态、寿命、同阵营保护、战斗成长和 DoT 最后一击主人回退。
- 灵石碎片召唤先全库存预检并按槽位保留；实体生成失败退款。catalog 和 `HonestSummonSpell` 均删除失败后玩家自增益的假成功路径。
- `CultivatorNpcEntity extends PathfinderMob` 统一商人、执事、钱庄、任务 NPC，生产源码不继承或新建 Villager；旧档命名 Villager 仅保留兼容读取入口。
- 179 条命名 NPC 通过 `NpcKind` 全量分类，宗主/长老/执事优先 steward；三类命名 NPC 共享附近坚固地面、两格净空和碰撞校验的安全生成路径。
- 四类 NPC 返岗寻路增加距离、20 tick 和导航空闲门控；执事先启动命名 NPC 数据树，无树/失败才回退宗门业务授权。
- GeckoLib `4.8.4` 改为必需运行依赖；新增 7 个 Geo、2 个 animation、6 个基础灵兽 atlas、84 个体型/元素 atlas 和 4 个 NPC atlas。
