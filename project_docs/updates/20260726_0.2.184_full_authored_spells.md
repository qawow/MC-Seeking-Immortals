# 0.2.184 全量作者法术功能与独立视觉接线

## 范围

- 汇总 `文本材料/data/techniques/` 与全部 `novel_curated_techniques_v*.json`，不再依赖旧 344 条术法视觉子集。
- 为每条资料生成严格类型化的功能、视觉、逐帧、来源哈希与签名计划。
- 将目录法术接入服务端执行器、统一视觉目录和 Lodestone shape 几何。
- 收口启动烟测发现的专用物品重复注册与粒子 sprite 路径问题。

## 目录与运行时

- `generate_authored_spell_effects.py` 动态扫描全部 `novel_curated_techniques_v*.json`，当前至 v641 确定性生成 2,229 条 profile：747 条基础语料、1,482 条原著条目。
- 原著条目中 1,401 条保留直接视觉描述，81 条使用设定回退；目录保存 3,575 段视觉引文与 2,229 个 profile 签名。
- `AuthoredSpellEffectCatalog` 对 namespace、ID、family/motif、effect/target、particle/trail、shape、数值边界、逐帧和功能计划失败关闭。
- `TechniqueDataManager` 补入原著法术；`AbstractTechniqueEffectResolver` 使所有目录 profile 优先进入 `AuthoredSpellEffect`。
- 服务端共享执行族覆盖攻击、防御、恢复/净化、移动、召唤/指令、侦测/隐匿、变化、地形、封印、吸取、炼制辅助、修炼辅助与传音；攻击细分实体投射、弹幕/剑雨、射线、锥形、连锁、范围和持续场，伤害保留施法者归因。
- 持续场按服务器 tick 执行，限制目标数并设置每服务器 128 场硬上限；目标过滤覆盖 PvP、队友、自有傀儡与灵兽，服务器停止和维度卸载都会清理。
- `wall` 生成有碰撞且定时移除的 `EARTH_WALL`；火球溅射和飞剑命中共用友方过滤，不会绕过施法权威。

## 视觉与资源

- 统一视觉目录的术法域由 344 条扩展为 2,229 条，全域合计 5,664 条。
- 客户端读取并穷举 52 种作者 shape；除巨爪、拳影/弹幕、剑雨、涡旋、符文环、锁链网、法相/召唤门、蛇龙、领域和封印牢笼外，还包含法眼、声波、莲台、巨手、山岳、镜盘、雾幕、火鸟、兽影、空间裂隙、冰牢、血海、古树、经文、元磁场、雷暴、法轮、针矛、羽翼、虫群、潮浪与灵珠几何。
- `LodestoneVfxContractTest` 直接比较生成 shape 集与客户端 switch 分支集，并限制 `aura_burst`/`single_projectile` 泛化比例；全部几何继续受距离、粒子、事件和后效预算约束。
- 12 个粒子 JSON 改为 `seeking_immortals:<id>` sprite 引用；契约测试逐个验证 JSON 与 `textures/particle/<id>.png`。
- `catalog_bulk_items.json` 移除 11 个已有专用注册的材料/丹药，避免 Forge 启动时重复 ID 被替换为 `air`；测试同时约束目录互斥和 1,189 条 bulk 基线。
