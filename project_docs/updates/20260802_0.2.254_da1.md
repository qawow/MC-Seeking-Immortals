# 0.2.254 D-A-1 对话世界动作对账与 dispatch 分型

## 更新内容

对 `DialogueActionExecutor` 的 dispatch 做 D-A 分型第一步，为后续 D-A 深化建立"作者动作 → 独立 handler"契约：

- 新增 `DialogueActionCoverageTest`（纯数据/源码契约）：
  - 解析 `npc_dialogue_branches_v139.json` 全部 effect type，断言 D-A 家族（mark_structure/hint/clue/call_guard/combat_flag/combat_or_arrest/add_suspicion/anomaly_log）闭合——作者写出的世界动作必须属于该家族，违规即失败。
  - 源码契约断言：`CALL_GUARD`/`COMBAT_FLAG`/`COMBAT_OR_ARREST` 三个 case 各自调用独立 handler，不再合并为单个 generic 分支；未知动作仍 `effect_unsupported` fail-closed；`DialogueWorldActionService` 暴露 `callGuard`/`combatFlag`/`combatOrArrest` 三个类型化方法。
- `DialogueActionExecutor.java`：
  - 把 `case CALL_GUARD, COMBAT_FLAG, COMBAT_OR_ARREST`（共用 `triggerCombat`）拆为三个独立 case，分别调 `DialogueWorldActionService.callGuard/combatFlag/combatOrArrest`。
  - 新增 `CLUE` 常量并把 `HINT, CLUE` 合并到来源绑定 hint recorder 分支（作者若写 `type:clue` 不再落入 default 被拒）。
- `DialogueWorldActionService.java`：
  - 新增 `callGuard`（暂委派 `triggerCombat`，D-A-4 改守卫）、`combatFlag`（只写敌对账本+惩罚+标记，不生成实体）、`combatOrArrest`（暂委派 `triggerCombat`，D-A-4 加逮捕分支）。
  - 未改动网络协议，无包字段/顺序/类型/注册/频道行为变化。
