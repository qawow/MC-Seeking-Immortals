# 0.2.10 暖漆问道录 — 全前端 UI 暖色重绘

日期：2026-07-18

## 目标

在 0.2.9 克制问道录结构之上，把气候从冷青墨绿底改回 **凡人暖漆金木** 问道录：
旧纸 / 漆木 / 古铜金框 / 朱砂印 / 苔玉点缀，细节更丰富，但不做霓虹灵光、不改布局与协议。

## 变更

### ImmortalUiSkin 色板

- `JOURNAL_VOID/PANEL/INNER/HEADER` → 暖漆褐（V1 木夜系）
- `JOURNAL_BORDER` → 古铜金 `#D4BC78`（近 V1 仙金，略旧）
- 正文/次要 → 暖宣纸 `#F0E4C0` / `#B8A882`
- 玉语义保留但改为苔玉 `#6FAE88`；修为填充去掉霓虹青
- HUD / 技能轨半透明 token 同步暖色，alpha 不变
- 遗留 `PANEL_*` / `TOOLTIP_*` / `STATUS_*` / skill 边框对齐同一暖金气候
- 新增 `JOURNAL_RIM_INNER` 双层金边内高光

### 绘制层细节

- `drawLayeredPanel`：双阴影 + 双调铜边 + 纸纹 + 角标 + 大面板朱砂印
- `drawInnerFrame`：双调内嵌井，不再是第二块重面板
- `drawTitleBar`：朱砂侧条、双底线、右侧装订短线、宽标题小印
- `drawListRow`：底部分割线 + 选中双轨（玉+铜）
- `drawButtonBackground`：双层 rim + 主按钮印章
- `drawTooltipPanel`：迷你 journal chrome（阴影/金边/纸纹/印）
- `drawControlBox` / `drawCornerMark` / `drawCinnabarSeal`：双描边与更完整的印面

### 贴图

- 重生成 `paper_texture.png`：暖米黄纤维，低 alpha 可平铺
- 调整 `jade_texture.png`：苔玉矿物脉，低饱和

## 版本与协议

- `mod_version`：`0.2.9` → **`0.2.10`**
- `PROTOCOL_VERSION`：**保持 24**（纯客户端皮肤，无 packet 变更）
