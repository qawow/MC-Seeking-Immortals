# 2026-07-17 0.2.5 凡人风格 HUD 深度重设计

## 变更摘要

将玩家四块 HUD 统一为「问道录 / 玉简」视觉语言，并把原左上气血与右上修为合并为右上状态条。

## 布局

- **右上 `statusStrip`**：气血 band + 修为/灵力 band（同一玉简外框）
- **左 `techniques`**：七槽玉简技能轨（不再压在气血下方）
- **底 `breathing`**：打坐吐纳玉简
- 窄屏 `railMode`（宽 &lt; 300 或高 &lt; 140）仍保持左技能轨 + 右内容列

## 绘制职责

- `CultivationHealthOverlay` **拥有**外框 chrome：自由 HUD 画完整条；打开 Screen / 未同步时画紧凑 `healthOnlyStrip`
- `CultivationHudOverlay` **不画**外框，只在 `cultivationBand` 内画境界/修为/灵力/神识/天劫
- `TechniqueSkillBarOverlay` 使用 `drawJadeSlipRail` + `drawJadeSlipSlot`
- `BreathingHudOverlay` 使用 `drawBreathingTablet`
- 气血替换原版心形谓词保持 0.2.4：`!hideGui && hasPlayer && shouldDrawSurvivalElements`

## 皮肤 API

`ImmortalUiSkin` 新增：

- `drawStatusStripChrome`
- `drawBreathingTablet`
- `drawJadeSlipRail` / `drawJadeSlipSlot`
- `drawHudDivider` / `drawCinnabarSeal`
- `drawMeterRow`

## 验证

- 定向：`ScreenLayoutTest` + `ImmortalHudLayoutTest`
- 完整：`./gradlew build`

## 版本与协议

- `mod_version`：`0.2.4` → `0.2.5`
- `ModNetwork.PROTOCOL_VERSION`：保持 `24`

## 备份

- `.bak/20260717_161605_hud_visual_redesign/`

## 剩余风险

- 右上状态条可能与第三方小地图叠层；仅靠 margin/宽度夹紧，不迁回左上
- 全屏模组 UI 右上仍可能叠紧凑气血条（故意保留，避免原版心形回退）
- 真实客户端 GUI Scale / 打坐 / 低血+护体仍建议人工烟测
