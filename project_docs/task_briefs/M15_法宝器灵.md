# M15 法宝与器灵

- 分支：`task/m15-artifacts` ｜ worktree：`/root/mc-mod-worktrees/m15-artifacts`
- 前置模块：M00、M03（法宝物品 id）、M01（认主境界门槛）、M14（状态/伤害钩子）、M02（主动技效果 id）
- 优先级：P2

## 目标

落地 217 件法宝：十一阶品阶体系、认主/祭炼、主动技与协同（synergy），打通法宝在战斗管线与拍卖行中的完整生命周期。

## 功能点清单（可勾选）

- [x] 法宝主数据：`artifacts_catalog`（217 件）→ `artifact/` 8 服务（`ArtifactDataService` 现读 `data/seeking_immortals/artifacts/` 16 JSON，ROOT 常量 22 行）扩量对账。
- [x] 品阶体系：`artifact_tier_rules` + `eleven_tier_map` + `taxonomy_111` + `tier_map` → 品阶→属性缩放/境界压制规则。
- [x] 认主与祭炼：`ArtifactRefinementService`（现读 `reference/text_material_id_map.json`）扩展：认主绑定（M01 境界门槛）、祭炼层数成长、器灵觉醒条件。
- [x] 主动技：法宝 active skills 语料 → 引用 M02 `SkillEffectRegistry` 效果 id 触发（冷却/灵力消耗服务端校验）。
- [x] 协同：`item_synergy.json` → 多法宝组合加成（属性走 M14 伤害/属性钩子）。
- [x] 拍品与掉落：`wanbao_auction_artifacts`（M05 拍卖框架的拍品池数据）、`artifact_realm_drops` + `artifact_faction_specialty`（掉落归 M09/M10 loot 表引用，本模块提供数据）。
- [x] 飞行法宝：`FlyingArtifactItem` 与 `FlyingAuthority`（M13）的许可对接。
- [x] 草案对账：`moditems_artifacts_draft` ↔ 实际注册物品清单差异报告。

## 涉及文件

**语料侧（本模块拥有）**
- `文本材料/data/artifacts_catalog*`、`artifact_catalog_v92*`、`artifact_tier_rules*`（低阶法器→中阶→法宝(要 core_material+refinement_manual)→古宝(binds_soul,不可批量)→灵宝(空间/时间法则)阶梯）、`artifact_eleven_tier_map*`、`artifact_taxonomy_111*`、`artifact_tier_map*`
- 法宝主动技语料、`item_synergy.json`、`moditems_artifacts_draft*`
- `wanbao_auction_artifacts*`、`artifact_realm_drops*`、`artifact_faction_specialty*`、`tiannan_faction_specialty*`、`talisman_treasure_templates*`（符宝模板）、`ancient_treasure_index*` 的法宝段

**模组侧（本模块拥有）**

- `ArtifactCatalogItem`、`FlyingArtifactItem`
- `data/seeking_immortals/artifacts/`（16 JSON → 扩量）
- `reference/text_material_id_map.json` 法宝段（再生成走 M00）

## 依赖前置库

- Curios（强制依赖）：法宝佩戴槽位（`data/curios/` 槽位数据）；Forge attribute modifier 体系（佩戴属性）。

## 接口交叉（谁提供 → 谁消费）

- **M15 → M14**：法宝装备属性/伤害修饰经 M14 钩子注入（禁止绕过伤害管线直改）。
- **M15 → M05**：拍品池数据（M05 拍卖框架消费）。
- **M15 ← M03**：法宝物品注册与 id。
- **M15 ← M01/M02/M14**：认主门槛、主动技效果、状态 id。
- **M15 ← M13**：飞行许可（FlyingAuthority）。

## 验收与红线

- 217 件法宝的品阶/效果 id/物品 id 全部可解析（校验测试）。
- 红线（DESIGNER_HANDBOOK §5）：唯一法宝不复制、不进重复掉落、不进无限商店；越阶使用压制规则服务端强制。
- 认主绑定数据存物品 NBT + 玩家 UUID，偷取/拾取他人本命法宝不可用。
