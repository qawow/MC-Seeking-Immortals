# M08 宗门与势力

- 分支：`task/m08-sects-factions` ｜ worktree：`/root/mc-mod-worktrees/m08-sects-factions`
- 前置模块：M00、M01、M03、M06（region_id）、M12（对话 API，可先桩）、M05（贡献商店框架）
- 优先级：P0-E（EXPANSION_ROADMAP 方向 E：faction graph/sects）

## 目标

落地 20 宗门 + 全势力关系图（faction_graph）：宗门加入/贡献/声望、势力间关系与冲突事件，成为任务门槛（M11）与贡献商店（M05 框架实例）的状态提供方。

## 功能点清单（可勾选）

- [x] 宗门主数据：`sects.json`（20 宗门）+ `sect_specialty_map` → `sect/` 包服务扩量（入门条件走 M01 门槛 API）。
- [x] 势力关系图：`faction_graph.json` + `faction_species.json` → `FactionGraphService`（新建）：势力节点、敌友边、声望轴查询。
- [x] 分势力深数据：`demonic_six_sects`、`star_palace_internal_factions`、`chaotic_sea_factions`、`dajin_factions`、`human_clan_league`、`wutu_mulan_feud`、`yin_luo_hall`、`ghost_sect_ban_rules` → 图中节点属性/禁令规则。
- [x] 声望解锁：`reputation_unlocks_v102` → 声望阈值 → 解锁项（商店档位/任务线/区域通行）查询接口。
- [x] 贡献商店：`sect_contribution_shop` + `sect_shelves_v106/107` → 用 M05 贡献兑换框架实例化宗门货架（红线：功勋≠灵石无限兑换）。
- [x] 阵营冲突事件：`faction_conflict_events` → 订阅 M06 每日事件钩子触发冲突（服务端裁决，影响声望/物价）。
- [x] 宗门任务/对话数据维护：`sects/missions`（30 JSON）、`sects/dialogues`（30 JSON）扩量对齐（对话运行时归 M12，任务钩子归 M11）。
- [x] 鬼修禁令：`ghost_sect_ban_rules` 与 M01 鬼修路线联动（特定宗门拒收/追杀标记）。
