# M11 任务与主线

- 分支：`task/m11-quests-story` ｜ worktree：`D:/codex/mc-mod-worktrees/m11-quests-story`
- 前置模块：M00、M12（对话 API）、M08（声望状态）、M01（境界门槛）、M03（奖励 id）、M06/M09（事件钩子）
- 优先级：P1（内容最大件：62 任务链 + 35 任务线 + 主线章节）

## 目标

落地任务体系全量数据：62 条任务链、35 条 QUEST_LINES_FULL_v147 任务线、主线章节（chapter_0_mortal 起）与韩立时间线彩蛋，打通 FTB Quests 桥接与原生任务追踪双通道。

## 功能点清单（可勾选）

- [ ] 任务链扩量：`quest_chains.json`（62 条，schema 18：id/region/realm_span/steps hooks/alchemy_loop_ref/skill_tree_ref）→ `ExtendedCatalogService`（198 行处读取）与 `quest/` 包 12 类运行时。
- [ ] 任务线：`QUEST_LINES_FULL_v147`（35 条）→ 章节化任务线服务（与任务链的引用关系校验）。
- [ ] 主线：`main_story_chapters.json`（schema 3，quest_chain_refs）+ `main_story_quest_map_v145.json` → 主线推进器（章节解锁条件含境界/声望/秘境通关）。
- [ ] 任务钩子接线：steps hooks 与 `quest_hooks` → 订阅 M06 每日事件、M09 通关事件、击杀/采集/炼制事件总线。
- [ ] 奖励发放：`main_quest_rewards_v101` + 分阵营任务网络（chaotic_sea/mulan/dajin/inverse_star/human_clan/spirit_realm_clan 六个 faction quest network 文件）→ 奖励 id 走 M03 解析（红线：唯一剧情道具只发一次）。
- [ ] 时间线内容：`hanli_timeline_items_v100`、`timeline_guide_v115`、`chronicle_events`（49 条）→ 编年史/时间线记录服务（展示归 M16）。
- [ ] FTB Quests 桥：SNBT 章节包（10 章）与原生任务的映射维护：`FtbQuestDefaults`、`FtbCustomTaskHooks`、`FtbRewardBridgeService` 对新任务链的注册。
- [ ] 任务追踪同步：`SyncQuestTracker`/`QuestTrackerAction` 包容量评估（62 链全量追踪的数据量）。

- FTB Library/Teams/Quests（现为强制依赖）；Forge 事件总线（击杀/采集钩子）。

## 接口交叉（谁提供 → 谁消费）

- **M11 → M13**：主线/任务完成 flag（飞升前置条件）。
- **M11 ← M12**：对话推进 API（对话节点完成 → 任务步进）。
- **M11 ← M08**：声望/阵营门槛。
- **M11 ← M06/M09**：每日事件、秘境通关钩子。
- **M11 ← M01/M03**：境界门槛、奖励物品 id。

## 验收与红线

- 62 链 + 35 线 + 主线图三者交叉引用全部可解析（校验测试）；每条 chain 的 region/realm_span 有效。
- 红线：唯一剧情道具的奖励发放有全局幂等标记；任务奖励不可重复领取。
- FTB Quests 缺席（开发环境剥离测试）时原生通道不崩溃。
