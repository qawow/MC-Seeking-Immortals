# M14 战斗与状态

- 分支：`task/m14-combat-status` ｜ worktree：`/root/mc-mod-worktrees/m14-combat-status`
- 前置模块：M00、M01（境界推导属性）
- 优先级：P0/P1 之间（M02/M10/M15 的状态注册表前置，宜早合并）

## 目标

落地统一状态效果注册表（burn/frozen/soul_shock/illusion/karma/demonic_qi/foundation_unstable/marrow_drain/seal_nascent/conceal_qi 等 ~20 个）与按境界配装基线，并修复已知战斗管线风险，向术法（M02）、妖兽（M10）、法宝（M15)提供状态与伤害钩子。

## 功能点清单（可勾选）

- [x] 统一状态注册表：`status_effects` 语料（WORLD_SETTING_BIBLE 统一状态 id 清单）→ Forge `MobEffect` 注册 + id→effect 映射服务 `StatusRegistry`（字符串 id 与语料一致，供跨模块引用）。
- [x] 状态数值/叠加/免疫规则：按境界差与体质（M01）计算命中/抵抗；心魔/道伤类与 `ImmortalAffliction` 的关系明确化（affliction 归 M01，短时战斗状态归本模块）。
- [x] 配装基线：`loadout_by_realm_v99` → 平衡基准表（`CombatStats` 校准输入，写成测试断言防数值漂移）。
- [x] 十毒与解药：`ten_poisons_antidotes_v99` → 毒系状态 + 解药物品效果映射（物品注册归 M03，效果归本模块）。
- [x] 已知风险修复①：PvP 伤害替换挂 `LivingDamageEvent`，同事件路径内 `defender.hurt(...)` 可能递归——加守卫或迁移事件阶段。
- [x] 已知风险修复②：`LivingDamageEvent` 在原版护甲/吸收之后触发，闪避/未命中裁决被吞资源——评估迁移到 `LivingAttackEvent`/`LivingHurtEvent` 早阶段。
- [x] 已知风险修复③：`CombatCalculator#getCombatStats` 能力缺失返回 null——全调用点判空加固。
- [x] 对外钩子：`applyStatus(target, statusId, level, duration)`、伤害管线前后置回调（M15 法宝、M07 阵法场效果接入点）。
