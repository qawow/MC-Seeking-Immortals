# M04 炼制与生产

- 分支：`task/m04-craft-production` ｜ worktree：`/root/mc-mod-worktrees/m04-craft-production`
- 前置模块：M00、M03（物品 id）、M01（丹方境界门槛）、M07（多方块工作站，可先桩）
- 优先级：P0（EXPANSION_ROADMAP：炼丹三元组）

## 目标

落地"炼丹三元组"（丹方×火候×品质）及炼器、制符、傀儡组装、灵植四条生产线的配方数据，全部走 `AlchemyRecipeManager` 式的数据包可重载管线。

## 功能点清单（可勾选）

- [x] 炼丹配方扩量：`alchemy_system` + `alchemy_recipes` + `pill_recipes_detailed_v98` → `data/seeking_immortals/alchemy/recipes/`（唯一真实 reload listener `AlchemyRecipeManager` 加载），补齐 114 种丹药配方。
- [x] 丹药品质管线：`pill_quality` → `PillQuality`（LOW/MIDDLE/HIGH/PERFECT）判定参数与炼丹结果分布对齐。
- [x] 丹药效果实装：`BasePillItem.consumePill()` / `CatalogPillItem` 效果映射，覆盖语料内效果描述（增益走 M14 状态注册表 id）。
- [x] 炼器配方：`refinement_recipes` → `RefinementCraftingRecipe` + `RefinementForge` G1–G3 档位对齐。
- [x] 制符配方：`talisman_recipes` + `talisman_materials` → `craft/TalismanCraftService` + `TalismanTable`。
- [x] 傀儡组装：`puppet_craft_recipes` → `craft/PuppetCraftService` + `PuppetAssemblyBench`（产出实体归 M10）。
- [x] 灵植日历：`garden_liquid_calendar_v108` → `SpiritHerbPlanter` 生长/绿液周期参数（注意红线：绿液年配额）。
