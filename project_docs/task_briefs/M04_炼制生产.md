# M04 炼制与生产

- 分支：`task/m04-craft-production` ｜ worktree：`D:/codex/mc-mod-worktrees/m04-craft-production`
- 前置模块：M00、M03（物品 id）、M01（丹方境界门槛）、M07（多方块工作站，可先桩）
- 优先级：P0（EXPANSION_ROADMAP：炼丹三元组）

## 目标

落地"炼丹三元组"（丹方×火候×品质）及炼器、制符、傀儡组装、灵植四条生产线的配方数据，全部走 `AlchemyRecipeManager` 式的数据包可重载管线。

## 功能点清单（可勾选）

- [ ] 炼丹配方扩量：`alchemy_system` + `alchemy_recipes` + `pill_recipes_detailed_v98` → `data/seeking_immortals/alchemy/recipes/`（唯一真实 reload listener `AlchemyRecipeManager` 加载），补齐 114 种丹药配方。
- [ ] 丹药品质管线：`pill_quality` → `PillQuality`（LOW/MIDDLE/HIGH/PERFECT）判定参数与炼丹结果分布对齐。
- [ ] 丹药效果实装：`BasePillItem.consumePill()` / `CatalogPillItem` 效果映射，覆盖语料内效果描述（增益走 M14 状态注册表 id）。
- [ ] 炼器配方：`refinement_recipes` → `RefinementCraftingRecipe` + `RefinementForge` G1–G3 档位对齐。
- [ ] 制符配方：`talisman_recipes` + `talisman_materials` → `craft/TalismanCraftService` + `TalismanTable`。
- [ ] 傀儡组装：`puppet_craft_recipes` → `craft/PuppetCraftService` + `PuppetAssemblyBench`（产出实体归 M10）。
- [ ] 灵植日历：`garden_liquid_calendar_v108` → `SpiritHerbPlanter` 生长/绿液周期参数（注意红线：绿液年配额）。

## 涉及文件

**语料侧（本模块拥有）**
- `文本材料/data/alchemy_system*`、`alchemy_recipes*`、`pill_recipes_detailed_v98*`、`pill_quality*`
- `文本材料/data/refinement_recipes*`、`talisman_recipes*`、`talisman_materials*`、`puppet_craft_recipes*`
- `文本材料/data/garden_liquid_calendar_v108*`

**模组侧（本模块拥有）**
- `alchemy/` 包（含 `AlchemyRecipeManager`）、`data/seeking_immortals/alchemy/recipes/`
- `craft/`：`TalismanCraftService`、`PuppetCraftService`
- `recipe/RefinementCraftingRecipe`、`registry/ModRecipes`
- 工作站方块：`AlchemyFurnace`(+BlockEntity/Menu/Screen 数据面)、`RefinementForge`、`TalismanTable`、`PuppetAssemblyBench`、`SpiritHerbPlanter`
- `item/pill/` 的 consumePill 效果实现（目录映射归 M03）

## 依赖前置库

- Forge `SimpleJsonResourceReloadListener`（AlchemyRecipeManager 是全模组样板）。
- Forge BlockEntity/Menu 体系；JEI（可选依赖，配方展示类别，需 `ModCompat.JEI_LOADED` 守卫）。

## 接口交叉（谁提供 → 谁消费）

- **M04 → M05**：产出物的成本锚点（丹药/符箓/器物成本 → 市场定价参考，M05 只读）。
- **M04 ← M03**：全部原料/产物 id 经别名解析。
- **M04 ← M01**：丹方/炉温的境界门槛。
- **M04 ← M07**：高阶炼制的多方块阵列判定结果（`FormationFieldService` 布尔接口）。
- **M04 ← M14**：丹药增益状态 id。

## 验收与红线

- 每条配方原料/产物 id 可解析（新增校验测试挂 M00 管线）。
- 红线（DESIGNER_HANDBOOK §5）：**掌天瓶/绿液唯一、不可交易、年产配额与冷却必须服务端强制**；催熟不可绕过日历上限。
- JEI 未安装时不得崩溃（守卫检查）。
