# M07 阵法与多方块

- 分支：`task/m07-formations-multiblock` ｜ worktree：`D:/codex/mc-mod-worktrees/m07-formations-multiblock`
- 前置模块：M00、M03（阵材物品 id）
- 优先级：P1（M04 高阶炼制、M08 宗门阵、M13 传送阵的公共前置）

## 目标

把 86 个多方块结构索引（83 个带 MP 序列）与阵法目录落到 `structure/` 校验器 + `FormationFieldService` 场效果体系，对外提供"多方块工作站判定"与"阵法场效果"两个稳定接口。

## 功能点清单（可勾选）

- [ ] 结构索引落地：`multiblock_structure_index_v135.json`（86 结构，含 immortal_teleport_grand_array、sect_formation_hub、flying_boat_dock 等大件）→ `MultiblockPattern` 数据驱动化（现 `structure/` 26 类以代码 pattern 为主，补数据驱动加载路径）。
- [ ] 阵法目录：`formation_catalog` + `formation_array_catalog_v97` → `FormationFieldService` 场类型/半径/效果参数扩量。
- [ ] 阵材物品：`formation_items_catalog` → 阵旗/阵盘物品行为（注册归 M03，本模块实现放置/激活行为）。
- [ ] `FormationCore` BlockEntity 与 `FormationFieldSavedData` 对新阵型的持久化兼容。
- [ ] 聚灵阵体系对齐：`SpiritGatheringArrayBlock` 灵气加成参数并入阵法目录（保持既有行为向后兼容）。
- [ ] 对外接口：`isStationFormed(stationId, pos)`（多方块工作站判定，供 M04/M08/M13）与 `getActiveFieldEffects(pos)`（场效果查询，供 M14 战斗、M09 秘境）。
- [ ] MP 序列（搭建顺序）导出为 Patchouli 可引用的结构展示数据（展示实现归 M16）。

## 涉及文件

**语料侧（本模块拥有）**
- `文本材料/data/multiblock_structure_index_v135.json`
- `文本材料/data/formation_catalog*`、`formation_array_catalog_v97*`、`formation_items_catalog*`

- 传送阵/宗门阵**结构判定**部分（gate 方块行为归 M09/M13，本模块只提供 formed 判定）

## 依赖前置库

- Forge BlockEntity ticking、`SavedData`；无网络包变更预期（场效果为服务端裁决，展示走现有同步）。

## 接口交叉（谁提供 → 谁消费）

- **M07 → M04**：高阶炼丹/炼器的工作站 formed 判定。
- **M07 → M08**：sect_formation_hub、护山大阵判定与场效果。
- **M07 → M13**：immortal_teleport_grand_array、flying_boat_dock 判定（传送执行归 M13）。
- **M07 → M09/M14**：场效果查询（秘境阵法机关、战斗增减益）。
- **M07 ← M03**：阵材物品 id。

## 验收与红线

- 86 结构索引全部可解析、pattern 尺寸与索引一致（校验测试）。
- 阵法效果全部服务端计算；客户端只收展示数据。
- 大型结构（>16³）判定需缓存/脏标记，禁止每 tick 全量扫描。
