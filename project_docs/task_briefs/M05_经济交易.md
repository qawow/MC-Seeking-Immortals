# M05 经济与交易

- 分支：`task/m05-economy-trade` ｜ worktree：`D:/codex/mc-mod-worktrees/m05-economy-trade`
- 前置模块：M00、M03（物品 id）、M01（商店档位门槛）
- 优先级：P1

## 目标

落地三层经济模型：灵石阶梯（下/中/上/极品 = 1/100/10000/1000000）、全物品市场价格主表、商人商店与拍卖行软服务，成为贡献商店（M08）与 NPC 商人（M12）的框架提供方。

## 功能点清单（可勾选）

- [ ] 灵石阶梯对账：`economy_spirit_stone_master.json`（兑换链物品 id、1:100 比率）↔ `SpiritStoneItem` 与兑换逻辑（村民灵石兑换在 `ModEvents`）。
- [ ] 市场价格主表：`market_price_master_v100` + `item_economy_tags_v101` → `ShopService`/`ShopQuotaService` 定价与限购数据源（经 `catalog/merchant_shops_runtime.json` 再生成，走 M00 索引管线）。
- [ ] 商人商店扩量：`merchant_shops` + `trade_routes` → 商店货架与路线差价。
- [ ] 拍卖行波段：`economy_auction_bands`（现由 `AuctionSoftService` 558 行处读取）+ `wanbao_auction_*` 拍品池对齐（法宝拍品明细归 M15，本模块只管框架与价格带）。
- [ ] 周目经济：`newgame_plus_economy_v102` → 周目价格系数入口（软阶段 `SoftPhaseShellService` 参数）。
- [ ] 贡献兑换框架：`economy_contribution_exchange` → 通用"非灵石货币兑换"服务接口（供 M08 宗门贡献商店实例化；红线：功勋≠灵石无限兑换）。
- [ ] `AuctionHouseSavedData` 持久化字段兼容性检查（扩量后旧存档可读）。

## 涉及文件

**语料侧（本模块拥有）**
- `文本材料/data/economy_*`（spirit_stone_master、auction_bands、contribution_exchange 等全部 economy_ 前缀）
- `文本材料/data/spirit_stone_ladder*`、`market_price_master_v100*`、`item_economy_tags_v101*`、`newgame_plus_economy_v102*`
- `文本材料/data/merchant_shops.json`、`trade_routes*`

**模组侧（本模块拥有）**
- `shop/`：`ShopService`、`ShopQuotaService`；`catalog/merchant_shops_runtime.json`（索引产物）
- `AuctionSoftService`、`AuctionHouseSavedData`、拍卖相关包（`AuctionAction`/`OpenAuctionScreen`/`SyncAuctionLadder`）与拍卖/市场屏幕的数据面
- `SpiritStoneItem`、`ImmortalJadeItem`、`StarPalaceTaxReceiptItem`（货币行为）
- `ModEvents` 中村民灵石兑换段

## 依赖前置库

- Forge `SavedData`（拍卖行持久化）；网络包 `SyncShopData`/`ShopAction`/`AuctionAction`/`SyncAuctionLadder`。

## 接口交叉（谁提供 → 谁消费）

- **M05 → M08**：贡献兑换框架接口（M08 提供货架数据实例化）。
- **M05 → M12**：商店 UI/服务框架（NPC 商人 `MarketTrader` 复用）。
- **M05 ← M03**：全部商品 id 解析。
- **M05 ← M04**：产出物成本锚点（只读参考）。
- **M05 ← M01**：商店档位/拍卖入场境界门槛。

## 验收与红线

- 价格主表中每个物品 id 可解析；兑换链 1:100:10000:1000000 全链服务端校验。
- 红线（DESIGNER_HANDBOOK §5）：**功勋/贡献与灵石之间不存在无限双向兑换**；唯一物品不进拍卖与商店通道。
- 拍卖包字段若变 → 双升版本。
