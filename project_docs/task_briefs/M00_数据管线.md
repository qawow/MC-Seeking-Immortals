## 接口交叉（谁提供 → 谁消费）

- **M00 → 全部模块**：提供"语料同步规范 + 索引再生成流程 + 全绿校验基线"。其他模块改各自语料后按 M00 的流程重跑索引与校验。
- **M00 → M02**：功法期望数量基线裁决结果为 **作者侧 747**；发布副本是否升到 747 由 M02 决定。
- 本模块**不消费**任何其他模块接口。

## 验收与红线

- 合并前 `./gradlew build` 必须全绿；这是解除全局阻塞的唯一模块，不允许"聚焦测试绿即通过"。
- 禁止为了让测试变绿而删除语料文件；只能修正期望值或索引拼接逻辑，并在更新说明里写清裁决依据。
