# M09 秘境与副本

- 分支：`task/m09-secret-realms` ｜ worktree：`D:/codex/mc-mod-worktrees/m09-secret-realms`
- 前置模块：M00、M06（region_id）、M13（维度 id）、M10（Boss 实体，可先桩）、M03（掉落物品 id）
- 优先级：P1

## 目标

落地 19 个秘境：入口门方块 → 秘境维度/口袋空间 → 机关与 Boss → 掉落与结算 → 通关事件，打通"限时副本"完整循环。

## 功能点清单（可勾选）

- [ ] 秘境主数据：`secret_realms.json`（19 个）+ `secret_realm_template` → worldpack 秘境服务（`WorldpackDataService` secret_realms/secret_realm_flavor 段）扩量。
- [ ] 深潜数据：各秘境 deep dive（v104–v111 系列）→ 楼层/机关/事件脚本参数化。
- [ ] 入口门方块：7 个 gate 方块（AncientRift/Ascension/BloodForbidden/Cycle/HiddenRift/KingTerritory/NetherFerry）与秘境的开启条件（钥匙物品、境界带、开放窗口）逐一绑定；开启校验全部服务端。
- [ ] Boss 与守卫：按 `boss_loot_tables` 布置 Boss 战（实体由 M10 提供，本模块负责刷点/阶段/门锁）。
- [ ] 掉落结算：`boss_loot_tables` → loot table JSON + 首通/重复通关差异（红线：唯一物品不进重复掉落）。
- [ ] 通关事件：`onRealmCleared(realmId, player)` 钩子发布（供 M11 任务、M06 区域事件记录）。
- [ ] 限时/人数/复活规则：秘境内死亡处理、超时踢出、进度 SavedData 持久化。
- [ ] 秘境内阵法机关消费 M07 场效果接口（禁止自建一套场系统）。

- 19 个秘境全部有入口绑定、境界带校验测试、掉落表可解析。
