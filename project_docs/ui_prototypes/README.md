## 如何试装一套方案

1. 读目标方案文档的「四场景色板」节，把 46-token ARGB 值填入
   `client/ui/InkScene.java` 四个枚举常量（字段顺序见 `UiClimate.Palette`）。
2. 把方案文档附带的纹理生成 Python 片段合入
   `scripts/generate_ink_ui_textures.py`（或新建 `generate_<方案>_textures.py`），
   产出同名 `textures/gui/ink/*.png` 覆盖即可（skin 纹理常量不用改）。
3. 跑 `InkPaletteTest`：**深色方案需要按方案文档说明反转对比度断言**
   （现行断言假定浅纸深墨；深色方案文档各自给出替换断言）。
4. `./gradlew build` + runClient ���检 23 屏与 4 HUD。

## 共同硬约束（所有方案必须遵守）

- 四场景语义路由不变：静修族 / 行旅族（默认） / 交易族 / 凶危强调。
- 跨场景语义色恒定：警示琥珀、危签朱砂（可按方案微调色相，但四场景内一致）。
- 无霓虹、无近白半透明高光；HUD 半透明轻量化；技能栏无外框（0.1.31）。
- 全部颜色只活在色板层；屏幕零硬编码 hex；文案键化（zh/en 齐平）。
- 不可破坏接口清单见 `../ui_style_guide.md` §7。

## 挑选建议

- 想要**最强夜游戏氛围**：方案一（玄夜星图）。
- 想要**最"古董感"**、和坊市/宗门大殿气质最合：方案二（青铜鼎纹）。
- 想要**中性耐看、久用不腻**：方案三（洞府石刻）。
- 想要**最"符修"味、和符箓玩法呼应**：方案四（符箓黄纸）。
- 想要**最文人画意**、接近国风游戏大作：方案五（水墨山水），代价是纹理最讲究。
- 也可**混搭**：如日常界面用方案〇、坊市族换方案二、凶危强调借方案四的浓朱——
  InkScene 是按场景取色板的，跨方案混搭 = 只替换对应场景那一组值。
